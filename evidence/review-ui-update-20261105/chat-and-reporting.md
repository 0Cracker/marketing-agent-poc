# 공통 AI 챗과 보고 기준 선택 변경 검증

## 1. 리뷰 분석의 공통 AI 챗

- 사용자 요청은 리뷰 분석에서도 성과 현황과 동일한 오른쪽 AI 챗 버튼과 패널을 제공하는 것이다.
- 리뷰 페이지에서 버튼과 패널을 숨기던 조건을 제거하고, 리뷰 진입 시 열린 채팅을 강제로 닫던 동작을 제거했다. 패널의 현재 화면 이름은 리뷰 분석으로 표시한다.
- tests/roas/chat-navigation.test.mjs에서 변경 전 리뷰 페이지 가드로 실패한 것을 확인했고 변경 후 통과했다. 타입 검사를 통과했다.
- 실제 화면 독립 검증은 후속 결과에 기록한다.
- Git 작성자 설정이 없어 저장소의 기존 자동화 커밋 작성자인 Codex <codex@openai.com>을 해당 명령에만 지정한다.

## 2. 보고 기준시점 선택 제거

- 기존 기본값 initial, 2026-08-31 기준을 고정하고 사이드바의 보고 기준시점 선택 UI와 변경 상태를 제거했다. 기존 데이터 스냅샷과 원천 API는 보존한다.
- 성과 조회, 리뷰 조회와 AI 챗은 모두 같은 고정 스냅샷을 사용한다. 실제 집계 시점은 성과 화면의 보고 기준 표시로 확인할 수 있다.
- S15 설명에서 삭제된 선택기를 바꾸도록 안내하던 문장을 제거했다.
- tests/roas/reporting-cutoff.test.mjs에서 변경 전 선택기가 남아 실패했고 변경 후 통과했다. 전체 npm test 68/68, 타입 검사, 변경 파일 ESLint와 빌드를 통과했다. 빌드는 기존 폰트 경로와 청크 크기 경고가 있다.
- 독립 ui_ux_verifier(gpt-6.1-terra, high)는 정적 검토에서 스냅샷 전달의 일관성과 채팅 유지 경로를 확인했다. S15 설명 결함을 발견해 수정했으며 최신 코드에서 해당 수정도 확인했다.
- Chrome과 Edge headless가 모두 시작 직후 종료되고 디버깅 포트가 열리지 않아 실제 화면 조작, 모바일 배치 검증은 미완료다.
- 이전 리뷰 업데이트는 d1b6c55, 공통 AI 챗 표시는 6e923b6으로 각각 커밋했다. 이번 변경도 별도 커밋으로 보존한다. 원격 푸시와 배포는 수행하지 않았다.
