# 공통 AI 챗과 보고 기준 선택 변경 검증

## 1. 리뷰 분석의 공통 AI 챗

- 사용자 요청은 리뷰 분석에서도 성과 현황과 동일한 오른쪽 AI 챗 버튼과 패널을 제공하는 것이다.
- 리뷰 페이지에서 버튼과 패널을 숨기던 조건을 제거하고, 리뷰 진입 시 열린 채팅을 강제로 닫던 동작을 제거했다. 패널의 현재 화면 이름은 리뷰 분석으로 표시한다.
- tests/roas/chat-navigation.test.mjs에서 변경 전 리뷰 페이지 가드로 실패한 것을 확인했고 변경 후 통과했다. 타입 검사를 통과했다.
- 실제 화면 독립 검증은 후속 결과에 기록한다.
- Git 작성자 설정이 없어 저장소의 기존 자동화 커밋 작성자인 Codex <codex@openai.com>을 해당 명령에만 지정한다.
