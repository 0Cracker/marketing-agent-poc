- 변경 후 실제 컴포넌트를 Vite SSR로 로드한 동일 검사에서 S16, S17 각각 25건, 날짜 범위, 전체 기간 기본 선택과 보기 전환 버튼을 확인했다.

- 표 열 정렬 보완 후 SSR, 타입 검사와 최종 빌드를 통과했다. 최종 빌드는 39.08초에 완료했다.

- ui_ux_verifier 역할(gpt-6.1-terra, high)의 별도 컨텍스트에서 정적 검토했다. 기본 전체 기간, 두 기간의 별도 집계, 대분류별 세분류 연결과 동일 표의 열 구성을 확인했다.

- 원격 CI, 커밋, 푸시와 배포는 수행하지 않았다.

## 2026-11-05 화면 주석 후속 수정

- 대분류 그래프 행을 누르면 해당 세분류 그래프로 이동한다. 대분류 전체 버튼으로 복귀하며, 키보드 포커스도 진입과 복귀 대상에 이어진다. 하단 원문 카테고리 필터는 별도로 유지한다.
- 기존 공통 Button을 기반으로 SelectionButton을 만들었다. 판매처, 카테고리, 기간/보기 전환, 캠페인 탐색 모드와 AI 답변의 표/그래프 선택에서 재사용한다. 공통 모서리 값은 8px이다.
- 원문이 실제 두 줄을 넘거나 검색 문맥을 생략한 경우에만 더 보기를 표시한다. ResizeObserver와 폰트 준비 후 재측정을 수행한다.
- 리뷰 원문을 앞에 두고 원문 확인을 마지막 열로 옮겼다.
- 변경 전 SSR 회귀 검사는 반복된 세부 분류 보기 줄이 남아 예상한 실패를 확인했다. 변경 후 관련 SSR/리뷰 검사는 통과했다.
- 실제 iab에서 세정 및 사용감 진입 시 소속 세분류 5개만 표시됨, 대분류 복귀, 원문 펼침을 확인했다. 필터 9개의 계산된 모서리는 모두 8px이었다. 2줄 원문은 높이 37px, 버튼 없음이며 3줄 원문은 내용 높이 56px, 더 보기 표시를 확인했다. 표 머리글은 리뷰 원문 다음 원문 확인이었다.
