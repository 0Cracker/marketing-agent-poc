# 시각화 목록과 요소별 판정

평가 대상과 상세 발견은 [최종 보고서](report.md)를 따른다. 같은 컴포넌트가 지표마다 반복되는 경우 적용 지표를 모두 적고 표현 방식별로 묶었다. 제거를 권할 만한 중복이나 무의미한 요소는 이번 관찰에서 확정하지 못했다.

## 교육 대시보드

공통 기간은 분석 2026.08.17~08.30, 비교 08.03~08.16이다. 사례, 캠페인 또는 집행처, 기기 필터가 적용된다. 아래의 기간 비교는 이 두 기간을 뜻한다. UI 표시값의 정확성은 검산하지 않았다.

CAC 상세에는 기간별 차트와 집단 쌍 막대가 없다. 미집계를 차트의 0으로 그리지 않는 선택은 유지한다. 큰 차트의 자동 상한은 조회 범위에 따라 달라지지만 축이 표시되므로 그 자체를 왜곡으로 판정하지 않았다. 작은 카드의 무표시 눈금과는 구분한다.

## 전체 데이터 탐색의 41개 자료 화면

모든 행의 화면을 직접 열어 기본 일본, JPY, 기준월 2026.08 상태의 KPI, 차트 제목과 상세 표 머리글을 확인했다. 구성비, 시간 추이, 비교 표 같은 표현 구조는 렌더링된 UI와 구현을 대조했다. 개별 차트의 모든 클릭, 툴팁, 표 전환, 페이지 넘김, 필터 조합과 예외 상태는 미검증이다. 이 부분의 유지 판정은 기본 표현의 적합성에 관한 잠정 판단이며 교육 화면 수준의 경로 검증을 뜻하지 않는다.

아래 각 행은 KPI, 열거한 차트와 표에 공통으로 적용하는 판정이다. 다른 판정이 필요한 요소는 따로 표시했다. 제목의 구분 문자는 읽기 편하게 쉼표로 정리했다.

기간 표기 원칙: `월`은 상단 선택월에 해당하는 값, `이력`은 차트에 표시되는 관측 이력이다. 월을 골라도 이력이 여러 달에 걸치는 화면이 있어 정확한 시작과 종료를 현재 위치에 표시해야 한다. `최근`은 화면이 최근 관측을 선택하는 표현이며 상단 월과의 관계를 모두 검산한 것은 아니다. 이 공통 위험과 수정은 UX-12다.
