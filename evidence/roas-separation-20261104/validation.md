## 최종 결과

- 현재 회귀 65개 통과, 실패 0개. 전체 36개 성과와 36개 리뷰 응답은 이동 전 내용 해시와 일치한다. 자료 식별 해시만 전용 manifest로 바뀐다.
- 원본 네 파일 SHA-256과 재생성 결과 바이트 일치. 독립 검증에서 광고 원천 28줄의 Git HEAD 원본 일치도 확인했다.
- 타입 검사 통과.
- 전체 lint 오류 0개, 기존 연구 생성기 두 곳의 미사용 변수 경고 2개. DB 설정 이동 중 실행했던 lint는 ENOENT로 중단됐고 경로 확정 후 재실행은 통과했다. 실패 로그도 보존했다.
- 최종 현재 Vite 빌드 통과. dist/workbench-data/roas의 파생 응답은 73개이며 current/ 폴더와 원본 자료를 배포하지 않는다. 500kB 초과 청크와 폰트 빌드 시 경로 해석 경고는 남지만 폰트 파일은 plugin이 원래 URL로 배포한다.
- 보관 Vite 빌드 통과, legacy 초기 마케팅 집계와 CTI 시연 검사 두 명령 통과.
- 실제 ROAS 서버를 시작해 세션, 인증 채팅, 구 API 404를 확인했다.
- 리뷰 누락, 변조 시 성과 조회와 plugin 시작은 유지되고 리뷰만 오류로 반환한다. 회귀를 재현하는 RED 후 수정한 GREEN을 확인했다.

명령과 종료 코드는 checks.json, 상세 출력은 regression.log, types.log, lint.log, build.log, legacy-build.log에 있다. 로컬 도구 PATH에 npm이 없어 실제 검증은 Node로 설치된 실행기를 직접 호출했다.

## 독립 검증과 한계

별도 컨텍스트 코드 검증자는 legacy 파일 접근을 차단한 서버 시작, 선택적 리뷰 장애 격리, 필수 성과 자료 변조 거부, 원본과 복사 자료 일치를 확인했다. 독립 UI 검증자는 실제 브라우저에서 성과 현황, CVR 상세, 리뷰 판매처 필터와 구 메뉴 제거를 확인했다. 브라우저 도구 연결 장애로 캠페인 범위 필터, 예시 대화, 모바일과 키보드 조작은 실제 UI에서 미확인이다. 상세는 independent-review.md를 따른다.

실제 외부 모델 호출, Git 커밋, push와 원격 배포는 수행하지 않았다.
