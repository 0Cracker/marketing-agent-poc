# 독립 검증

2026-11-04, 별도 컨텍스트의 코드 검증자와 ui_ux_verifier가 미커밋 분리 작업본을 확인했다. 제품 코드는 주 담당이 수정했다.

## 코드와 데이터

분리 검증의 원래 네 시나리오가 통과했다. 36개 성과와 36개 리뷰 응답 기준값, 원본 생성 결과, 공개 자산 73개와 소스 import 경계를 확인했다. training-dashboard는 Git HEAD와 바이트 일치, 미추적 사용자 작업이었던 리뷰 원본 세 개는 legacy/data의 보존본과 바이트 일치, 광고 원천 28줄은 HEAD:data/ad-performance.jsonl의 해당 원천 줄과 정확히 일치했다.

초기 분리에서 리뷰 누락이 성과와 서버 시작을 막는 회귀를 발견했다. 주 담당은 오류를 재현하는 검사를 먼저 실패시킨 뒤 요청한 파일만 무결성 확인하도록 수정했다. 검증자는 fs 읽기 차단과 같은 크기의 원문 변조를 통해 리뷰 누락, 변조에도 성과 조회와 plugin 시작이 유지되고 리뷰만 오류로 반환하는 것을 재확인했다. 새 프로세스에서 필수 성과 원본 변조를 거부했다. legacy 읽기와 리뷰 읽기를 차단한 새 프로세스에서도 API 서버가 시작해 로컬 HTTP 요청에 응답했다. 이후 주 담당의 실제 서버 세션, 인증 채팅과 구 API 404 통합 검사도 통과했다. 외부 모델은 호출하지 않았다.

CI 경로 필터와 검사 목록의 누락도 발견해 현재 경로 전체와 npm test를 포함하도록 수정했다.

## 실제 UI

ui_ux_verifier는 로컬 Vite와 IAB에서 S16 성과 현황의 ROAS 284.7%, 직전 355.8%, 변화 -71.1%p, CVR 상세의 4.16%, 퍼널과 표를 확인했다. 리뷰 분석에서 자사몰 선택에 따라 리뷰 수가 13건에서 8건, 평균 평점이 3.5에서 4.0으로 바뀌었다. 구 대시보드 메뉴가 없고 버튼 이름, 리뷰 필터 선택 상태가 접근성 트리에 노출됐다.

캠페인 범위 선택기를 조작할 때 브라우저 도구가 시간 초과됐고 재연결, Chrome 탭 생성도 실패했다. 제품 문제인지 판단할 근거는 없다. 캠페인 범위 필터, 예시 대화, 모바일과 키보드 조작은 실제 브라우저에서 미확인이다. 표본 검증으로 화면 전체의 동일성을 확정하지 않는다.
