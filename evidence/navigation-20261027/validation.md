# 지표 상세 탐색과 성과 현황 복귀 검증

- 날짜: 2026-10-27, Windows, Chrome, Node.js. 대상: dev `48f51f5` 이후 v0.4.6 작업 트리.
- 입력: S16, 2026-08-17~30 분석, 직전 14일 비교, 전체 캠페인. 기존 데이터는 변경하지 않았다.

## 변경과 판단

기존 헤더의 작은 경로 버튼에 의존하던 복귀 동선을 보완했다. 필터 아래의 고정 탐색 바에 성과 현황 복귀, 7개 지표 바로 이동, 상세 분석과 비교 표 전환을 같은 위치에 배치했다. 현재 지표는 밑줄과 aria-current로 표시한다. 기존 경로와 브라우저 이력은 재사용하고 새 라우터나 의존성은 추가하지 않았다.

(구) 대시보드 버튼은 로고와 같은 Layers 아이콘을 사용하고 “(구) 대시보드 확인”으로 표시한다.

스크롤 복귀 검사에서 펼친 표가 상세 화면의 언마운트 이후 접혀 문서 높이가 줄고 저장 위치가 잘리는 문제를 발견했다. 성과 현황을 떠날 때 native details의 펼침 상태를 저장하고, 복귀할 때 스크롤보다 먼저 복원했다. 화면 전환 후 주제목으로 키보드 초점을 옮기되 별도 스크롤은 발생시키지 않는다.

스크롤 검증에서는 자동 locator 클릭이 고정 요소를 화면 안으로 이동시키면서 선행 스크롤을 바꾸는 점을 발견했다. 스크린샷에 근거한 실제 좌표 클릭으로 전후 위치를 검증했다. [최종 CPC 상세 화면](cpc-navigation.jpg)을 저장했다. 별도 모바일 기기와 실제 사용자의 탐색 성공률은 미검증이다.
