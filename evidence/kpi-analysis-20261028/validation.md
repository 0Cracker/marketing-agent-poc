## 수치와 집계

- 새 검사 9개 중 전수 검사는 18개 사례 × 보고 시점 2개 × KPI 6개 × 분할 5개 = 1,080개 조합이다. 캠페인, 기기, 상품, 타깃, 소재 분할을 각각 독립적으로 집계했다.
- 모든 조합에서 행별 기여 합계가 전체 KPI 변화와 일치한다. 허용 오차는 내부 단위 `1e-8`이다. 자체 변화와 구성 변화의 합도 각 행의 기여와 일치한다. 실제 자료에 있는 0 분모, 신규와 종료 그룹을 포함한다.
- S07의 전체 ROAS는 400% → 300%다. 개별 캠페인 ROAS는 그대로여서 자체 변화의 합은 0, 구성 변화의 합은 -100%p다. 높은 ROAS 캠페인들의 집행비 비중은 50% → 25%, 낮은 캠페인들은 50% → 75%다.
- S16의 ROAS는 355.8% → 284.7%, -71.1%p다. 화면 구성 지표 기여는 AOV +17.2%p, CVR -51.8%p, CPC -36.5%p다. 내부 계산은 6가지 교체 순서의 평균을 사용한다.
- S03은 할인율이 같고 상품별 주문 비중이 다르다. S12와 S17은 할인율 변화를 별도 확인한다. 모든 기존 주문은 수량 1이며 AOV와 평균 실현 판매가가 같다는 한계를 표시한다.
- 광고 CTR에는 콘텐츠 조회를 포함하지 않는다. CPC의 광고와 콘텐츠 관련 지표를 분리하고 두 구역의 그룹 기여는 전체 클릭수 분모로 계산한다.
- S13 결제, S14 계측 대조, S15 initial과 mature의 귀속 지연 구분은 기존 회귀를 유지한다. 이 변화들을 실제 구매 이탈의 동일 원인으로 설명하지 않는다.

## 남은 한계

- 마케터의 조사 성공률과 이해도, 실사용 데이터, 모바일 실기기는 미검증이다.
- 유입별 비용은 기존 교육용 가상 배분이다. 소재별 도달, 상품과 유입의 교차 집계, 개인별 여정, 다상품 주문 구성은 제공하지 않는다.
- 현재 AI 조회 계약의 범위는 캠페인과 기기다. 세부 유입 범위의 실시간 AI 질의는 지원하지 않는다. 범위를 조용히 넓혀 답변하지 않는다.
- 원천 JSON, manifest, 공통 타입과 API 계약을 변경하지 않았다. 추가 데이터가 필요하면 수량과 관계, 생성 규칙과 검산 방법을 별도로 제안한다.
- 기존 삭제 3개는 보존한다. 원격 push, Vercel 배포, main 병합, 태그와 Release는 이번 작업에서 수행하지 않는다.
- 첫 커밋 명령은 Git 작성자 정보 미설정으로 실패했다. 최근 3개 커밋의 동일한 작성자 정보를 조회하고 `git -c user.name=... -c user.email=... commit`으로 이번 명령에만 적용한다. Git 설정 파일은 변경하지 않는다.
