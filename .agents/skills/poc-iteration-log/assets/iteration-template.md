## 발행 준비 확인

`docs/DEVELOPMENT-WORKFLOW.md`의 체크리스트를 점검한다. docs/iterations/로 복사한 뒤 운영 문서를 연결할 때 상대 경로는 `../DEVELOPMENT-WORKFLOW.md`다. 태그 전에 구현·문서·Evidence·검증·남은 문제를 확정한다. 태그 푸시/병합/Release 성공은 아직 실행하지 않았으면 미확인으로 남긴다. 최종 커밋 SHA는 Release Notes에 기록하고 발행 후 인덱스는 다음 dev 사이클에서 갱신한다.
