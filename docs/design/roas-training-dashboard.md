# ROAS 교육용 공통 대시보드, 계획과 실행 기록

현재 상품과 비용 계약은 [2026-10-26 DATA-01~03 승인 수정](#2026-10-26-data-0103-승인-수정)을 우선한다. 아래 날짜별 계획과 검증 기록은 당시 상태로 보존한다.

2026-10-26 사용자 요청으로 각 사례의 상황과 살펴볼 내용을 화면 제목 아래 옅은 설명으로 추가했다. 앞선 중립 사례명만 표시하던 방침에서 사용자가 요청한 안내 방식으로 변경한 것이다. 현재 설명은 원인 후보도 일부 알려주는 학습 안내이므로, 설명을 읽은 탐색을 정답을 모르는 상태의 독립 조사로 평가하지 않는다. 집계와 원본 데이터는 변경하지 않았다.

이 문구 수정은 TypeScript 검사와 diff 공백 검사를 통과했다. 로컬 브라우저에서 기본 사례 16의 표시, 사례 17 전환과 상세 데이터 화면의 설명 유지를 확인했다. 18개 사례 각각의 화면 전수 검사와 실제 마케터 이해도 검증은 수행하지 않았다.

2026-10-23, 사용자 대화에 따른 구현 명세다. 기존 `feature/roas-decision-flow`의 미커밋 작업을 보존하며 새 발행 버전은 정하지 않는다. 아래 생성 수량과 검증은 별도 결과가 기록되기 전까지 목표이며 완료 실적이 아니다.

## 1. 목표와 범위

모든 사례는 같은 데이터 규약과 화면을 사용한다. 학습자가 ROAS 변화를 발견한 뒤 지표, 비교 집단과 운영 근거를 직접 찾아 결론과 대응을 판단하도록 한다.

> ROAS 변화 → 매출과 광고비 → CPC, 구매율, AOV → 캠페인과 기기별 비교 → 세부 근거 조사 → 조건부 대응

- S01~S18의 메뉴, 표, 열, 기본 정렬과 필터가 같다. 관련 없는 영역도 정상 자료를 제공한다.
- 사례별 패널 숨김, 문제 자동 강조, 원인 요약, 조사 경로와 액션 정답을 넣지 않는다. 사례명은 `사례 01`처럼 표시한다.
- 기존 원천 41,341행, 정의, 계산 API와 과거 승인, Evidence를 보존한다. 신규 자료는 화면용 집계 계약으로 분리한다.
- 주문, 클릭, 세션 원본과 리뷰 원문은 새로 만들지 않는다. 실제로 내용을 열어보는 소재, 설정 변경과 장애만 개별 기록으로 만든다.
- 수식 일치와 화면의 조사 가능성을 검증한다. 실제 학습 효과나 인과효과 입증으로 보고하지 않는다.

## 3. 하나의 공통 데이터 규약

화면용 계약은 `roas-training/1`이다. 기존 41개 원천 유형에 가짜 주문이나 이벤트를 끼워 넣지 않는다. 생성 규칙과 정답은 비공개 검수 자료로 관리하고 공개 조회에는 필요한 측정 정의와 출처만 제공한다.

| 공통 데이터 | 모든 사례에 제공할 내용 |
| --- | --- |
| 성과와 광고 | 날짜, 출처, 채널, 유형, 캠페인, 기기, 노출 또는 조회, 클릭, 비용, 귀속 주문과 매출 |

| 소재와 유입 | 소재 버전과 문구, 형식, 연결 상품과 랜딩, 타깃 정의, 지면, 검색어와 매치 유형별 집계 |

변경과 장애가 없으면 현재 정상 상태와 조회 범위를 제공하고 건수는 0으로 표시한다. 유형상 검색어 등이 적용되지 않으면 모든 사례에 같은 `미적용` 규칙을 사용한다. 누락 자료를 정상 0으로 채우지 않는다.

### 산식과 생성 관계

- ROAS = 귀속 구매매출 / 비용. CPC = 비용 / 클릭. 클릭 기준 구매율 = 귀속 주문 / 클릭. AOV = 귀속 매출 / 주문. CPA = 비용 / 주문.
- ROAS = 클릭 기준 구매율 × AOV / CPC. 광고 CTR = 클릭 / 광고 노출. 광고 CPM = 비용 / 광고 노출 × 1,000.
- 콘텐츠 링크 클릭률 = 추적 링크 클릭 / 콘텐츠 조회. 세션 구매율은 구매 세션 / 대상 세션으로 별도 계산한다.
- 전체 비율은 합계의 분자와 분모로 계산한다. 분모 0은 계산 불가다. 도달은 일별 값을 합산하지 않는다.
- 퍼널은 같은 세션의 순차 도달이며 재방문 구매는 분리한다. 신규 자료에서 한 주문과 한 분석 세션은 하나의 SKU 집단에 속하고 타깃 집단은 상호 배타적이라고 가정한다.

기본 집계는 날짜 × 캠페인 × 기기 × 상품 × 타깃이다. 28 × 6 × 2 × 3 × 2 × 15 = 30,240행을 계획한다. 보조 집계 포함 50,000행 이하, 공통 마스터 참조를 포함한 고유 개별 상세 200건 이하로 제한한다. 실제 생성 후 수량은 결과 절에 기록한다.

기본 비교기간 목표는 비용 120만원, 클릭 2,400, 구매 120, AOV 4만원, 매출 480만원, ROAS 400%다. 광고 노출과 콘텐츠 조회는 유형별 배분하고 120,000이라는 예시 노출 합계를 공통 광고 분모로 강제하지 않는다.

공통 요일과 캠페인 패턴에서 사례별 변화만 적용한다. 비용과 건수를 먼저 만들고 비율을 계산한다. 고정 seed와 정수 배분으로 재현한다. 소재, 지면과 검색어의 제공 조합을 명시하고 서로 다른 분할표를 중복 합산하지 않는다.

모든 사례에 같은 보고 기준시점 선택을 둔다. S15의 후속 구매는 09-07 조회에만 나타나며 08-31 응답에 정답이나 예상 최종 수치를 포함하지 않는다. 생성 규칙과 정답은 공개 API, 프런트 번들과 Agent 조회 자료에서 분리한다.

## 10. 지표 개요와 상세 분석, 2026-10-23

사용자 요청에 따라 비용, 구매율, 객단가와 결제 상태가 함께 변하는 S16을 기본 사례로 설정했다. ROAS를 상단 주지표로 유지하고 CTR, CPC, CVR, CPA, CAC, AOV의 비교기간/조회기간 추이를 카드로 제공한다. 모든 사례에 같은 배치와 상세 분석을 적용한다. 지표를 누르면 개요를 대신하는 상세 화면이 열리며 뒤로 가기로 복귀한다. 채널, 출처, 캠페인, 기기와 기준시점 필터는 상세에도 유지된다.

비교기간은 회색 점선, 조회기간은 보라색 실선으로 표시하고 14일의 같은 요일끼리 겹친다. 그래프의 날짜 안내에는 두 실제 날짜를 함께 남긴다. 기간별 집계는 일별 비율의 평균이 아니라 원천 수 합계로 계산한다. 막대 비교는 기간 전체 집계이며 일별 선 그래프와 구분한다. 숫자 크기와 방향에 따라 정답, 원인이나 정상/문제 색을 자동 부여하지 않는다.

| 지표 | 상세에서 비교하는 자료 |
| --- | --- |
| ROAS | 매출, 광고비, CPC, CVR, AOV, 캠페인과 기기별 ROAS |
| CTR | 광고 노출과 클릭, CPM, CPC, 소재별 수치, 소재와 집행 기록 |
| CPC | 광고비와 클릭, CPM과 CTR, 타깃/지면별 수치와 설정 기록 |
| CVR | 클릭과 주문, 세션 구매율과 결제 완료율, 세션 퍼널과 기기별 결제 실패율 |
| CPA | 광고비와 주문, CPC와 CVR, 구매 퍼널과 결제 상태 |
| CAC | 신규 고객 수 미집계 안내, 광고비만 비교. CPA나 주문 수로 대체하지 않음 |
| AOV | 매출과 주문, 할인 전 단가와 할인율, 상품별 주문 구성과 매출 |

CTR은 광고 노출 분모만 사용한다. 콘텐츠만 선택하면 CTR은 측정값 없음이며 콘텐츠 조회를 광고 노출로 바꾸지 않는다. CAC는 현재 계약에 신규 고객 수가 없으므로 추이와 값을 null로 유지한다. 신규 고객 판정, 비용 범위와 신규 데이터 생성은 이번 수정에 포함하지 않았다. 전 단계와 공통 메뉴의 넓은 표와 운영 기록은 기본 접힘으로 바꾸고 모든 값과 집계 근거는 계속 열람할 수 있다.

[검증 기록](../../evidence/training-metric-ui-20261023/validation.json): 자동 검사 17개, 타입, 린트와 빌드 통과. 새 추이 검사는 같은 요일과 실제 날짜, 기기 필터, 각 분모, 콘텐츠 CTR 제외와 CAC null을 확인한다. 기존 집계 파일 SHA256은 직전 검증본과 같다. PC 브라우저 검수는 도구 비활성화로 미실행, 모바일 검수와 실제 학습 효과, 발행도 수행하지 않았다.


### 테스트 케이스 선택 위치 정리, 2026-10-23

S16 기본값은 유지하고 상단 필터의 사례 선택을 왼쪽 하단 전체 데이터 탐색 위의 접힌 테스트 케이스로 이동했다. 기본 대시보드와 다른 17개 사례를 선택할 수 있고 테스트 중인 사례명은 하단에만 표시한다. 동일 사례 재선택의 요청 초기화 방지와 모든 데이터, 지표 상세, 필터는 유지했다. 상단에서 선택기 제거, 하단 배치와 S16 기본값, Vite 변환 모듈 HTTP 응답을 확인했다. PC 브라우저 화면 검수는 기존 도구 비활성화로 미실행이다.


## 11. 추이와 상세 데이터의 연결, 기간 표현과 카드 수정, 2026-10-23

사용자가 카드의 글자 겹침과 기존 5개 메뉴의 데이터 분산을 지적했다. 카드 전체에 적용된 공통 .wb button의 inline-flex와 nowrap이 카드 grid보다 높은 CSS 우선순위로 적용되고 있었다. 카드를 article로 바꾸고 제목, 상세 버튼, 값과 증감, 추이를 분리했다. 개요 카드의 계산 설명은 상세 화면으로 옮겼으며 좁은 PC 폭에서는 2열로 배치한다. 미실행 브라우저 검수를 완료로 기록하지 않는다.

메뉴는 성과 추이, 상세 데이터의 2개로 통일했다. 성과 추이에서 지표를 선택해 분석하고, 상세 데이터에서 확인 버튼으로 같은 기간과 전역 필터를 유지하며 관련 지표 묶음을 연다. 상세 데이터는 캠페인, 채널, 출처, 기기, 소재, 타깃, 지면, 검색어, 상품, 결제 수단, 브라우저 분류와 핵심 성과, 노출과 유입, 구매 퍼널, 주문과 매출, 결제 상태, 수집과 대사 묶음을 조합해 한 표에서 확인한다. 운영 기록과 도달/빈도, 캠페인 설정과 상품 기준 정보도 같은 화면에 유지했다. 기존 사례별 원천과 기준시점, 테스트 케이스 위치는 그대로다.

상단에 분석 기간의 실제 날짜, 비교: 직전 14일과 실제 날짜를 명시했다. 그래프와 표에서는 분석 기간, 직전 14일로 통일하고 화살표로 두 값을 중복 표시하던 ROAS 영역을 단순화했다. 선 그래프의 가로축은 분석 날짜이며 툴팁은 분석 날짜와 직전 날짜를 함께 표시한다.

증감 색은 사용자가 물은 두 방식 중 방향을 일관되게 읽는 방식으로 구현했다. 증가는 빨강, 감소는 파랑, 변화 없음과 미집계는 중립색이다. 상단에 범례를 두며 지표별 유불리에 따라 색을 뒤집지 않는다. 선 그래프의 기간 구분은 기존 회색 점선과 보라색 실선을 유지한다.

검증은 evidence/training-navigation-20261023에 기록한다. 기존 집계 SHA256 보존을 확인했다. 타입, 린트와 자동 검사, 빌드는 실행 중이다. PC 브라우저 도구가 Local browser use is disabled in Work settings를 반환하여 실제 화면 크기별 겹침과 조작은 미검증이다. 모바일 검수, 신규 데이터 생성과 발행은 제외했다.


최종 자동 검증: 18개 사례에 대한 검사 17개, 타입과 린트, Vite 빌드를 통과했다. 현재 UI 모듈의 JSX 변환과 HTTP 응답 200, 집계 원본 SHA 보존을 확인했다. [검증 결과](../../evidence/training-navigation-20261023/validation.json)와 [현재 코드와 응답 확인](../../evidence/training-navigation-20261023/http-and-source.json)에 범위를 기록했다. PC 실화면 검수는 브라우저 도구 비활성화로 미실행이며 카드 겹침의 시각적 해소까지 검증한 것으로 해석하지 않는다.


## 12. 찾는 자료 중심의 분류, 매체 선택과 식별자 표시, 2026-10-23

사용자는 상단 채널/출처와 하단 분류/지표 선택이 경쟁해 원하는 자료를 찾기 어렵다고 지적했다. 상단은 조회 대상인 매체, 캠페인, 기기만 표시한다. 채널과 출처를 매체 하나로 통합하고 실제 캠페인 메타데이터에 있는 조합만 선택한다. 검색광고에는 구글, 소셜광고에는 페이스북과 인스타그램 피드, 콘텐츠에는 네이버 블로그 협찬과 인스타그램 협업이 있다. 인스타그램 피드광고는 실제 소셜 캠페인이 있으므로 제거하지 않고 콘텐츠 협업과 구분한다. 매체 변경 시 호환되지 않는 캠페인은 전체 캠페인으로 해제한다. 보고 기준시점은 테스트 케이스 영역으로 옮겼다.

상세 데이터는 무엇을 확인할까요?에서 캠페인 성과, 클릭 효율, 방문의 구매 전환, 상품 매출, 결제 실패, 구매 기록 일치 여부 중 조사 목적을 선택한다. 선택한 내용에 맞는 지표와 설명을 제공하며, 표의 행 구분은 목적에 관련된 비교 대상만 제공한다. 상품 매출은 상품별 표로 바로 열리고, 클릭 효율은 소재/타깃/지면/검색어만 선택한다. 검색어는 현재 조회 대상에 검색광고가 있을 때만 표시한다. 상단은 데이터 범위를 고르고 하단은 그 범위 안의 비교 기준을 정한다. 상세 페이지의 반복 KPI 요약도 제거했다.

이전 표현은 광고 노출과 클릭, 방문부터 구매까지, 주문 수와 매출 금액, 결제 시도와 실패, 구매 기록 일치 여부로 다듬은 뒤 조사 질문과 한 줄 설명으로 통합했다. 해당 없음은 광고와 콘텐츠 간 적용되지 않는 지표, 계산 불가는 분모가 0인 비율/평균, 미집계는 신규 고객 수나 고유 도달 등 제공되지 않은 자료, 데이터 없음은 선택 범위에 관측이 없는 경우다. 표와 카드, 비교 막대의 빈 값을 구분하고 이유를 title과 접근성 설명으로 제공한다. 실제 0은 숫자 0으로 유지한다. 증감 비교가 불가능할 때도 비교 불가 또는 기준값 0으로 표시한다.

캠페인 표시 이름은 8월_구글검색_구매전환_02 같은 운영 이름, 표시 코드는 GGL-SA-202608-002 같은 형식을 쓴다. 실제 광고 계정에서 발급받은 ID라고 주장하지 않는다. canonical EDU-C2 등의 ID와 모든 참조는 보존하고 표시할 때만 치환한다. 기존 데이터의 의미나 생성 수량을 변경하지 않는다. 소재 코드와 상세 기록, 검색에도 같은 치환을 적용한다. core/extended는 기존 타깃/확장 타깃으로 표시하며 재방문/신규 고객 여부를 의미한다고 바꾸지 않는다.

[검증 결과](../../evidence/training-data-discovery-20261023/validation.json): 검사 20개, 타입, 린트와 빌드를 통과했다. 신규 검사는 실제 캠페인으로 유효 매체 조합, 캠페인 선택 유지/초기화, 기존 식별자 보존과 한국어 타깃 표시, 적용 불가/분모 0/신규 고객 미집계 구분을 확인한다. 원천 SHA256은 이전 검증본과 같다. 로컬 서버의 연결 거부를 확인해 5183에서 재시작하고 최신 UI 모듈 응답 200을 확인했다. PC 브라우저 검수는 도구 비활성화로 미실행이며 모바일, 새 데이터 생성과 발행은 제외했다.

## 13. 독립 UX 평가 후 표현과 조회 맥락 보완, 2026-10-26

사용자는 매출 의미, 기준시점, 자동 필터 초기화, 변화 탐색과 기술적 근거 표현의 개선 필요성을 제시하고, 운영 기록과 개별 근거를 본 뒤 현황으로 복귀하는 경로의 재검증을 요청했다. 관련 원천과 스키마는 유지하며 화면에 매출의 귀속 조건과 제외 항목을 표시하고, 사례와 실제 보고 기준일, 기간과 필터를 스크롤 중에도 확인하도록 했다. 비호환 캠페인의 자동 초기화에는 이유를 알린다.

상세 표는 분석기간 값과 증감을 정렬 기준으로 구분하고, 현재 정렬 기준과 방향, 분석기간 수치 아래의 증감을 표시한다. 비율 지표의 변화는 %p 차이, 금액과 건수는 상대 증감으로 비교한다. 기준값 0에서 양수가 된 경우 상대 증감은 계산 불가로 처리하며 순위 뒤에 둔다. 운영 기록 종류와 주요 필드를 한국어로 표시하고 중첩 객체를 항목별로 열람하게 했다. 원본 코드와 검색 자료는 보존했다.

작은 차트에 축과 개별 범례를 넣은 초안은 사용자가 시각적 복잡성을 이유로 거부했다. 이를 제거하고 원래 70px 추이 표현으로 복원했다. 메인 ROAS 차트는 축 테두리를 없애고 0 기준을 유지한 눈금 3개, 날짜 4개, 옅은 가로 격자와 실선, 점선 범례를 사용한다. 이 과정의 캡처는 [검증 기록](../../evidence/ux-taxonomy-20261026/validation.md)에 구분했다. 모바일 설계와 검증은 사용자 요청으로 제외했다.

같은 날 후속 요청으로 보조 지표 차트에도 날짜와 두 기간의 수치를 보여 주는 툴팁을 연결했다. 축과 범례는 화면에 추가하지 않고, 날짜 대응을 위한 숨긴 축만 사용한다. 카드의 overflow로 툴팁이 잘리지 않도록 포인터나 포커스가 있는 카드에서만 표시 범위를 연다. CTR, CPC, CVR, CPA, AOV를 PC Chrome에서 조작해 확인했다. CAC와 미적용 지표는 수치를 생성하지 않고 미집계 또는 적용 불가 사유를 안내한다. 캠페인 직접 검색과 추가 필터, 지표 상세로 메뉴를 통합하는 안은 [분류 조사](../research/campaign-media-taxonomy-20261026.md)에 후속 제안으로 기록했으며 구현하지 않았다.

현재 매체 선택기의 분류 자체는 변경하지 않았다. 광고 운영 시스템, 분석 채널, 게재 서비스와 위치의 관계를 [공식 자료 조사와 제안](../research/campaign-media-taxonomy-20261026.md)으로 분리했다. 신규 객체와 필드, 캠페인 병합, 목표 추정과 새 데이터 생성은 수행하지 않았다. 기존에 작업 중이던 사례 설명과 매출 명칭 변경은 보존했으며 이번 작업의 단독 변경으로 주장하지 않는다.

검증은 기존 회귀에 현재값과 증감 순위가 달라지는 S16 검사 1개를 추가한 총 21개 통과, 타입 검사와 대상 파일 린트 통과다. 실제 PC Chrome에서 ROAS 상세, 상세 표, 현재값과 증감 정렬, 비호환 캠페인 초기화 안내, 운영 기록과 중첩 근거, 현황 복귀, 기준시점 변경을 확인했다. 실제 마케터의 이해도와 과업 성공률, 학습 효과는 미검증이다. 새 버전, 태그, 원격 발행은 없다.


## 2026-10-26 DATA-01~03 승인 수정

사용자는 DATA-01~03의 수정 방향을 명시 승인했다. 기존 화면 개선 미커밋 작업은 보존하며 이번 변경의 단독 결과로 기록하지 않는다. 현재 사업 범위는 교육용 자사 상품 3종을 판매하는 쇼핑몰이다. 기존 원천 상품의 소유 구분을 바꾸거나 다브랜드 판매 가정을 사후에 붙이지 않는다.

- DATA-01: 교육용 상품을 EDU-P1~P3, 교육용 자사 상품 1~3으로 분리했다. 상품 분할, 광고 대상, 랜딩 주소, 재고, 운영 기록과 중첩 상품 참조를 함께 변경했다. 기존 P1A/P1B/P2A와 41,341행의 원천은 그대로 보존한다. 가격은 25,000/50,000/75,000원이며 주문과 매출은 바꾸지 않았다. 생성 원천 설명도 상품 정체성 재사용에서 독립 교육 상품으로 정정했다.
- DATA-02: S16~S18에 공통 60,000원 초기 예산 기록을 중복 연결하던 부분을 제거했다. 캠페인별 240,000원 초기 설정 하나와 후속 변경을 제공한다. 초기 기록의 기존 출처와 측정 정의, 콘텐츠 비용 설명도 보존한다. S16의 240,000원에서 420,000원 변경은 75% 증가로 해석한다.
- DATA-03: 콘텐츠는 클릭당 정산하는 유료 제휴로 명시하고, 클릭 발생일 비용, 제외 비용과 가상 분할 가정을 API 운영 설정과 화면 설명에 제공했다. 집행 유형은 blog_affiliate/creator_affiliate, 표시 이름은 콘텐츠 제휴로 정정했다. 전체 비용은 매체 광고비와 제휴 수수료를 합친 유료 마케팅 집행비로 표시한다. 고정 협업비, 제작비와 제품 제공 원가는 포함하지 않으며 고정비 협찬 교육으로 일반화하지 않는다.

첫 검증에서 S06 EDU-C6는 클릭 0인 일별 행 8개에 비용 합계 4,902원이 남아 있어 클릭 발생일 정산과 모순됨을 확인했다. 사용자가 추가로 일별 비용 재배분을 승인했다. 해당 캠페인의 분석기간 성과 28개와 분할 112개의 spend만 변경했다. 기기별 비용을 클릭 비중으로 날짜에 배분하고 상품과 타깃별 기간 합계를 유지하도록 정수 배분했다. 다른 행의 비용, 모든 비비용 수치와 도달은 변경 전 해시와 일치한다. 클릭 0, 비용 양수인 성과 행은 0개다. 가격, 주문, 매출과 모든 제공 분할의 기간 KPI는 유지하지만 이 범위의 일별 비용과 ROAS 추이는 달라진다.

원천과 과거 Evidence는 덮어쓰지 않는다. 과거 복합 확장의 payload 전체 해시 보존 검사는 승인된 상품과 비용 의미 변경으로 그대로 적용할 수 없으므로, [수정 직전 baseline](../../evidence/training-data-contract-20261026/before.json)을 기준으로 모든 숫자와 도달을 비교하고 승인된 S06 비용 예외만 별도 검사한다. 기존 원천 바이트 보존 검사와 재생성 일치 검사는 유지했다. [승인 원문과 범위](../../evidence/training-data-contract-20261026/approval.json), [실제 비용 변경](../../evidence/training-data-contract-20261026/cost-reallocation.json), [HTTP 응답 대사](../../evidence/training-data-contract-20261026/api-reconciliation.json)를 남겼다.

검증은 교육용 회귀 24개, 기존 ROAS 회귀 67개, 독립 Python Decimal 검산 97,067항목과 실제 로컬 HTTP 응답 36개가 통과했다. 타입 검사와 대상 파일 린트, Vite production build를 수행했다. 기존 ESLint pages 경로 안내와 빌드의 폰트 해석 안내는 남아 있으나 종료 코드는 0이다. 집계는 38,760개, 고유 상세는 105건이다.

브라우저는 최초 탐색 타임아웃 후 복구했다. 로컬 in-app browser의 /workbench에서 S16 ROAS 227.8%, AOV 32,678원과 교육용 상품 3종을 확인했다. S06 인스타그램 콘텐츠 제휴 선택 후 ROAS 200%, CPC 500원, CVR 2.5%, CPA 20,000원, AOV 40,000원과 광고 CTR 해당 없음 표시를 확인했다. 판매 범위와 비용 정의를 펼쳐 [화면 증거](../../evidence/training-data-contract-20261026/definitions.png)를 저장했다. 이는 표본 화면 확인이며 18개 사례의 모든 화면과 모바일 검증, 실제 학습 효과와 현업 유용성 검증은 아니다. Git 커밋과 원격 발행, 배포는 수행하지 않았다.

## 14. 캠페인 선택과 단일 탐색 경로, 2026-10-26

사용자가 캠페인과 집행처를 중심으로 찾는 방식, 성과 현황 → 지표 상세 → 비교 표 → 운영 근거 흐름과 편한 복귀를 요청하여 앞선 제안을 구현했다. 기존 매체와 캠페인 드롭다운을 분석 대상 선택기 하나로 바꾸고 캠페인 이름, 표시 ID, 집행처와 유형 검색을 지원한다. 집행처로 찾기에서는 Google Ads, Meta Ads, 콘텐츠 제휴를 나누고 실제 캠페인의 게재 서비스와 유형을 보조 정보로 표시한다. 기기는 독립 필터다. 콘텐츠 제휴는 현재 자료의 클릭당 정산 제휴이며 모든 크리에이터 협업을 광고 시스템 밖으로 분류하는 일반 계약은 아니다.

독립 상세 데이터 메뉴를 제거하고 지표 상세의 비교 표 보기에서 해당 지표에 관련된 표와 운영 근거로 연결한다. 지표 상세의 중복 표와 기록을 덜고, 계산 연결 수치와 추이, 집단 비교를 유지했다. 비교 표에서는 짧은 자료 탭과 행 구분만 선택한다. 긴 사례 설명은 테스트 케이스 영역에 두고 기간과 매출 정의, 사례와 기준시점은 계속 표시한다.

상단 고정 경로의 성과 현황과 지표 상세를 직접 누를 수 있다. 근거 창에도 성과 현황 버튼을 두었다. 브라우저 뒤로 가기와 앞으로 가기는 현황, 상세, 비교 표와 근거 창을 복원하고 현황 복귀 시 기존 스크롤 위치를 복원한다. 조회 조건은 같은 화면 세션에서 유지하며 새로고침 이후 복원은 구현 범위가 아니다. 과거의 성과 추이 복귀 버튼은 제거했다.

[최종 검증](../../evidence/ux-taxonomy-20261026/navigation-validation.md): 타입, 대상 파일 린트와 Vite 빌드 종료 코드 0, 교육 대시보드 검사 24개 통과. PC Chrome에서 캠페인 검색과 집행처 전체 선택, Meta Ads와 PC 조건의 CVR 상세, 비교 표, 운영 기록과 개별 근거, 브라우저 왕복과 현황 복귀를 직접 수행했다. 근거에서 현황 복귀 후 스크롤 669px와 필터가 유지됐다. 화면 조작 성공을 실제 마케터 이해도나 사용 시간의 증거로 보지 않는다. 모든 사례의 전수 조작과 전 경로 키보드 검증은 미실행이며 모바일은 사용자 요청으로 제외했다. 새 데이터, 스키마, 의존성, 버전과 원격 발행은 추가하지 않았다. 기존 데이터 감사 변경은 보존했다.


## 15. 브라우저 주석 19건 반영, 2026-10-26

사용자 주석에 따라 모든 주요 지표 상세의 핵심값을 제목 아래 왼쪽으로 옮기고 산식은 지표명 도움말, 반복 정의는 상단 오른쪽 집계 기준 펼침으로 이동했다. 증감 방향의 자명한 설명은 제거했다. 현황 복귀는 고정 헤더의 화살표 버튼으로 강조했고 비교 표 진입은 세부 수치와 운영 기록으로 바꿨다. ROAS 상세에는 실제 캠페인별 수치 표를 추가했다.

캠페인 비교는 공통 눈금의 가로 이중 막대와 우측 값, 증감 열로 정리했다. 표는 캠페인당 한 행에 현재값, 직전값과 증감을 두고 선택 지표의 일별 추이를 표 전체의 공통 눈금으로 비교한다. 현재 수치 순위와 변화량 순위를 구분하고 긴 표의 캠페인 이름 열은 고정한다. 퍼널은 두 기간의 단계별 도달 수와 이전 단계 대비 이탈 수, 이탈률을 시각화한다. 기기는 전역 조건의 역할을 유지하며 보조 펼침으로 분리했다. 캠페인 표시 이름은 기존 의미와 ID를 보존한 읽기 쉬운 이름으로 변경했다.

[주석별 반영과 실제 검증](../../evidence/ux-taxonomy-20261026/comment-revisions.md): 타입, 린트, 빌드와 기존 검사 24개 통과, PC 인앱 브라우저에서 7개 상세 화면과 정렬, 기기 전환, 퍼널과 현황 복귀를 확인했다. 사용자 이해도와 전 사례 UI 전수 검증, 모바일은 포함하지 않는다. 원천과 스키마, 새 의존성, 버전과 원격 발행은 추가하지 않았다.
