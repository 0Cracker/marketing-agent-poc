# 실제 LLM 도구 선택과 채팅 시각화 연결 · 2026-10-19

후속 CURRENT 통합본의 실제 모델·가상 승인·재시작 검증은 [최신 전체 흐름 기록](current-live-20261019.md)을 따른다. 아래 D007 선택·실행 안내와 수치는 당시 검토 결과다. 현재 서버는 sibling의 CURRENT manifest를 공통으로 읽는다.

사용자가 번호형 Gemini 키를 저장하고 Flash·Flash Lite·Gemma 4 중심 배치 및 계속 진행을 요청했다. 기존 미커밋 작업을 보존하고 실제 모델 도구 선택을 로컬 채팅에 연결했다. 원천·마케팅 명세·모의 예산 값·실제 Ads·Git 발행은 변경하지 않았다.

## 모델 배치와 키

| 업무 | 기본 모델 | 근거와 현재 한계 |
| --- | --- | --- |
| 분석 도구 선택 | `gemini-3.5-flash-lite` | 사용자 제공 한도 15 RPM / 250K TPM / 500 RPD. 실제 D007 시장·가격 분석을 통과했다 |
| 예산 도구 선택 | `gemini-3.8-flash` | 사용자 제공 한도 5 RPM / 250K TPM / 20 RPD. 실제 기존 시나리오 계산·현행 유지 결과를 확인했다 |
| 명시적 대체 선택 | `gemini-3.1-flash-lite` | 설정 허용. 이번 생성 점검은 미실행 |
| 실험용 선택 | `gemma-4-26b-a4b-it`, `gemma-4-31b-it` | 짧은 JSON 생성은 성공. 전체 도구 루프·응답 품질은 미검증이므로 기본 배치하지 않는다 |

한도 수치는 사용자가 제공한 AI Studio 표의 스냅샷이다. 서버가 최신 잔여량을 조회해 확정한 수치가 아니다. 한도는 프로젝트 기준으로 공유되며, 같은 프로젝트의 키 두 개가 요청 한도를 두 배로 만들지는 않는다. [Google 한도 문서](https://ai.google.dev/gemini-api/docs/rate-limits)

두 키의 모델 목록 인증은 각각 HTTP 200이었다. 두 키의 프로젝트 소속이 같은지는 API 응답만으로 확인하지 않았다. 기본은 번호 순 첫 번째 유효 키 한 개를 사용하며 자동 순환·자동 공급자 전환은 없다. `AGENT_KEY_NAME`으로 다른 키를 명시 선택할 수 있다. 키 값은 세션·모델 대화·로그·근거 파일·브라우저에 저장하지 않는다. 원본 `.env.local`은 Git 제외 상태를 유지한다.

`agent-runtime.mjs`는 모델별 요청 시작 간격을 공유한다. 같은 모델을 분석과 예산에 쓰면 동일 간격 관리기를 사용한다. 429는 기존 실행기의 `paused`로 남고 사용자가 기다린 뒤 재개한다. 이 간격 관리는 단일 프로세스의 RPM 완화 장치이며, TPM·일별 잔여량·다른 프로세스 사용량을 보장하는 한도 관리기가 아니다. 실제 공급자 한도 판단을 우선한다. Gemma 입력은 12,000자로 제한하지만 이는 토큰 수의 정확한 보장이 아니다.

## 실행

기존 오프라인 실행은 유지한다.

```powershell
node scripts/agent-server.mjs
```

실제 모델 모드는 서버 프로젝트의 `.env.local`을 읽는 명시적 실행으로 시작한다.

```powershell
node scripts/agent-server.mjs --live
```

기본 서버는 127.0.0.1:8788이다. 실제 모드는 `work/agent-flow-live.sqlite`, 오프라인 모드는 기존 `work/agent-flow.sqlite`를 사용한다. 브라우저 복원 키에도 모드를 붙여 서로 다른 모드의 실행을 혼합하지 않는다.

기존 서버를 중단하지 않기 위해 이번 검토는 다음 별도 포트로 열었다.

```powershell
# marketing-agent-poc
$env:AGENT_PORT='8790'
$env:AGENT_UI_ORIGINS='http://127.0.0.1:5175'
node scripts/agent-server.mjs --live
```

```powershell
# marketing-dashboard-drafts
$env:AGENT_API_PORT='8790'
node node_modules/vite/bin/vite.js --host 127.0.0.1 --port 5175 --strictPort
```

`http://127.0.0.1:5175/workbench`에서 데이터 **Agent 연결 표본 · D007** → 국가·월 선택 → Agent의 분석 탭을 연다. 현재 다른 배치의 자동 전환은 없다. 실제 모델 사용 중이라는 표시와 분석·예산 모델 이름을 확인할 수 있다. 실제 광고 집행은 계속 비활성이다.

필요한 경우 `.env.local`에 아래 선택값을 추가한다. 기존 키·설정은 덮어쓰지 않는다.

```dotenv
AGENT_KEY_NAME=GEMINI_API_KEY_1
AGENT_ANALYSIS_MODEL=gemini-3.5-flash-lite
AGENT_BUDGET_MODEL=gemini-3.8-flash
```

## 실제 호출에서 발견하고 고친 문제

짧은 JSON 연결 점검에서는 Flash Lite·Gemma 26B·Gemma 31B가 성공했다. Flash는 `thinkingLevel:minimal`을 거부했다. 이 모델은 low/medium/high를 지원하며 minimal은 지원하지 않는다는 [공식 문서](https://ai.google.dev/gemini-api/docs/models/gemini-3.8-flash)를 확인하고, 기본 설정 재점검 후 런타임에 모델별 low/minimal을 적용했다. Gemma 31B의 한 점검은 약 30초가 걸렸으며 일반적인 응답 속도 측정으로 확대하지 않는다.

최초 업무 호출에서는 최종 결과를 `finish` 밖에 반환했다. 그다음에는 조회에서 발급되지 않은 사실 ID, 일부 반대 근거 누락이 각각 검증에 걸렸다. 실패를 성공으로 바꾸거나 게이트를 완화하지 않았다. 기존의 도구/최종 응답 봉투 계약을 Gemini `responseJsonSchema`로 표현하고, 조회된 사실 ID만 선택하게 했다. 조회된 지지·반대 참조는 순서와 건수를 포함해 보존하도록 제한했다. 새 마케팅 스키마를 만들지 않았다. 기존 서버의 범위·의미·근거·계산·승인 검증은 유지했다.

마지막 [실제 흐름 결과](../../evidence/v0.2.0/agent-live-20261019/marketing-agent-live-flow-20261019-5.json)는 분석 3호출, 예산 3호출로 통과했다. 분석은 시장 비교·관계 조회를 선택하고 3개 사실을 반환했다. 예산은 기존 기준안 60.500000·후보안 61.538462를 재계산했으나 모델이 변경 승인을 요청하지 않고 `retained`로 끝냈다. 소스 지문은 전후 동일했고 실제 Ads 호출·신규 마케팅 원천은 0이다. 이 1회 결과는 자유 질문 전반의 품질을 입증하지 않는다.

앞선 실패 파일 1~4와 [모델 연결 점검](../../evidence/v0.2.0/agent-live-20261019/marketing-agent-model-check-20261019.json)을 그대로 보존했다. 첫 연결 보고서의 Flash 400은 [기본 설정 재점검](../../evidence/v0.2.0/agent-live-20261019/flash-default-settings-recheck.json)의 200과 구분한다. 자동 승인 검토 사용량 제한으로 거절된 최초 시도는 실행되지 않았다. 사용자 재개 요청 후 허용된 도구 호출로 이어 진행했다.

## 답변 화면

기존 결론·다음 행동·근거 링크 문구를 유지하면서 아래를 추가했다.

- 핵심 수치 카드와 수치별 원천 연결.
- 같은 기간 제품별 금액 점유율 막대그래프와 수치 대체 보기. 여러 기간의 중복 제품값을 단일 비교 막대로 그리지 않는다.
- 가격·재고·광고·계측 비교표. 미검토·미분류는 ‘영향 없음’이나 0건으로 표시하지 않는다.
- 원문 발췌·원천 경로·자료 시각·원문 위치를 읽는 근거 카드. 기술 상세는 접는다. 근거 선택 후 카드로 스크롤·포커스를 옮긴다.
- 기준안·후보안의 캠페인별 배분과 별도 예산 기간 표시.
- 최근 8개 선행 분석 요약 복원, 후속 분석 문맥 전달, 중단된 실행의 수동 재개.

현재 설명문은 **검증된 결과의 템플릿 표시**다. LLM이 도구를 선택하지만 임의의 자유 서술·차트 코드를 실행하게 하지 않는다. 사용자 요청에 맞는 모든 차트 종류와 상세 보고서 생성을 완성한 상태는 아니다. 이전 분석은 이력 요약이며 과거 예산 제안 전체를 채팅 타임라인으로 복원하지 않는다.
