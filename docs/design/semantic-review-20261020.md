# 대표 업무 사례 의미 검수

## 사용자 답변과 반영 · 2026-10-20

S1·S2 동의. S3 자료 조회 성공과 원인 판단 미완료 구별, S4 CURRENT 더미 확보시각 무시, S5 추가 설명 후 인터넷 근거를 가진 가상 공식 적용 요청, S6 기존 더미값 대표 선택으로 수정했다. 구현·새 수식·검증은 [의미 검수 반영](semantic-changes-20261020.md)을 따른다. 아래 pending·옛 수치는 답변 전 검수안의 이력이다. 이번 답변을 전체 필드의 사람 검수 완료로 집계하지 않는다.

2026-10-20 · 사용자 검수 대기. 아래는 기존 명세와 실제 가상 자료의 해석을 사람이 확인하기 위한 목록이다. 자동 시험 통과를 사람의 승인으로 기록하지 않는다.

각 항목에 ‘동의 / 수정 필요 / 추가 설명 필요’와 이유를 남긴다. 동의해도 데이터 생성·스키마 변경·85행 보류 해제·실제 광고 집행의 승인이 되지 않는다.

## S1 · 시장 비교의 분모

흐름: `제품 P1A의 판매 관측 → 같은 국가·기간의 시장 분모 → 금액 점유율`.

실제 사례: 일본 2026년8월, P1A 판매액1,483,235 JPY / 원천 시장분모39,055,434 JPY, 표시 약3.80%. 원천 D008-T03-00277. 가상·부분 표본의 원천 정의를 벗어나 실제 일본 전체 시장을 입증한 수치로 확장하지 않는다. 6제품 합계를 분모로 바꾸면 다른 지표가 된다.

컨펌할 의미: **비교에는 같은 국가·기간·정의·분모를 사용하고, 가상 자료의 적용 범위를 표시한다.**

## S2 · 원문과 가격 원인 후보

흐름: `리뷰 D008-T24-00561 → 발췌 D008-T25-01121 → 가격 원인 후보를 지지하는 해석`.

실제 발췌: “가격이 부담스러웠습니다”, Unicode offset12~24. 현재 도구는 지지8건·반대8건을 반환했으며 각 방향의 최대8건으로 제한한 조회다. 의견 전체의 비율·신뢰도·영향 크기가 아니다. 원래 주석의 사람 검토나 실시간 LLM 감성 추출을 완료했다는 의미도 아니다.

컨펌할 의미: **가격 불만은 조사할 근거이며 매출 하락의 인과를 입증하지 않는다. 반대 근거도 함께 보인다.**

## S3 · 재고 관측과 미분류

흐름: `특정 시점의 재고 관측 → 제품/위치 관계 조회 → 원인 평가의 분류 여부`.

현재 재고 관계는 조회할 수 있지만 지지·반대 원인 분류가 안 된 결과가 있다. 빈 분류 배열을 ‘지지0·반대0이므로 영향 없음’으로 읽으면 안 된다. 재고 snapshot을 합산하거나 한 시점의0으로 품절 지속기간을 만들지 않는다.

컨펌할 의미: **조회했지만 원인으로 분류하지 못한 상태, 실제 수치0, 자료 없음은 서로 다르다.**

## S4 · 측정 기간과 알 수 있었던 시점

흐름: `2026년8월 측정 기간 → 2026-10-19 자료 확보 → 해당 시각 이후의 회고 분석`.

CURRENT의 source_created_at은2026-10-19T05:06:31.333Z다. 8월 자료라고 해서 8월 말에 이미 알고 있었던 정보로 자동 취급하지 않는다. 확보시각 이전 기준으로 요청하면 가용 자료가 부족할 수 있다.

컨펌할 의미: **측정 기간과 자료 확보시각을 분리하고, 당시 알 수 없던 값을 과거 의사결정에 섞지 않는다.**

## S5 · 예산 모형과 승인

흐름: `기준/후보 배분 → 기존 가상 모형 계산 → 사용자 가상 승인 → 후속 분석 시 무효화`.

실제 사례: 총1,500,000 JPY. 기준search525,000/social975,000, 후보각750,000. 가상 전환수60.500000→61.538462. 예산 기간은2026-08-03 이상31일 미만이며 분석 월간 범위와 구별한다. 새로 학습한 실제 효과가 아니라 기존 가상 포화 함수의 결과다.

컨펌할 의미: **모의 수치 개선은 실제 성과 보장이 아니며, 가상 승인은 실제 집행이 아니다. 분석·제안이 바뀌면 재승인한다.**

## S6 · 사이트 성능 충돌

흐름: `같은 국가·페이지·기기·기간 → 서로 다른 p75 값 → 미확정 보류`.

T37 성능85행은12개 업무 키에 충돌한다. 활성23행은 전부 장애 사건이다. 성능 자료가 빠졌다는 이유로LCP0·정상·장애 없음으로 표시하지 않는다. 조사 기록은 sibling의 `docs/design/site-performance-conflicts-20261020.md`다.

컨펌할 의미: **측정 구분 근거가 없는 충돌값은 임의 선택·평균 없이 보류하고, 성능 미확정과 장애 사건을 구분한다.**

## 기록과 후속 조치

현재 S1~S6의 사람 검수 상태는 모두pending이다. 사용자 답변 이후 항목별 의견·확인 시각·수정 요청을 별도 기록한다. 이 검수는 대표 해석6건이며345필드 전체의 사람 검토로 집계하지 않는다. 수정 요청이 명세·신규값 변경을 요구하면 구체적인 별도 변경안을 먼저 제시한다.
