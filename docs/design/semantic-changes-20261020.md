# 사용자 의미 검수 반영 · 2026-10-20

사용자가 더미 자료 확보시각을 무시하고 사이트 성능 대표값을 선택하며, 인터넷에서 적합한 전환수 공식을 찾아 가상 모형으로 적용하도록 요청했다. 문서 갱신과 커밋도 명시했다. 실제 자료 연결·학습·광고 집행은 범위에 없다.

## 예산: Hill 포화 모형

[Google Meridian 공식 설명](https://developers.google.com/meridian/docs/advanced-modeling/media-saturation-lagging)의 Hill 일반형 `x^s / (ec^s + x^s)`에서 `s=1`을 선택하고 채널별 최대 반응을 곱했다.

`예상 전환수 = Σ채널 최대반응 × 채널총예산 / (반포화예산 + 채널총예산)`

| 가상 계수 | 검색 | 소셜 |
| --- | ---: | ---: |
| 기간 내 최대 전환수 | 60 | 40 |
| 반포화 예산 | 기준 총예산의 20% | 기준 총예산의 10% |

기준 총예산은 KR 15,000,000 KRW / JP 1,500,000 JPY / US 15,000 USD다. 반포화 예산은 채널 반응이 최대값의 절반이 되는 예산이다. 계수는 시연용 설정이며 인터넷이나 실제 데이터에서 추정한 값이 아니다. 국가별 통화 규모를 정규화했으므로 같은 배분 비율이면 같은 모의 전환수가 나온다. 실제 효율의 우열·인과 효과·최적 배분을 주장하지 않는다. 시계열 학습과 Adstock은 추가하지 않았다.

일본 대표 예: 검색525,000/소셜975,000 JPY 기준안 **72.848485** → 각750,000 JPY 후보안 **76.190476**. 같은 채널의 캠페인 예산은 먼저 합산해 최대 반응을 중복 계산하지 않는다. 과거 global 계수 모형은 캠페인별 계산을 유지하므로 새 모형과 직접 성과 비교하지 않는다.

기존 함수도 Hill의 `s=1` 형태였다. 핵심 변경은 출처·계수 의미의 명시, 다른 채널 계수, 채널 단위 합산이다. CURRENT T39 모형36행·시나리오36행을 결정적으로 투영하고 저장 예상값·모형 버전도 갱신했다. 원본 D008 source/archive는 보존하고 migration/provenance에 변환을 기록했다. 화면에는 ‘예상 전환수 · 가상 모형’, 수식·계수·가정을 표시한다.

## 자료 상태·확보시각·사이트 성능

- 재고 조회 성공·원인 지지/반대 분류 미구현은 **자료 확인됨 · 원인 판단 미완료**로 표시한다. 자료 없음·출처 검증 실패·요청 실패와 구별하며 기존 실패 시험을 유지한다.
- CURRENT 가상 자료는 `available_at`으로 조회를 막지 않는다. 측정기간·관측일·국가·제품·자료 해시는 유지한다. 과거 배치의 확보시각 계약은 보존한다.
- P1A는 가상 자사 제품A의 내부 식별자다. 시장 분모와 가격 반대 근거의 의미는 유지한다.
