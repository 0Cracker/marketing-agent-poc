보류 85행은 T37 `performance`의 국가·페이지·기기·기간이 겹치지만 다른 LCP 값을 가진다. 표본 식별자가 없어 한 행을 임의 선택하거나 평균내지 않았다. 모든 충돌 행을 `data/archive/pending.json`에 남겼다. 사이트 장애 사건은 별도 키로 유지하며 화면에 보류 수량을 표시한다. 리뷰 560/730/1,120개, 구매 확인 null, 한국어 본문과 규칙 주석의 의미는 유지했다.

41유형의 실제 파일 매핑은 `data/manifest.json`, 업무 키의 공통 차원·유형별 필드는 `data/archive/business-keys.json`에 있다. 국가·시나리오를 업무 키에 포함한다. D007→D008 대체는 생성 규칙의 시나리오 대체이며 같은 관측이라는 선언이 아니다. 원형 순번을 보존한 유형만 레코드 대응 ID를 기록하고, 재구축된 유형은 일대일 대응을 만들지 않았다.

원본 131파일과 public 카탈로그·고정 회귀 복사본·기존 TS 시연 파일을 전수 목록화하고 해시로 보존했다. `data/archive/source-inventory.json`은 물리적 복사본과 원본을 구별한다. 같은 내용의 보관 파일은 내용 해시로 공유하며 새 관측으로 세지 않는다. `migration-map.jsonl`은 모든 원본 행의 판정, `provenance.jsonl`은 활성 ID·원본 파일/행·해시·변환 근거를 연결한다. 원본 저장소와 public 보존본을 이동·삭제하지 않았다.

## 조회·배포

화면과 sibling Agent는 같은 `data/manifest.json` 및 SHA-256 검증된 유형 파일을 읽는다. 현재 논리 데이터셋은 `CURRENT`다. 레코드의 원래 ID·scope·금액·시각·출처는 그대로이며, manifest의 scope 매핑을 통해 국가 범위를 검사한다. 사용자가 D007/D008을 고르는 UI와 런타임 배치별 조회 로더를 제거했다. 과거 자료는 관리용 archive와 고정 회귀 검사에서만 접근한다.

`scripts/current-data.mjs`의 Vite 플러그인은 명시한 현재 가상 자료만 `/workbench-data/current/`로 제공하고 빌드에 복사한다. `publicDir:false`로 옛 카탈로그의 중복 배포를 차단했다. archive·migration·provenance·db·drizzle 및 임의의 새 파일은 공개하지 않는다. 기존 폰트·라이선스·아이콘은 유지했다. 개발 서버는 요청 시 manifest를 다시 검사하므로 파일 목록 갱신이 반영된다.

프론트는 제품 정의·시장 자료·캠페인과 제품 표시 정보로 시작하고 유형을 열 때 필요한 자료만 가져온다. 리뷰 주석에는 실제 원문 리뷰를 함께 읽는다. 동일 유형의 진행 중 요청과 완료 자료를 공유하고 실패한 요청은 재시도할 수 있다. 사용하지 않는 전체 정의 파일은 내려받지 않는다. 초기 자료는 **611,139바이트**이며 전체 활성 JSONL은 39,231,166바이트다. 41유형을 모두 열었을 때도 파일당 한 번만 요청하는지와 전체 적재 방식의 지표·근거 ID 일치를 검사했다. 이는 전송 파일 바이트이며 브라우저 메모리나 지연시간의 상한을 뜻하지 않는다.

Agent 세션은 자료 계약·해시를 제공하고 화면과 다르면 요청을 보류한다. 이전 해시로 저장된 실행은 `inputs_changed`로 명시적으로 만료된다. 같은 자료에서는 원래 실행 ID로 복원한다. 전체 기간은 manifest의 2024-10-01–2026-10-01 범위를 사용한다. 오프라인 분석의 최종 사실 선택은 기존 100개 제한을 유지하며, 조회 도구는 전체 기간 사실을 검사한다. 실제 LLM 호출·광고 집행은 이번 검증에 포함하지 않는다.

## 다시 실행하기

저장소 루트에서 `node scripts/consolidate-data.mjs`는 보존된 기존 입력의 대사를 재현한다. 이 스크립트는 과거 입력을 다시 읽는 이행 도구이며 새 업무 데이터 추가용 생성기가 아니다. 현재 자료를 수동 수정한 뒤 실행하면 통합 결과를 다시 작성하므로 먼저 변경을 보존한다.

`node scripts/verify-consolidation.mjs`는 통합·기존 회귀·타입·린트·빌드를 실행하고 이 폴더에 결과를 쓴다. sibling의 `node scripts/check-agent-tdd.mjs --output 새_보고서.json`은 Agent 회귀를 실행한다.

실행 시 sibling에서 `AGENT_PORT=8792`, `AGENT_UI_ORIGINS=http://127.0.0.1:5176`으로 `node scripts/agent-server.mjs`, 화면 저장소에서 `AGENT_API_PORT=8792`로 Vite를 실행하면 된다. 환경 변수는 PowerShell의 `$env:이름='값'`으로 설정한다. 기본 포트는 각각 8788과 화면 개발 포트다. `MARKETING_DATA_DIR`로 통합 data/ 경로를 지정할 수도 있다.
