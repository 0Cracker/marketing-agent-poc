# 일별 추세와 국가 비교 · 2026-10-20

## 주석 후속 · 문의 가독성·데이터 의미·보유 기간

사용자가 누적 막대의 시각적 피로와 문의 주제 페이지 분할을 지적했다. 일별 문의는 전체 접수량 한 계열로 단순화하고, 다섯 문의 주제는 한 카드에 모두 표시했다. 앞선 Recharts 예제는 구현 근거였으며 실제 운영 화면의 선택을 입증하지 못했다. 이번에는 [Intercom 공식 차트 안내](https://www.intercom.com/help/en/articles/8870221-custom-report-chart-types-and-options)의 시간 추세에는 선, 범주 비교에는 가로 막대라는 용도에 맞췄다. 특정 서비스 화면을 그대로 복제한 것은 아니다.

T10의 B1·B2·B3는 실제 업체가 아닌 가상 자사·경쟁사 브랜드다. 축 이름과 설명을 명시하고, 비교값이 공개 광고 표본 수라는 점을 표시했다. T33은 산출식·기준연도가 없는 시연용 임의 지수이므로 ‘가상 시장 배경 지수’로 바꾸고 실제 경제·시장 통계로 해석할 수 없음을 표시했다. 원천의 날짜 선언을 우선하도록 추세 날짜를 수정해 T33의 발행일이 측정월보다 한 달 늦게 보이던 문제도 바로잡았다.

현재 연결된 41개 유형·30,327행을 전수 집계해 [국가별 보유 기간·단위·질문 범위](current-data-coverage.md)를 작성했다. 월별·일별 혼합 자료, 4개월 조사, 2개월 검색 관심, 격월 경매 경쟁, 정의 유효기간과 예정 기간을 구분했다. 리뷰 주석은 연결 리뷰의 날짜를 따른다. 신규 원천·수치·스키마 변경은 없다. [검증 결과](../../evidence/dashboard-trends-20261020/feedback-checks.json)와 feedback 접두 로그·브라우저 캡처를 보존했다. 아래 누적 막대 설명은 최초 변경 이력이며 이번 후속으로 대체했다.

시작은 깨끗한 main `7e93f84`, 작업 브랜치는 `feature/dashboard-trends`다. 사용자는 3개국의 제품별 주문 수량·매출 흐름을 다르게 조정하고, 문의 차트와 국가 비교 그래프를 개선하도록 요청했다. 신규 버전은 정하지 않았다. 작업 중 별도로 발생한 온톨로지 설치 경로·검증 문서 변경은 이번 작업과 구분한다.

## 선택과 재현

문의는 날짜별 주제 구성을 누적 막대로 표시한다. 해당 접수일의 없는 주제는 0건이며, 원천에 없는 날짜까지 0건으로 채우지는 않는다. [Recharts 공식 예제](https://recharts.github.io/en-US/examples/StackedBarChart/)를 참고해 기존 라이브러리를 사용했다. 국가 비교에는 동일 단위의 막대그래프와 기존 상세 표를 제공한다. 판매 수량·주문 수·문의 해결률·평균 별점 등을 비교하며 현지 통화를 한 축에 섞지 않는다. 나머지 유형의 기본 비교는 관측 표본 수이므로 시장 규모로 해석하지 않는다.

보존 원본을 기준으로 3개국 × 자사 제품 A·B에 서로 다른 5개 추세 기준점과 고정 해시 변동을 적용해 일별 합계와 행별 정수 수량을 조정했다. 선을 부드럽게 그려 값을 숨기지 않고 원천을 수정했다. 일본에서는 8월 12~17일 주문이 18일에 몰린 분포도 발견해 기존 주문행 번호에 따른 날짜로 분산했다. 해당 주문의 환불·배송 시각은 같은 일수만큼 옮겨 선후관계를 유지했다.

주문 1,712행 중 실제 값이 변경된 행은 1,501개, 환불 시각 9행, 배송 시각 72행, 고객군 순매출 204행이다. 할인·세금은 기존 수량당 비율로, 주문행 금액과 고객군 순매출은 연결 원천으로 재계산했다. 신규 행·ID·스키마 변경은 0이다. source/archive를 유지하고 CURRENT provenance·migration 해시와 manifest를 갱신했다. `node scripts/update-demo-order-flow.mjs`는 보존 원본에서 같은 값을 재현한다. 전체 통합 스크립트에도 같은 투영 함수를 연결했다.

## 기간과 한계

주문·환불·문의 상세는 2026년 8월만 있다. 월별 판매 요약은 2024년 10월~2026년 9월 자료이며, 상세 화면에 기간 안내와 전체 기간 판매 요약 이동 버튼을 추가했다. 다른 달의 주문 상세는 생성하지 않았다. 월별 요약은 기존 `no_detail` 자료이므로 주문 표본과 일치하는 원장으로 주장하지 않는다. 변경값은 모두 가상 시연값이다.
