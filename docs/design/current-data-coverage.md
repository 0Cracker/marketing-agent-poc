- T18 구매 단계의 조회·장바구니·결제 시작·구매는 8월 3~30일이다. 9월 1일까지 이어지는 것은 환불 이벤트이며, 9월 구매 데이터가 있다는 뜻이 아니다.
- T04·T32는 4개월 조사 구간 6개, T05·T06은 2개월 구간 12개다. 기간이 겹치는 달에 조회되더라도 해당 월 단독으로 측정한 값은 아니다.
- T27은 관측일 기준 누적 조회수다. 일별 신규 조회수나 콘텐츠 발행일 기준 집계와 구분한다. T23 배송 범위는 화면 필터와 같은 배송 약속일 기준이며 출고·도착일 범위와 다르다.

## Agent 질문에 적용하는 방법

- 월별 자료는 해당 집계 단위로 묻는다. 예: “일본의 2025년 8월과 2026년 8월 자사 순판매액을 비교해 줘.” 월별 합계를 일별 성과로 분해할 수는 없다.
- 8월 상세는 실제 날짜와 제품을 지정한다. 예: “미국의 2026년 8월 제품 A·B 주문 수량과 문의 주제를 비교해 줘.” 표에 없는 7월 주문 상세는 답할 근거가 없다.
- 여러 자료를 결합할 때는 기간 교집합·국가·제품·통화·집계 정의를 먼저 확인한다. 월별 판매 요약은 no_detail 자료이며 주문 표본과 일치하는 원장이 아니다.
- T05 검색 관심은 동일 정규화 범위 안에서만 비교한다. T10은 가상 광고 표본 수이며 실제 경쟁사의 광고비·전환·매출은 알 수 없다. T33은 산출식·기준연도 없는 시연 지수이며 경제·시장 성장률을 설명하지 못한다.
- 제품·식별자·소재 유효기간, 캠페인 설정 기간, 협업 예정 기간, 수집 예정 기간, 모형·정책 기간은 실제 성과 시계열과 구분한다. 모형·예산안은 실제 예측 성능·인과 효과·집행 결과를 입증하지 않는다.
- 위 질문은 **자료상 가능한 조회 예시**다. 모든 자연어 질문의 Agent 성공을 보증하지 않는다. 화면에서 국가·기간을 먼저 선택하고 질문하는 것이 현재 지원 범위를 명확히 한다.

[기계 판독 상세](../../evidence/dashboard-trends-20261020/data-coverage.json)는 유형·국가·세부 종류·날짜 필드·개별 기간 목록을 담는다. 재생성: `node scripts/report-data-coverage.mjs`. 원천 수치·스키마는 변경하지 않는다.
