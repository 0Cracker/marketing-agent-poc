# 분석·예산 에이전트의 로컬 화면 연결 · 2026-10-19

대시보드의 국가·제품·월·자료 기준시각을 HTTP 요청으로 연결했다. 사용자는 분석의 사실·반대 근거를 확인한 뒤 예산 검토를 선택하고, 기존 가상 시나리오를 수정·재계산·승인할 수 있다. 외부 LLM과 실제 Ads는 연결하지 않았다.

## 실행과 경계

두 터미널에서 실행한다. 새 패키지는 설치하지 않는다.

```powershell
# marketing-agent-poc
node scripts/agent-server.mjs
# marketing-dashboard-drafts
node node_modules/vite/bin/vite.js --host 127.0.0.1 --port 5173 --strictPort
```

`http://127.0.0.1:5173/workbench` → D007 → Agent → 분석. Vite가 `/agent-api`를 포트8788로 전달한다. 포트를 변경하면 `AGENT_PORT`, 화면 출처를 변경하면 `AGENT_UI_ORIGINS`와 Vite proxy를 함께 맞춘다. 로컬 개발용이며 공개 배포 설정·사용자 로그인·여러 사용자 권한은 포함하지 않는다.

분석 서버는 기존 D007 카탈로그만 읽고 업무 실행 상태만 Git 제외 경로 `work/agent-flow.sqlite`에 저장한다. 화면은 국가·제품·반개방 월 기간·asOf·지표 이름·선택 근거 ID만 보낸다. 원천 행을 요청에 포함하지 않는다. 화면 범위 밖 근거 ID는 서버가 제외한다. D007 이외 배치, 전체 국가, 미지정 월은 명시적으로 범위를 선택해야 한다.

## 요청과 상태

| 요청 | 동작 |
| --- | --- |
| `GET /agent-api/session` | 오프라인 모드·실제 집행 비활성·프로세스 한정 토큰 |
| `POST /agent-api/analysis` | 신규/후속 분석; 후속 분석은 이전 분석에 연결된 제안·승인 무효화 |
| `POST /agent-api/budget` | 사용자의 명시 선택과 분석 버전 검사 후 인계 |
| `GET /agent-api/runs/:id` | 공개 실행 상태 복원; 내부 모델 대화·발급 자료 집합 제외 |
| `GET /agent-api/runs/:id/budget-inputs` | 같은 범위의 기존 가상 후보·가정 모형 |
| `POST /agent-api/runs/:id/evidence` | 해당 실행이 조회했던 근거만 원문 확인 |
| `POST /agent-api/runs/:id/approve`, `reject`, `revise` | 서버의 가상 승인자·버전 검사; 수정은 새 제안 ID와 재승인 대기 생성 |
| `POST /agent-api/runs/:id/resume`, `cancel` | 기존 실행기의 재개·취소 연결; 현재 화면에는 별도 조작 미노출 |

실제 모델 공급자·키·승인자·파일 경로·임의 도구 입력은 허용하지 않는다. 제출·대사 라우트도 없다. 서버가 30분 승인 만료시각과 가상 승인자를 지정한다. Host·Origin 허용 목록, 메모리에 둔 토큰, JSON 크기·필드 허용 목록을 검사한다. 이 장치는 로컬 개발의 웹 출처 간 오용을 줄이기 위한 것이며 다중 사용자 인증을 대신하지 않는다.

브라우저에는 실행 ID만 저장한다. 복원 키는 국가·제품·기간·asOf·선택 근거 ID를 포함해 다른 범위의 결과를 가져오지 않는다. 서버 재시작으로 토큰이 바뀌면 변경 전 거절인 `csrf_denied`에 한해서 한 번 갱신한다. 변경 요청의 응답이 유실되면 자동 재전송하지 않는다. 최초 생성 응답이 유실돼 ID를 모르는 실행의 자동 탐색은 아직 제공하지 않는다.

## 한계와 다음 단계

현재 질문은 저장·후속 연결되지만 자연어 이해는 검증하지 않는다. 선택한 원인에 따라 모델 대역이 정해진 도구 순서를 수행한다. 관계는 원인 후보를 좁히고 지지·반대 근거를 추적하는 데 사용하며 인과 입증으로 표시하지 않는다. 분석 권고는 추가 조사이고 예산 검토는 별도 사용자 선택이다.

이후에는 허용할 자료·모델·전송 범위를 확정한 뒤 실제 LLM의 자유 질문/범위 확인·보류 품질을 평가한다. 원천·명세·새 가상값·패키지·Git 발행은 이번 작업에서 변경하지 않았다.
