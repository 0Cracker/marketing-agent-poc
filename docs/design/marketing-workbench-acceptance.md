## 원문과 기존 작업 보존

확정 명세는 사용자 첨부 파일을 바이트 그대로 복사했다. SHA-256은 `891eac80d6be827a20ba229877db7ac5d578bd01edc13cfe8dd71c260335126a`다. 원문의 마지막 계획 모드 문장도 역사적 원문으로 유지했다. 이번 구현 결과는 이 문서에 따로 기록한다.

초기 변경은 `data-proposal.md`·`work-log.md`의 기존 추가 기록 22행과 미추적 `docs/design/`이었다. 기존 기록·초안·원본 checkout을 보존했다. 패키지·잠금 파일은 변경하지 않았으며, 별도 설치한 의존성은 기존 잠금 파일을 사용했다. 가상 원천 생성·수정·감성 분류·예측·승인 이력 생성은 수행하지 않았다.

## 실행 검증과 제한

- `node scripts/check-workbench.mjs`: 통과. 11파일·1,652건·40유형·12개 국가/월 조합 및 결측·수집률·기간·계산식 검사.
- `node --experimental-strip-types tests/marketing.test.ts`, `tests/demo.test.ts`: 기존 CTI 회귀 검사 모두 통과.
- `node node_modules/typescript/bin/tsc --noEmit --incremental false`: 통과.
- `node node_modules/eslint/bin/eslint.js frontend/workbench frontend/src/main.tsx scripts/workbench-map.mjs scripts/check-workbench.mjs`: 통과. 기존 커스텀 Vite 경로에 대한 Next의 pages 디렉터리 안내는 남음.
- `node node_modules/vite/bin/vite.js build`: 통과. 원천 JSONL과 전체 필드 매핑을 포함하는 워크벤치 청크에 500KB 크기 경고가 남음. CTI와 워크벤치는 별도 lazy route 청크로 분리.
- 실제 API·DB·LLM·광고 집행과 미생성 30유형의 데이터 기반 동작은 이번 범위에 없음. 접근성은 명시한 키보드 경로와 의미 구조를 검증했으며 전체 스크린리더 인증을 의미하지 않음.

정적 빌드 미리보기 `http://127.0.0.1:5175`에서도 `/workbench`의 지표·두 차트와 420px 패널을 확인했다. 기존 `/`의 CTI 성과 대시보드가 로드되며 브라우저 오류가 없음을 확인했다. 관련 캡처는 `production-workbench.jpg`·`production-cti-regression.jpg`다.

## 발견한 충돌·누락

1. 저장소 AGENTS.md·기록 Skill이 참조하는 `docs/agent-contract.md`와 `docs/scenario-playbook.md`는 현재 트리에 없다. 이번 확정 명세와 현재 앱·테스트를 기준으로 분리 구현했으며, 누락 문서를 임의로 복원하거나 계약 내용을 추정하지 않았다.
2. Iteration 인덱스의 v0.2.0은 온톨로지 검증 진행 중이며 v0.3.0은 아직 시작하지 않은 목표로 기재되어 있다. 이번 화면 구현을 임의의 발행 버전·새 Iteration으로 확정하지 않았다. 이 검증 문서와 기존 작업 기록에 실제 작업만 남겼다.
3. 기존 의존성의 junction 내부 대상이 이전 폴더를 가리켰다. 원본 의존성을 수정하지 않고 해당 워크트리에 기존 잠금 파일 그대로 설치했다.
4. manifest LF와 checkout CRLF 차이는 메모리에서만 정규화해 검산했다. 원천 파일의 줄바꿈은 수정하지 않았다.

확정 계획을 변경해야 하는 충돌은 발견하지 못했다. 위 누락·환경 차이는 계획을 수정하지 않고 처리했다.
