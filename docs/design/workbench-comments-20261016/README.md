## 후속 피드백 — 원 내부 표기·강조·호버·별점 색상

원 내부에 점수·비율을 표시하고, 가장 많은 3점(50%) 조각을 반지름 방향으로 7만큼 분리했다. 최다 값이 같으면 표시 순서의 첫 조각 하나만 강조한다. 옆 건수 목록은 제거하고 오른쪽 아래에 5–1점 색상 범례만 둔다. 조각에 마우스를 올리거나 키보드 포커스를 주면 별점·건수·자사 전체 표본 대비 비율을 표시한다. Enter·Space·클릭으로 기존 원천 근거를 연다. 0건 별점은 범례에 남기고 원 조각은 만들지 않는다.

[ColorBrewer](https://colorbrewer2.org/)의 보라–주황 대비 구성을 참고해 기존 대시보드의 보라색·코랄 톤에 맞춘 별도 팔레트를 적용했다. 원본 팔레트를 그대로 복제한 것은 아니다. 5점 #7762B8 / 4점 #A697D2 / 3점 #D5D0E4 / 2점 #EDB78D / 1점 #D78269. 제품별 막대·원그래프·범례는 같은 매핑을 공유한다. 별점 색을 감성 분류로 해석하지 않는다.

기존 CSS 원그래프를 SVG 조각으로 바꾸고 더 이상 사용하지 않는 원·목록 CSS를 제거했다. 의존성 추가와 원천 변경은 없다. ESLint의 렌더 내 변수 변경 지적을 받아 조각 시작 각도를 이전 건수 합에서 직접 계산하도록 수정했다. 타입 검사·ESLint·수치 검사·빌드 결과를 확인했다. 기존 청크 크기 경고는 유지한다.

Spectrum의 관계 기반 색상 체계·텍스트 대비·색 외 라벨 보완, Carbon의 일관된 시각화 팔레트를 참고했다. 브랜드를 모든 색으로 반복하기보다 기준 보라색과 제한된 보조색을 쓰는 방식으로 이 화면에 적용했다. Adobe/IBM의 공식 토큰을 그대로 쓴다는 뜻은 아니다.

기존의 보라·옅은 회색·주황 조합을 폐기했다. 별점 색은 OKLCH 명도 72–80%, 채도 0.07–0.12 범위에 맞추고 5→1점을 퍼플 295 / 블루퍼플 285 / 라벤더 305 / 로즈 340 / 로즈 350 색상각으로 구성했다. 4–5점과 1–2점은 색상각으로 구분하고 내부 라벨은 어두운 중성색을 쓴다. 정확한 값은 `frontend/workbench/review-profile.tsx`의 공유 매핑에 있다. 제품별 막대·원·범례에 같은 색을 적용했다. 자사 브랜드 주색·광고비는 #8666BD, 비교 계열은 명도와 채도가 비슷한 블루·로즈·틸로 정리했다. 품질 경고·누락의 의미색은 유지한다.
