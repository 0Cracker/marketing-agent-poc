# 두 에이전트 B 흐름의 TDD 구현

범위: 분석·예산 역할의 제한된 도구 루프, 공통 자료/출력 검증, 버전 있는 인계, SQLite 승인 대기·재개, 모의 집행·대사. 실제 LLM·광고 연결·화면 변경·신규 마케팅 데이터 생성은 포함하지 않는다. 공급자 연결 코드는 별도로 검증하고 실제 전송 없이 테스트한다.

승인된 D007 및 기존 공통 카탈로그를 읽기 전용으로 재사용한다. 테스트의 질문·잘못된 인자·모델 제어 응답·장애 주입은 실행 조건이며 기존 원천을 바꾼 새 마케팅 레코드가 아니다. 신규 원천/보완값은 0행이다. 데이터 명세·OWL·SHACL·생성기는 수정하지 않는다.

## 구현 원칙과 검증 방식

시험 ID로 답변을 선택하지 않는다. 모델은 허용 도구를 선택하고 서버는 실제 카탈로그를 조회한다. 사실은 조회가 발급한 사실 ID로만 출력하며, 수치·원문·관계 근거를 검증한 뒤 보고서를 구성한다. 관계와 감성 주석은 원인 후보 탐색 자료이며 인과 증명으로 쓰지 않는다.

가상 T39 모형·예산 후보·T40 정책만 선택해 계산한다. 새 탄력성·예산 값을 만들지 않는다. 가정 변경 시험도 기존 다른 모형을 선택해 현행과 대안을 함께 재계산한다. 계산은 정확한 정수/유리수로 수행하고 표시 때 반올림한다. 원천의 사전 계산 expected 값은 정답으로 복사하지 않는다.

운영 흐름은 고정 관문 + 역할 내부 탐색으로 구현한다. 현재 카탈로그가 Node에 있으므로 우선 동일 런타임·표준 라이브러리로 업무 도구/상태/테스트를 연결한다. B안 선택과 특정 Python 프레임워크 채택은 구분한다. 이후 하네스를 바꿔도 이 업무 계약과 검증을 유지한다.

Node 기본 테스트 러너로 RED→GREEN을 기록한다. 원천 숫자는 파일을 별도로 다시 읽어 계산 대조한다. SQLite는 재시작·동시 제출·버전 충돌을 실제 파일로 검증한다. 모의 집행 성공은 실제 Ads 성공으로 표시하지 않는다.

실행: `node --test --test-concurrency=1 tests/agents/*.test.mjs` (저장소 루트).

## RED → GREEN 결과

2026-10-18, 시작 HEAD `d0f6267`, Node 24.19.0에서 구현했다. [최종 통합 결과](../../evidence/v0.2.0/agents-tdd/result-2.json)는 **98 pass / 0 fail / 0 skipped / 0 cancelled**다. 기존 `marketing.test.ts`, `demo.test.ts`, D007 카탈로그 조회 회귀도 모두 통과했다. 원천·manifest·공통 스키마·OWL/SHACL 102파일의 실행 전후 hash가 일치했다. 새 원천 0행, 외부 LLM/실제 Ads 호출 0회다.

처음에는 구현 모듈 부재로 RED를 확인했다. 이후 [경계 RED](../../evidence/v0.2.0/agents-tdd/red-boundaries.txt)는 20시험 중10실패를 실제로 기록했다. 반대 가설 전체 삭제, 임의 지지 근거 분류, 가격 focus 무시, 대체된 분석 재사용, 승인 본문 hash 누락, 만료 뒤 승인 참조 잔존 등이 드러났다. 검증 관문과 재개 전이를 수정했으며 실패 로그를 보존했다. 신규 도구·모델 연결·온톨로지 타입·품질 장애·충돌 표시도 각각 RED 후 구현했다.

기존 품절 0값이 일본에 있는데 초기 시험 범위를 한국으로 고정한 테스트 오류도 발견했다. 0값을 새로 만들지 않고 기존 0관측의 국가·표본을 읽어 범위를 선택하도록 시험을 수정했다. 월 중간 범위는 빈 결과로 보류하기 전에 기간 비교 불가로 판정하도록 관문 순서도 고쳤다.

## 구현 결정과 검증 경계

B 흐름은 사용자 확정이다. 현재 공통 카탈로그가 Node에 있으므로 실행기를 Node 표준 라이브러리로 연결한 것은 이번 구현 판단이다. 기존 Python 검산·RDF 검증 자산은 보존했다. LangGraph·ADK를 추가하지 않았으며, 하네스 교체가 필요하면 동일한 도구·관문·회귀를 유지한다. [결정 기록](../decisions/decision-002.md)을 따른다.

관계 조회는 실제 ontology.ttl에 선언된 predicate를 사용하는 타입 있는 투영이며 새 영구 RDF 저장소나 추론기를 구현한 것이 아니다. 지지/반대 후보는 해석으로 표시하고 온톨로지에 인과 관계를 기록하지 않는다. 계산 baseline은 기존 가상 시나리오이며 실제 계정 현행을 확인했다고 표시하지 않는다.

외부 모델 연결부는 HTTP 대역으로 형식·오류·전송 허용 경계만 검증했다. 실제 모델의 한국어 질문 이해·탐색 품질·호출 한도·응답 품질은 미검증이다. UI/HTTP 서버·다중 사용자 인증·분산 워커·실제 Ads 연결은 구현하지 않았다. 승인 principal은 신뢰할 수 있는 서버 호출자라는 전제다. 라이브 모델/매체를 연결해야 이번 오프라인 흐름 시험이 완료되는 것은 아니다.

기존 52정형시험/OWL/SHACL 전체 회귀는 이번에 재실행하지 않았다. 변경하지 않은 기존 시스템의 통합 pass 근거는 2026-10-17 보고서이며, 이번 신규 검증은 98시험·기존 앱2시험·카탈로그 조회·입력 보존에 한정한다. Git 스테이징·커밋·원격 발행은 수행하지 않았다.
