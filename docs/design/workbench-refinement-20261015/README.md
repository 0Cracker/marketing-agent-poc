# 워크벤치 화면 피드백 반영

2026-10-15. [최초 확정 명세](../marketing-workbench-spec.md) 이후 사용자가 요청한 화면 변경이다. 최초 명세와 이전 구현 ZIP은 수정하지 않았다. [최초 검증 기록](../marketing-workbench-acceptance.md)은 당시 구현의 이력이며, 현재 화면의 차이는 이 문서를 따른다.

## 반영한 변경

- 차트 아래 출처·기간·범위 주석, 차트 부제, 지표 아래 설명, 표 아래 전체 결과 건수, 페이지 하단 안내를 기본 화면에서 제거했다. 단위·축·계열 범례와 데이터 상태는 유지했다. 범위와 기간·출처·계산식은 근거 패널과 툴팁에서 확인할 수 있다.
- 시장 상세 표는 브랜드 합계 행을 굵은 글자와 옅은 배경으로 구분했다. 제품 A/B는 브랜드 아래 연결선과 들여쓰기로 항상 표시한다. 브랜드 접기 버튼과 반복되는 제품 이름의 브랜드 접두어를 제거했다. 전문 이름은 셀 툴팁·접근 가능한 이름·근거에 유지했다.
- 기본 선택 상자를 아이콘·선택 값이 있는 검색형 팝오버로 바꿨다. 검색어·국가 코드·기준월 값으로 검색하고 키보드로 선택할 수 있다. 클릭·터치·키보드로 명확하게 여는 방식이다.
- 본문 기본 글꼴을 로컬 SUIT Variable 2.0.5로 변경했다. 기존 Pretendard는 대체 글꼴과 이전 구현 자산으로 보존했다.
- 본문·표는 중립색으로 정리했다. 브랜드는 자사 코랄·경쟁 B2 블루·경쟁 B3 민트·기타 회색을 고정했다. 광고의 광고비·클릭률·전환율·ROAS는 각각 블루·민트·앰버·라벤더로 구분했다. 선은 관측값 사이의 직선을 유지하고 점 장식을 줄였다.
- 미생성 유형의 긴 필요 데이터·해석 안내와 예산 검토 항목은 펼쳐서 확인하도록 정리했다. 미생성 상태와 승인·집행 비활성은 유지했다.

새 의존성·마케팅 원천·감성·예측·승인 이력은 추가하지 않았다. 기존 11개 원천의 표시·계산 의미는 유지했다.

## 컴포넌트·글꼴 근거

선택 UI는 저장소에 이미 있는 Popover·Command를 재사용했다. [shadcn 공식 Combobox 문서](https://v3.shadcn.com/docs/components/combobox)의 조합을 바탕으로 워크벤치의 필터 행·밀도·색상에 맞춰 스타일을 적용했다. SUIT는 [공식 v2.0.5 배포](https://github.com/sun-typeface/SUIT/releases/tag/v2.0.5)를 사용하며 [글꼴 해시·출처](font-provenance.json)와 로컬 라이선스를 보존했다.
