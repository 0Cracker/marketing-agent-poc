A

같은 측면의 상반된 경험

같은 제품과 작성기간, 같은 평가 측면에서 서로 다른 두 리뷰가 상반된 경험을 뒷받침해야 합니다.

검사 방법

리뷰 ID 두 개, 각각의 원문 인용과 세부 경험 코드를 대조합니다. 한 리뷰의 두 측면만으로 통과하지 않습니다.

S16 1쌍 이상, S17 1쌍 이상
B

전체와 판매처 추세의 차이

전체 평점 또는 상위 측면의 언급 비율 변화 방향이 최소 한 판매처 내부 방향과 반대여야 합니다.

검사 방법

각 판매처의 실제 분모로 가중 계산하고, 두 변화량의 곱이 음수인지 확인합니다. 변화 없음은 반대 방향으로 세지 않습니다.

전체 변화 × 판매처 변화 < 0
C

작성, 수집, 성과의 시간 순서

비교기간에 작성하고 분석기간에 수집된 후기도 올바른 기간에 배치하고, 늦게 작성된 리뷰를 앞선 ROAS 변화의 원인으로 단정하지 않습니다.
