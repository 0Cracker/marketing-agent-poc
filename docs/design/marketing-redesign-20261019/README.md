# 마케팅 대시보드 피드백 반영 — 2026-10-19

사용자의 브라우저 주석 1–7과 시장·경쟁/브랜드·소비자/예산·검증 메뉴 피드백을 반영했다. 레코드를 하나씩 나열한 차트를 업무별 요약으로 바꾸고, 전체 기간·국가 선택에서 빠지던 대시보드를 복구했다. 국가·제품별로 수량과 분포가 다른 **화면 비교용 D008 시나리오 30,394행**을 별도로 만들었다. 기존 5배치·22,242행과 확정 명세 원문은 보존했다.

작업 시작 HEAD는 `4d286c505e8ac659c1d839b257631ef7280f31d6`, 브랜치는 `feature/workbench-evolution`이다. 기존 미커밋 작업과 별도 Agent 연결 작업을 유지했다. 작업 전 7개 화면/조회 파일과 CSS는 상위 `dashboard-design-history/2026-10-19-before-marketing-redesign/`에 보존했다. 이 요청으로 커밋·스테이징·푸시·브랜치 변경·새 발행 버전/Iteration을 만들지 않았다.

## 화면의 의미와 용어

| 기존 표현 | 화면 표현·의미 |
| --- | --- |
| 구매 패널 | **구매 경험 조사**. 일정 조사 표본에서 제품 구매 경험을 물은 자료. 패널별 최근 표본과 긍정 응답을 비교하며 시장 전체 구매자 수로 확대하지 않음 |
| 경쟁 활동 | **경쟁사 공개 활동**. 외부에서 관측한 자사·경쟁사 광고·소재·공개 발행 자료. 경쟁사의 실제 광고비·전환·매출은 포함하지 않음 |
| 외부 환경 | **시장 외부 요인**. 가상 문맥 지수·날씨·운영일 같은 보조 맥락. 매출 변화의 원인으로 확정하지 않음 |
| 검색 수요 | **검색 관심·수요**. 상대 관심지수와 예상 검색량을 분리. 관심지수는 같은 정규화 요청 안에서만 추이로 표시 |
| VOC·문의 | **고객 문의**. 사용법·배송·교환 등 문의 접수와 처리 상태를 집계 |
| 브랜드 조사 | **브랜드 인식 조사**. 구매 경험 조사와 별도의 질문·표본으로 측정한 브랜드·제품 인식 |
| 전체 국가 | **국가별 비교**. 국가별 표본·별점·문의 해결률·현지 통화 금액·비율을 나란히 표시. 통화나 시장 분모를 합치지 않음 |
| 공통 기준 | 일반 국가 선택에서 제거. 국가가 없는 제품/식별자 기준은 보존 자료·검증 도구에서 접근 가능 |

각 화면의 ‘이 화면은?’에서 짧은 설명을 확인할 수 있다. 예산·실험과 기준·품질은 기본 탐색에서 제외하고 ‘데이터·검증 도구’ 아래로 옮겼다. 해당 자료나 기존 Agent의 예산 기능을 삭제한 것은 아니다. 기존 명세의 9개 도메인 기본 노출은 이번 사용자의 축소 요청으로 변경했으며 명세 원문을 소급 수정하지 않았다.

## 주석별 변경

| 피드백 | 반영 |
| --- | --- |
| 국가 선택의 의미 불명확 | 공통 기준 제거, 국가별 비교로 명칭 변경. 금융 값은 현지 통화와 함께 표시하고 비율을 별도로 비교 |
| 한국만 접수·해결 순서가 다름 | 국가·건수·원천 정렬과 무관하게 접수 → 처리 중 → 해결 → 종료 순서 고정 |
| 사이트 사건 지속 시간 막대 | 페이지·기기별 **발생일/지속 시간 달력**과 로딩 속도 비교로 교체. 기록 없음과 장애를 구분하고 가동률을 만들지 않음 |
| 상품 이벤트 183구간 나열 | **행동별 수량 카드**, 일별 구매 수량 추이, 제품별 구매 수량으로 집계. 개별 레코드는 상세·CSV에 유지 |
| 재고 글자 겹침 | 날짜는 가로축, 제품·위치는 행으로 분리. 최신 재고와 일별 재고 추이·품절 관측 달력으로 표현 |
| 가격 글자 겹침 | 제품별 판매가 추이와 최근 판매처별 가격 범위로 교체. 같은 제품·날짜의 판매처 가격 중앙값이며 원천 판매가는 상세에 유지 |
| 예산 막대의 목적 불명확 | 기본 메뉴에서 제외. 검증 도구에서는 총예산·검색 배분·소셜 배분·모형 예상값을 같은 후보 내역 표에서 확인 |
| 리뷰/검색/문의/브랜드 조사 화면 누락 | 전체 기간이 기존 차트 경로에서 제외되고 전체 국가가 레코드 개수 화면으로 바뀌던 분기를 수정. 요약과 국가 비교를 모두 제공 |
| 전체 배치가 배치별 그래프 | **전체 자료 · 최신 기준**은 최신 호환 시나리오로 제품·채널·문의 유형·상태 등 업무 범주를 보여준다. 모든 보존 버전은 원천 레코드 보기에서 유지 |

막대는 소수 제품/범주 간 크기 비교에만 사용한다. 추이는 선, 구성비는 도넛, 사건·품절은 관측 달력, 판매처 간 분포는 범위와 중앙값, 다른 통화·조사 조건은 비교 표를 사용한다. 카드 높이를 내용에 맞추고 축을 자르던 고정 높이도 수정했다. 기존 보라색 중심 팔레트와 SUIT 글꼴을 유지하며 자사·경쟁사의 계열색을 일관되게 사용한다.

- [기존 R01/R02·R11/R13 조사 자료](../../../../dashboard-design-references-20261015/catalog.md): 밝은 업무 화면·절제된 경계·한국어 가독성과 밀도를 유지했다. 참고 제품의 수치·로고·이미지를 데이터로 가져오지 않았다.

## 비교용 가상 데이터 D008

사용자는 국가·경쟁 제품별 수치 차이, 광고주/형식 비율 차이, 미국은 더 많고 일본은 조금 더 많은 표본을 직접 요청했다. 수량·분포·구현 규칙의 구체적인 선택은 이번 구현 판단이며 사용자가 개별 레코드를 검토했다고 기록하지 않는다. [생성 계획](data-plan.json), [실제 프로필](data-profile.json), `scripts/build-comparison-demo.mjs`에 재현 규칙을 남겼다.

| 국가 | 전체 행 | 리뷰 | 공개 광고 | 고객 문의 | 주문행 | 방문 이벤트 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 한국 | 6,825 | 560 | 28 | 79 | 400 | 934 |
| 일본 | 8,987 | 730 | 41 | 107 | 512 | 1,333 |
| 미국 | 14,582 | 1,120 | 87 | 200 | 800 | 2,333 |
| 합계 | 30,394 | 2,410 | 156 | 386 | 1,712 | 4,600 |

제품별 리뷰 수는 한국 `83/111/74/129/97/66`, 일본 `119/138/92/151/127/103`, 미국 `213/167/245/196/162/137`이다. 순서는 자사 A/B, 경쟁1 A/B, 경쟁2 A/B다. 별점·텍스트·주석·문의 주제·상태·광고 형식도 국가/제품 조건과 고정 해시에 따라 다르게 구성했다. 광고 형식은 한국 16/7/5, 일본 23/11/7, 미국 37/29/21(텍스트/이미지/동영상)이다.

기존 D007을 원형으로 재사용하고 새로운 모의 표본을 추가한 **비교 시나리오 버전**이다. 실제 국가별 인구·시장 비율을 추정한 자료나 통계적 독립성의 증거가 아니다. 주문 수를 늘릴 때는 주문행만 늘리지 않고 일본 12개·미국 48개의 추가 가상 고객군에 해당하는 주문·환불·배송·코호트·CRM을 새 ID로 함께 연결했다. 상품 가격·금액 산식·반품 차감 관계를 유지했다. 리뷰 구매 확인은 미제공 상태를 유지하고 실제 승인·집행 이력을 만들지 않았다.

리뷰 주석 4,820행은 문장에 존재하는 발췌를 규칙으로 연결한 가상 주석이다. 인간 검토나 LLM 감성 분석을 실행했다고 하지 않는다. JSON Schema·참조 ID·발췌 위치·통화·주문행 산식·코호트 순매출을 검사했다. 원본 저장소의 OWL/SHACL/RDF나 Agent 서버에 새 시나리오를 적재한 것은 아니다.

`frontend/public/workbench-data/D008/`에 40개 JSONL·카탈로그·잠금 파일을 보존했다. 잠금 파일에 기존 D007 해시, 실제 검증한 스키마/검증기 해시와 화면 계약을 기록했다. 생성·조회 가능 기준시각은 실제 실행 시각을 잠금 파일의 `source_created_at`에 기록했다. 원래 5배치는 변경하지 않았으며, 모든 보존 버전의 행 수 합은 **52,636행**이다. 이는 여러 버전의 보존 행 수이며 시장 성과로 합산하지 않는다.

## 검증·남은 제약

- `node scripts/check-marketing-redesign.mjs`: 국가 3개·국가 비교, 8월·전체 기간의 **323개 조회** 통과. 예전 배치의 결측 표현, 국가/제품별 분포, 고정 상태 순서, 상품 수량 합계, 최신 기준 조회와 전체 원천 접근, 통화, 주문행·코호트 대사를 확인했다. [기계 결과](query-checks.json)
- 기존 D003B 모델 496개 동일, D007 123조회·기존 22,242행 전수 검사를 다시 통과했다. 과거 검사는 새 업무 차트 의미에 맞게 검사 항목을 수정했으며 원천·분모·전체 행수 대조는 유지했다.
- 기존 Agent 클라이언트 시험 7개 통과. Agent 관련 기존 변경을 보존했다.
- [타입 검사·이번 변경 파일의 ESLint·Vite 빌드 결과](build-checks.json)를 확인했다. 전체 workbench 린트에는 다른 작업의 `agent-conversation.tsx` effect 관련 오류 1개·경고 2개가 있어, 해당 파일을 임의로 수정하거나 전체 린트 통과로 보고하지 않는다. 기존 큰 청크 경고도 유지된다.
- 실제 브라우저: 전체 기간의 기본 **34개 화면**에서 빈 대시보드·가로 넘침이 없음을 확인했다. 가격·재고·사건·문의·리뷰·국가 비교와 390px 화면을 별도 확인했다. [브라우저 기록](browser-checks.json)

**Agent 연결 제약:** 새 D008은 이번 화면 비교용 시나리오다. 현재 별도 Agent API는 D007만 지원하므로 D008을 D007로 바꿔 보내거나 새로운 수치로 분석 성공을 꾸미지 않았다. 데이터 선택의 ‘Agent 연결 표본 · D007’에서 기존 연결을 유지한다. 신규 시나리오의 Agent/RDF 연결 완료로 보고하지 않는다.
