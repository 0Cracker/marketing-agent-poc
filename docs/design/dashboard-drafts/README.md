## 데이터 재사용

사용자의 기존 가상 데이터 사용 요청에 따라 [D003B](../../research/marketing-ontology/batches/D003B/report.md) 11종·1,652건의 기존 필드만 읽어 투영·집계했다. 원본 수정·재생성, 신규 원천·감성 주석·예측·승인 레코드 생성은 하지 않았다.

- 한국·일본·미국, 3브랜드·6제품, 샴푸 300ml·A/B 비교군.
- 월간 2024-10–2026-09, 상세 2026-08-03–08-30. 국가 3개와 2026-07/08/09를 선택할 수 있으며 기본값은 일본·2026-08이다.
- 시장 분모는 국가·기간별 공통 시장 금액을 한 번 사용한다. 분모를 반복 합산하지 않고 기타 제품 비중을 포함한다.
- 통화 간 합산 없음. 매체는 원천의 ‘모의 검색·모의 소셜’을 유지한다.
- 비율은 원시 합계에서 재계산한다. 보고 전환은 중복 제거 전 플랫폼 합계로 명시하고 ROAS는 매체별 표시한다. 플랫폼 귀속 매출을 자사 순매출로 취급하지 않는다.
- 월간 완전 보고와 일별 상세를 더하지 않는다. 일본 소셜 8/26·8/27 null을 보존한다.
- 원문·별점을 유지하고 감성/토픽·인과 결론을 새로 만들지 않는다. 가격·재고 스냅샷을 기간 합계로 더하지 않는다.
- 예산은 실제 지출 구성만 표시한다. 다른 CTI 사례의 가상 예산 곡선을 D003B와 섞지 않는다.

## 검증 결과와 한계

- 생성 도구 종료 0. 원천 11종·1,652건, 가상 표시, 선언된 LF 기준 manifest 해시, null 보존, 시장 분모, 스크립트 문법 검사 통과.
- Windows `core.autocrlf=true`로 새 checkout의 원천 11개는 CRLF다. 메모리에서 LF로 정규화한 해시가 manifest와 일치했다. checkout 바이트 자체의 동일성을 주장하지 않으며 원본 파일은 변경하지 않았다.
- 브라우저 3시안×6탭=18개 전환 확인. 지표 4개 표시, NaN/undefined 없음, 예산 승인 버튼 비활성 확인.
- 320·768·1024px에서 세 시안의 시장 화면 확인. 실제 콘텐츠 너비 305·753·1009px에서 페이지 전체 가로 넘침 없음. 모든 탭의 모든 반응형 조합을 시각 검증한 것은 아니다.
- 국가 3개 전환 시 통화·값 갱신, 7월 리뷰 빈 상태, 브라우저 오류·경고 로그 없음 확인. 최종 전체 페이지 캡처 3개 보존.
- 실제 앱 테스트·타입 검사·빌드는 미실행이다. 앱 변경이 없어 이 결과를 앱 기능 완성으로 해석하지 않는다.

## 2026-10-15 초안 스냅샷 보존

사용자가 개발 과정 기록과 초안 스냅샷 보존을 요청했다. 세 시안의 여섯 탭 전체를 일본·2026-08 조건으로 캡처한 JPEG 18장, 캡처 metadata, 독립 미리보기·템플릿·생성 도구, D003B 원천 사본과 검증·설계 기록을 워크트리 밖에 보관했다. 원본 데이터·화면 코드는 변경하지 않았다.

[스냅샷 목록·보존 범위](../../../archive/design-history/2026-10-15-drafts/README.md)를 참고한다. 이미지 정상 여부·파일 해시·압축본 대조 결과는 보관 manifest와 상위 checksum 파일로 확인한다. Git 커밋·푸시는 수행하지 않았으며 이번 요청은 실제 앱 구현안 선택과 별도다.

## 2026-10-15 구조 선택 및 시각 디자인 재조사

사용자는 분석 워크벤치형을 선택하고 각 도메인을 왼쪽 탭에서 탐색하는 구성을 선호한다고 밝혔다. 현재 초안의 전반적인 UI와 글자 품질을 개선하기 위해 다양한 디자인 자료를 먼저 보고 레퍼런스를 고르겠다고 요청했다.

[디자인 레퍼런스 조사 기록](../../references/dashboard-design/README.md)에 참고 지점 40개, 이미지가 있는 후보 13개, 원문 출처·확인 범위·장단점·도메인별 적용 후보를 정리했다. [비교 보드](reference-board.html)는 같은 자료의 이미지 내장 미리보기 사본이다. 기존 초안 보존본은 변경하지 않았다. 밝기·서체·정보 밀도·개별 참조 화면은 미확정이며 앱 화면과 가상 데이터는 변경하지 않았다.
