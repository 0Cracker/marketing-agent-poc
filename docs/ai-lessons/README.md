# AI 활용 교훈

실제 시행착오에서 재사용할 원칙을 얻었을 때 [Lesson 템플릿](../../.agents/skills/poc-iteration-log/assets/lesson-template.md)을 복사해 `lesson-NNN.md`를 만든다. [운영 절차](../DEVELOPMENT-WORKFLOW.md)를 따르며 현재 Lesson은 아래와 같다.

| 주제 | Lesson·제목 | 검증 상태 | 관련 버전 | 핵심 원칙 |
| --- | --- | --- | --- | --- |
| UI/정보 전달·검증 | [001: 원천 연결 검증과 업무 화면 검증을 분리한다](lesson-001.md) | 검증 중 | 미확정 | 원천 연결·집계 의미·실제 가독성을 각각 확인 |

주제는 문제 정의, 프롬프트/작업 분할, Mock/수치 검산, UI/정보 전달, 검증/운영 등 실제 교훈에 맞게 정한다. 가설 / 검증 중 / 검증 완료를 구분한다. 한 번 성공했다고 보편적인 개발 원칙으로 확정하지 않는다. 반복되면 기존 Lesson에 날짜·버전·추가 근거와 적용 한계를 축적한다. 검증된 원칙만 향후 작업 지침 후보로 삼고 사용자 판단 없이 개인 철학을 확정하지 않는다.
