# Lesson 002: 원천 연결 검증과 업무 화면 검증을 분리한다

## Lesson 기본 정보

- 제목: 원천 연결 검증과 업무 화면 검증을 분리한다
- 주제: UI/정보 전달·검증
- 관련 버전: v0.3.0. 작성 당시 미확정이었으며 2026-10-19 통합 시 분류했다.

- 검증 상태: 검증 중
- 적용 범위와 한계: 가상 마케팅 PoC 화면. 이번 구현의 수치·가독성 확인이며 사용자 최종 수용이나 보편적 원칙 검증은 아님

## 1. 문제 상황

10월 18일 22,242행·41유형의 연결 검사는 통과했지만 사용자는 개별 원천마다 막대를 나열한 상품 행동 차트, 겹치는 재고·가격 레이블, 목적이 불명확한 모형 차트와 빈 전체 기간 화면을 지적했다. 레코드 접근 가능성과 업무 비교 가능성을 같은 성공 기준으로 취급한 것이 한계였다.

## 2. AI 활용 방식

Codex로 원천 스키마·조회 분기를 읽고 사용자 주석별 집계 단위와 차트 목적을 대응했다. 기존 D003B 모델 회귀 검사를 유지하면서 업무 집계 검사와 실제 브라우저 순회를 추가했다. 사용자 가상 데이터 다양화 요청은 별도 시나리오로 구현하고 원본을 보존했다.

## 3. 시행착오 및 개선

개별 행 막대·구간 페이지 이동을 업무별 수량 카드, 날짜 추이, 판매가 범위, 사건·품절 달력으로 바꿨다. 전체 기간과 전체 자료를 별도 수용 조건으로 검사했다. 상품 이벤트와 주문 표본의 수집 범위가 달라 조회→구매 수량으로 사용자 이탈률을 만들 수 없음을 확인해 퍼널 대신 독립 행동 수량을 표시했다. 브라우저에서 광고 축이 고정 높이로 잘리는 문제도 발견해 내용 높이에 맞췄다.

## 4. 결과 및 교훈

신규 323조회, 기존 모델 496조회, 기존 원천 22,242행 대조를 통과했다. 기본 34화면의 전체 기간 순회와 390px 상품·재고 검사를 수행했다. 향후에는 ‘무엇을 비교·판단하는가 → 집계 단위·분모·범위 → 시각화 → 원천 대사 → 실제 화면 가독성’을 각각 확인한다. 전체 연결/빈 화면 없음만으로 사용자 목적을 충족했다고 보고하지 않는다. 실사용자 수용·다른 데이터 분포의 재현성과 접근성 추가 검증은 남는다.
