# 결정 001 — 근거를 연결한 온톨로지 설계와 데이터 사전 승인

날짜: 2026-10-13. 관련 발행 버전: 미확정. 기준 SHA: fb74fed. 상태: 작업 원칙 채택 / 온톨로지·데이터 세부 제안. [조사 작업](../research/marketing-ontology/README.md) 연결.

## 문제·제약

현재 데모는 정적 응답으로, 원천과 답변·행동의 연결을 실제 관계 조회로 검증하지 않는다. 기업 내부 모델·현업 접근이 없고, 사용자는 가상 데이터의 모든 생성·수정·재사용에 사전 제안을 요구했다. 대표 성과 목표는 아직 선택되지 않았다.

## 대안

| 대안 | 장점 | 제약 |
| --- | --- | --- |
| 고정 답변·그림 개선 | 기존 앱에 빠르게 반영 | 실제 저장·관계 조회 요구를 충족하지 못함 |
| 명시적 온톨로지→Neo4j | 현재 질문에서 필요한 관계·근거 경로를 실행 가능하게 함 | 설치·Node API·적재·제약 검증 필요 |
| RDF/OWL 전체 추론 | 표준 의미 추론과 호환성 | 이번 질문에 필요한 능력·추론 범위가 확인되지 않음 |

## 선택·승인 구분

사용자가 승인한 방향: 1–3단계 조사·정의 우선, 자료 공유·정리, 독자 모델, 실제 그래프·계산 우선, 데이터마다 명시적 사전 승인.

설계 기본안: 온톨로지 명세를 Neo4j 속성 그래프에 매핑하고 Node API에서 조회·계산, Cytoscape.js로 근거 부분 그래프 표시. 전체 OWL 추론·실제 LLM·Ads 집행은 후속 범위다. 이 방향은 설계이며 설치·연결 완료로 기록하지 않는다.

D001 변환, 대표 성과 목표, 추가 자료·시뮬레이션 가정은 제안 중이며 미승인이다. 계획 실행 요청을 D001 데이터 승인으로 확대 해석하지 않는다.
