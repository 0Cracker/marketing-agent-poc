# 기술·기획 의사결정

재검토할 가치가 있는 선택만 `decision-NNN.md`에 기록한다. 작은 선택은 Iteration의 Develop에 남긴다. [기존 설계](../poc-v2-initial-design.md)·[응답 계약](../agent-contract.md)·[시나리오](../scenario-playbook.md)를 먼저 확인하고 같은 내용의 문서를 복제하지 않는다. 아직 새 의사결정 문서는 없다.

| 번호 | 주제 | 상태 | 관련 Iteration | 문서 |
| --- | --- | --- | --- | --- |

새 문서는 제목, 날짜, 관련 버전, 상태(제안/채택/대체), 문제와 제약, 고려한 대안 및 장단점, 선택과 이유, 검증 근거/한계, 되돌리거나 재검토할 조건, 관련 Iteration·Evidence·커밋을 포함한다. 기존 결정을 바꾸면 과거 이유를 지우지 말고 대체 문서 또는 변경 날짜를 연결한다. 승인된 기획과 AI 제안을 구별한다.
