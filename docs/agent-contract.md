# 고정 시나리오 응답 계약

현재 앱은 준비된 질문·답변을 표시하는 시연입니다. 실제 모델 연결 지침을 적용하지 않습니다.

`lib/demo-scenarios.ts`의 DemoCase가 공통 원천·CTI·기여도·근거·예산안을 담습니다. `responses.lookup`, `responses.diagnosis`, `responses.action`에 고정 질문·제목·결론이 저장되어 있습니다. 같은 case ID를 유지한 채 질문 수준에 필요한 컴포넌트를 렌더링합니다.

- 조회: 핵심 지표와 시계열.
- 진단: 기여도, 상황별 근거 그래프, 가설, 지지/반대/대안, 원천 테이블.
- 대응: 우선순위, 판단 근거, 예산 시연 진입.
- 예산: 고정안, 노출 반응 곡선, 가정/제약, 모의 효과, 승인/Mock 집행.

사례를 전환하면 대화와 승인 상태를 초기화합니다. 미등록 질문은 해석하지 않습니다. E의 결측은 null로 유지하고 예산 검토를 막습니다. 수치가 표시되는 모든 영역은 동일 case 객체를 참조합니다.

관측/계산/가설/모의 효과를 구별합니다. 가설에는 실제 확인한 인과 효과나 근거 없는 확률을 붙이지 않습니다. 실제 AI·광고 계정에 연결되지 않았음을 표시합니다.

CTI는 선택한 경쟁 제품군 내 검색·긍정 리뷰·참여·광고 노출 비중의 가중 합계다. 이 데모는 A+B 비교이며, 매출·구매 확률·시장 전체 점유율·광고 효율의 측정값이 아니다. 가중치 .35/.25/.20/.20은 PoC 설계 가정이다. 기본 UI는 숫자와 짧은 라벨을 우선하고, 정의·가설·제한은 필요한 경우 펼쳐 본다.

현재 승인 대상은 업무/실험 계획이며 Mock 요청 등록이다. A/B/D의 조사, C의 조건부 실험, E의 복구/보류, F의 현행 유지를 구분한다. decision/proof/process/chronology 필드는 정적 작성 결과다. C 이외 예산 배분은 유지하며, 승인으로 실제 팀 전달·집행·측정이 일어났다고 표현하지 않는다.
