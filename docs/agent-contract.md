# 모델 연동과 보고서 응답

현재 구현은 샘플 데이터 기반의 준비된 보고서이며 실제 모델이 연결되지 않습니다. 전체 답변을 챗에 바로 표시하고 별도 캔버스·근거 접기·시나리오 테스트 UI는 사용하지 않습니다.

## 응답 구조

`lib/marketing.ts`의 `Analysis` 타입을 기준으로 합니다. `title`, `conclusion`, `scope`, `sections`(제목과 문단), `rows`(채널별 수치), `closing`, `followups`를 반환합니다. 현재 화면은 후속 질문 버튼을 별도로 표시하지 않습니다.

결론을 첫 문장에 제시하고, 성과 변화·핵심 근거·추천 행동 순서로 정리합니다. 행동은 번호 목록으로 표시하며 반복 결론과 설명은 생략합니다. 동일한 기간과 귀속 기준의 합계에서 비율을 계산하고, 수치 분해와 원인 확정을 구분합니다.

## 데이터 해석 기준

Meta는 클릭 증가·구매 전환율 하락·구매당 매출 유지, Kakao는 구매 수 유지·구매당 매출 하락을 구분해 설명합니다. 전체 순매출 감소보다 특정 채널 감소액이 클 수 있으며 다른 채널 증가의 상쇄 효과를 함께 설명합니다.

전환율 비교로 계산한 구매 건수 차이는 산술적 비교값이며 회복 가능한 구매 수나 미래 매출이 아닙니다. 평균 ROAS를 추가 예산의 효율로 사용하지 않습니다. 제공하지 않은 기간, 소재, 고객군, 퍼널 단계는 생성하지 않습니다.

## 모델 연결 시

질문, 현재 필터, 이전 대화, 검증된 집계와 지표 정의를 서버에서 모델에 제공합니다. 모델은 보고서 설명을 작성하고, 계산은 검증된 함수가 담당합니다. 출력 스키마·수치·허용 범위를 검증하며 실행 가능한 HTML·JS를 화면에 주입하지 않습니다. 키는 서버에만 보관합니다.

검증은 전체 매출 증감 정합성, 전환 산술, 채널·기간 범위, 예산 효과와 데이터 부족의 한계를 포함합니다.
