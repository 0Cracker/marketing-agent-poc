검토용 [도구 실행 확인 결과](../../evidence/v0.4.0/exploration-20261019/marketing-agent-answer-examples-evidence-20261019.json)에 사용한 원값·근거 ID·모의 결과·상태를 보존했다. 자료 기준시각과 예시용 승인 시각을 고정하고 SQLite 메모리 저장소로 실행했다. 기존 저장된 사용자 실행·승인은 변경하지 않았다. 외부 모델 호출과 실제 Ads 호출은 각각 0회다. 전후 카탈로그 지문이 같은지도 확인했다.

화면의 점유율은 도구의 비율값을 백분율로 바꿔 소수 둘째 자리까지 표시했다. 시장 분모는 `39,055,434.00 JPY`다. 모의 전환수의 원값은 최초 비교 `60.500000 / 61.538462`, 수정 비교 `64.015977 / 64.015977`이다. 표시 자릿수 때문에 원계산값을 변경하지 않았다.

‘다음으로 살펴볼 내용’, 근거를 설명하는 문장, 버튼 이름과 문체는 시안 작성자의 제안이다. 문장 생성·버튼 동작·선호 우열을 현재 앱이나 사용자 테스트로 검증했다고 보지 않는다. D03·D05는 확인한 조회·실행 경계에 따른 설명 시안이며, 해당 자연어 요청을 외부 LLM에 보내 시험한 결과가 아니다.

## 피드백을 남기는 간단한 방법

전체 세트 선호와 개별 답변 선호를 나눠 적는다. 예: ‘전체는 A, 근거 설명은 B02, 승인 안내는 C05’처럼 섞어서 선택해도 된다.

| 비교 항목 | 남길 내용 |
| --- | --- |
| 기본 말투 | A / B / C 중 편한 것과 이유 |
| 첫 분석 | 판단이 바로 읽히는지, 표가 필요한지 |
| 근거 설명 | 원문·출처·해석·한계 중 더 필요하거나 과한 것 |
| 예산 검토 | 배분과 가정을 이해하고 승인 대상을 구별할 수 있는지 |
| 수정·무효화 | 무엇이 바뀌었고 무엇을 다시 해야 하는지 분명한지 |
| 원하는 조합 | 유지할 답변 ID, 줄일 부분, 바꿀 표현 |

선호가 높아도 사실·반대 근거·가상 표시·승인 대상 정보는 생략하지 않는다. 이 세트는 이후 화면 시안과 프롬프트 예제를 만들 때 사용할 검토용 문서이며 현재 운영 프롬프트에 자동 적용하지 않았다.
