# 업무·문제 정의 초안

2026-10-13. 상태: 조사에 근거한 설계 초안. 현업 인터뷰 없음. 자료 ID는 [근거 목록](research-status.md)을 따른다.

## 사용자와 업무

주 사용자 가설 H01: 국가·카테고리의 마케팅 성과를 점검하고 대응 전략·매체 예산 조정안을 작성하는 담당자. 브랜드 담당자라는 직함만으로 한정하지 않는다. 사용자가 두 Step의 주요 사용자를 요구한 U01/U02와 측정·실험 업무 구조 S01을 참고했지만 실제 이용 빈도는 미검증이다.

| 역할 | 필요한 판단·산출물 | 근거·상태 |
| --- | --- | --- |
| 주 사용자 | 열위 현상 확인, 원인 후보·대안 설명 검토, 대응·예산 제안 | U01, S01/S02, H01 |
| 매체 운영자 | 캠페인·채널 제약 확인, 실행 가능한 변경안 검토 | U01, S05, 역할 분담 H02 |
| 예산 승인자 | 목표·근거·위험·변경 범위·실패 조건 검토 | U01, 권한 구분 H03 |
| CS·제품·계측 담당 | 비광고 문제 조사·자료 복구 | L01/L03 사례에 존재. 실제 조직 체계 미확인 |

## 문제 가설과 성공 기준

H04: 여러 자료의 기간·대상·수집 기준을 맞추고 경쟁 상대값과 자사 절대값을 구분하는 과정이 수작업 판단을 어렵게 할 수 있다. H05: 결과가 다음 업무와 연결되지 않으면 복사·재작성 부담이 생길 수 있다. U01은 문제의 단서지만 소요 시간·반복 빈도의 실측은 아니다.

대표 결정: 열위가 관측됐을 때 광고 변경, 고객 경험 조사, 경쟁사 조사, 계측 복구, 현행 유지 중 무엇을 먼저 검토할 것인가.

데모의 성공: 같은 관측 변화라도 절대값·경쟁 범위·출처·사건에 따라 다른 설명 후보와 행동을 제시하고, 사용자가 각 근거를 따라갈 수 있다. 실제 시간 절감·매출 개선은 후속 현업 검증 대상이다.

## 대표 목표 비교 — 사용자 선택 대기

| 대안 | 판단 목표·필요 자료 | 현재 자료 적합성 | 추천 여부 |
| --- | --- | --- | --- |
| 인지·관심/경쟁 존재감 | 검색·리뷰·참여·노출의 상대 변화, 광고비·노출 비용 | 현재 L01–L05와 비교적 직접 연결. 실제 인지도 조사값은 없음 | 첫 그래프 검증 범위로 추천. 사업 효과로 해석하지 않음 |
| 전환·매출 | 구매·매출·CPA·ROAS 또는 증분 성과 | 클릭·전환·매출·귀속 자료가 없어 새 제안·승인 필요 | 사용자 선택 시 새 데이터 설계 먼저 |

단기 기술 검증 목표는 근거 추적·동적 계산이다. 사용자 대표 성과 목표는 미확정이며 이를 몰래 채택하거나 예산 최적화 기준으로 사용하지 않는다. D001은 목표 선택 이전에도 기초 관계 모델을 검증할 수 있도록 범위를 제한했다.

| 데이터 그래프 | 승인된 자료가 개체·관계로 들어간 인스턴스. 스키마 관계도와 구별 |
| 시뮬레이션 | 지정한 가정과 제약하에 계산한 후보 비교. 실제 효과 예측 정확도를 보장하지 않음 (S05) |

## 유닛장 피드백 대응

피드백 당시 화면을 현재와 동일하다고 가정하지 않는다. 아래 '존재'는 문서·코드로 확인한 것이며 이번 UI 실행 검증은 하지 않았다.

| 피드백 | 현재 확인 | 다음 반영·검증 |
| --- | --- | --- |
| 차트 가까이 AI 분석, 좌측 메뉴 역할 정리 | 기존 대시보드·채팅 구조 존재 | 차트 맥락 전달과 기본 질문 화면을 분리 없이 연결 |
| 여러 AI 기능 이름·진입 통합 | 고정 lookup/diagnosis/action 응답 존재 | 화면 메뉴는 페이지, 분석 버튼은 작업으로 구분 |

## 다음 검토

사용자에게 목표 대안과 D001 범위를 제안한다. 현업 접근이 가능해지면 실제 담당자에게 대표 과제를 수행하게 하고, 근거 발견률·다음 행동 식별·오해·과제 시간의 기준선을 먼저 측정한다. 측정 전 개선율이나 목표 시간을 임의로 기록하지 않는다.
