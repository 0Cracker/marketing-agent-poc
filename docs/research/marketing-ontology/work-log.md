# 조사·설계 작업 기록

## 2026-10-19 Agent 답변 요약 형식 반영

질문별 흐름·답변 예시 검토 후 사용자의 다음 작업 요청에 따라 기존 패널에 결론·핵심 근거·한계·다음 행동을 먼저 표시했다. 실제 근거의 짧은 번호 링크, 수치·원인 후보 상세 접기, 실제 조회 단계 보기와 예산 상태별 결론을 연결했다. [연결 문서의 후속 기록](../../design/agent-connection-20261019.md)에 변경·시험·화면 증거와 한계를 통합했다. 원천·명세·신규 마케팅 값 생성·외부 모델 전송·Ads·Git 상태 변경은 수행하지 않았다. 병행 중인 비교 데모·결과 차트·모델 연결 변경은 이번 요약 구현의 실적으로 포함하지 않는다.

## 2026-10-19 Agent 패널의 로컬 분석·예산 연결

사용자의 다음 작업 진행 요청에 따라 기존 분석 탭을 sibling의 두 에이전트 HTTP 실행기에 연결했다. 기존 화면·데이터 분리 작업을 보존하고 별도 대화 클라이언트·검토 표시·Vite proxy만 연결했다. 범위별 저장 복원, 원문 근거 확인, 예산 검토의 사용자 선택, 수정/후속 분석의 승인 무효화를 확인했다. [변경·검증 기록](../../design/agent-connection-20261019.md)에 실행 방법과 시험 근거를 남겼다. 클라이언트7시험·타입·빌드·기존 화면 계약496조합·수치12조합pass다. 기존 가상 D007 재사용이며 신규 원천 생성·외부 모델/Ads 연결·Git 발행은 하지 않았다.

## 2026-10-15 워크벤치 화면 피드백 반영

사용자가 작은 보조 문구 제거, 브랜드·제품 구분, 기본 선택 칸 교체, 부드러운 글꼴과 다양한 차트 색상을 요청했다. 최초 확정 명세를 수정하지 않고 [후속 변경·검증 기록](../../design/workbench-refinement-20261015/README.md)에 변경 의도와 근거를 별도로 남겼다.

차트 부제·주석, 지표 하단 설명, 표 아래 결과 건수, 페이지 하단 안내를 기본 화면에서 제거하고 관련 정보를 기존 근거 패널에서 확인하도록 유지했다. 시장 표는 브랜드 합계 행을 강조하고 제품 A/B를 들여쓴 고정 계층으로 바꿨다. 브랜드 접기 버튼을 제거했으며 집계 값·검색·정렬·CSV는 유지했다. 기존 Popover·Command 컴포넌트로 검색형 필터를 구성하고 로컬 SUIT Variable 2.0.5와 차트 전용 팔레트를 적용했다.

검증: 수치 검산·타입 검사·변경 코드 린트·빌드·기존 CTI 회귀 검사 통과. 9개 도메인의 보조 문구 제거와 시장·광고·상품 3개 도메인×3해상도 9조합의 전체 가로 넘침 없음, 검색·키보드 선택·Esc 포커스 복귀, 일본 소셜 결측 선·데이터 표를 확인했다. 브라우저 사용량 제한에 따른 자동 승인 검토 중단은 사용자 재개 요청 후 같은 도구로 해소했다. 이전 보존본·원천·잠금 파일·Git 상태 변경 명령은 건드리지 않았다.


## 2026-10-15 확정 워크벤치 구현·검증

사용자가 첨부한 상세 명세 그대로 독립 detached 워크트리에 `/workbench`를 구현했다. [확정 명세 원문](../../design/marketing-workbench-spec.md)은 첨부와 바이트·SHA-256이 동일하며, [40유형 매핑](../../design/marketing-workbench-type-map.json)과 [수용 기준·검증](../../design/marketing-workbench-acceptance.md)을 연결했다. 기존 초안·조사·원본 checkout과 미커밋 기록을 보존했다.

D003B 직접 필드 전용 어댑터, 9개 도메인·세부 탭, 10개 T유형+H01 화면, 미생성 30유형 안내, 우측 Agent·근거·원본 패널, 표·CSV·기간·결측 계약을 구현했다. 실제 분석 응답·감성·예측·승인 이력을 만들지 않았다.

원천 11파일·1,652건의 LF manifest 해시와 checkout 바이트 해시를 기록했다. 수치 검산 12개 국가/월 조합, 전체 41개 화면 탐색, 9개 도메인×5해상도 45조합, 키보드·CSV·근거 이동 검증을 통과했다. 1440×900에서 주요 차트와 표 7행이 보였다. 타입·변경 코드 린트·빌드·기존 CTI 회귀 검사를 통과했으며 청크 크기 경고와 기존 Next 경로 안내는 검증 문서에 남겼다.

관련 계약 문서 2개의 기존 누락과 의존성의 이전 경로 링크 문제를 발견했다. 계약 내용을 추정하지 않았고 기존 잠금 파일로 이 워크트리에만 의존성을 설치했다. 이 작업을 v0.3.0 시작·발행 승인으로 해석하지 않았으며 Git/원격 상태 변경을 수행하지 않았다. 결과·코드·원천 사본·초안·캡처는 별도 구현 스냅샷에 보존한다.

이번 작업은 기록 보존이며 원천 값·화면 코드·실제 앱 구현·최종 시안 선택·Git 커밋·원격 발행을 변경하지 않았다. 원본 checkout의 다른 작업은 포함하지 않는다.
