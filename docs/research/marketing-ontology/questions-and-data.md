# 대표 질문·데이터 요구사항

2026-10-13. 상태: Q01–Q05 설계 초안, Q06 목표·데이터 대기. 실제 질의·API 구현 없음. 근거 ID는 [목록](research-status.md)을 따른다. 데이터 승인 경계는 [D001](data-proposal.md)을 따른다.

## 공통 입력·출력

입력은 caseId, 시장 범위(국가·카테고리), 대상 제품·비교 제품 집합, 기준/관측 기간, 질문 종류다. 월별 자료로 일별 질문에 답하지 않는다. 모든 비교는 기간 길이·단위·수집 기준·제품 집합을 확인한다.

출력은 분석 맥락, 계산한 지표·절대 변화·상대 변화, 사용 관측 ID·출처 위치, 원인 후보·지지/반대/대안, 한계, 다음 행동이다. 실제 자료가 없는 항목은 빈 결과/미확인으로 표시한다. 명세의 필드·규칙은 데이터 레코드가 아니다.

## 질문별 계약

| ID·질문 | 사용자·다음 결정 | 필요한 자료·근거 | 조회·계산 | 출력·자료 부족 처리 | 후속 행동 |
| --- | --- | --- | --- | --- | --- |
| Q01 어디서 열위인가? | 주 사용자: 더 볼 시장·제품 결정 | 같은 범위의 자사/경쟁 관측·지표 정의 (U01, S02/S07, L03) | 시장→제품→관측→지표. 절대값·비중·CTI 비교 | 지정 비교 집합의 열위·기여. 전시장 순위를 주장하지 않음. 결측 시 해당 지표 보류 | 근거 지표·Q02/Q03 탐색 |
| Q02 자사가 악화됐나, 경쟁사가 성장했나? | 주 사용자: 자사/경쟁사 조사 선택 | 각 제품의 비교기간 절대값·동일 수집 기준 (L01/L05, H04) | 두 제품의 절대 증감과 상대 비중을 함께 계산 | 방향을 구별해 요약. 경쟁 성장=고객 이탈로 단정하지 않음 | 경쟁 활동 확인 또는 자사 조사 |
| Q03 어떤 지표가 변화에 기여했나? | 주 사용자: 분석 우선순위 결정 | 원천값·가중치·산식 버전 (L03/L05) | 네 비중 차이에 가중치 적용, 합계 검산 | 산술 기여 pt·원천 ID. 인과 기여율로 표현하지 않음. 필수 결측 시 전체 CTI 보류 | 관련 자료·Q04 확인 |
| Q04 가능한 원인과 반대 근거는? | 주 사용자: 추가 확인할 가설 선택 | 사건·별도 관측·가설·지지/반대/대안 (S03/S08, U01) | 관측·사건의 범위·선후 확인, 가설 근거 경로 조회 | 근거 존재/혼재/부족. 임의 확률 없음. 근거 없으면 원인 확정 불가 | 누락 자료 요청·검증 과제 |
| Q05 광고 변경이 우선인가? | 주 사용자/매체 담당: 조사·유지·실험·복구 선택 | Q01–Q04, 광고비/노출, 리뷰 총수·긍정률/평점, 운영 조건 (L01/L03, S01) | 계산 결과와 명시적인 데모 판단 규칙으로 분기 | 행동 후보·이유·대안·필요 자료. CTI만으로 예산 이동하지 않음 | 조사 초안·Q06 검토 또는 보류 |
| Q06 예산 변경안이 현행보다 나은가? | 주 사용자/승인자: 실험·승인 판단 | 목표·총예산·채널 현재값·상하한·반응 가정 (S05), 전환 목표면 귀속·전환 자료 추가 | 동일 가정으로 현행/변경 계산, 총합·제약 검사 | 목표별 모의 결과·차이·가정·중단 조건. 목표·자료 미정이면 계산 보류 | 가정 변경·비교·승인 요청 |

D001만 승인하면 Q01–Q03의 기초 조회·계산을 먼저 구현한다. Q04의 사건·가설 인스턴스와 Q05의 추가 리뷰/매체 자료, Q06의 시뮬레이션 자료는 후속 데이터 제안 승인 전에는 제공되지 않는다.

## 지표 정의

| 지표 | 산식·단위 | 입력·예외 | 현재 상태 |
| --- | --- | --- | --- |
| 네 상대 비중 | A/(A+B) × 100, % | 검색·긍정 리뷰·참여·노출 각 별도 분모. 분모 0/결측이면 계산 불가 | 기존 정의 L03, D001 변환 후보 |
| CTI | .35S+.25R+.20E+.20M, pt | 같은 비교 집합·기간·버전. 필수 비중 결측이면 계산 보류 | 가중치 검증되지 않은 PoC 가정 |
| 산술 기여 | 가중치 × (관측 비중−기준 비중), pt | 합계=CTI 차이. 상대 비중 차이는 pp | 원인의 인과 기여가 아님 |
| 상대 증감 | (관측−기준)/기준 × 100, % | 기준 0이면 계산 불가. 절대 변화도 함께 표시 | 조회 후 계산 |
| CPM | 광고비/노출×1000, 통화/천 회 | 같은 기간·통화·집행 범위, 노출 0/결측 보류 | 원자료 존재, D001 범위 밖 |
| CTR/CVR | 클릭/노출, 전환/클릭, % | 클릭·전환 정의·귀속 필요 | 현재 자료 없음·생성 대기 |
| CPA/ROAS | 광고비/전환, 귀속매출/광고비 | 전환 0 또는 광고비 0 처리·귀속·통화 명시 | 현재 자료 없음·생성 대기 |
| 긍정률·평점 | 긍정/전체, 척도 내 평균 | 감성 합계·유효 표본·평점 척도 필요 | 기존 집계 있으나 D001 밖 |

합산 기간의 비율은 원천 분자·분모 합계에서 계산한다. 이미 계산한 비율의 단순 평균으로 대체하지 않는다. 검색 관심값은 실제 검색 횟수 단위라고 확정하지 않고 현재 데모 정의로 표시한다.

## 추적성과 검증 설계

| 문제·출처 | 질문 | 핵심 관계 | 검사 |
| --- | --- | --- | --- |
| H04, S07 | Q01/Q02 | IN_SCOPE, ABOUT_PRODUCT, MEASURES | 기간·시장·대상·수집 기준 혼입 금지 |
| L03/L05 | Q03 | INPUT_OBSERVATION, USES_METRIC | 기여 합=차이, pt/pp/% 구별 |
| U01, S03/S08 | Q04 | SUPPORTS, COUNTERS, DERIVED_FROM | 근거 없는 인과·확률 금지 |
| H05, L01 | Q05 | JUSTIFIES_ACTION | 비광고 대응·유지·복구도 가능 |
| U01, S05 | Q06 | HAS_ALLOCATION, USES_MODEL | 현행 대조, 목표·제약·가정 명시 |

검사는 승인된 기존 자료로 수행한다. 변형 자료·실패용 fixture가 필요하면 생성 규칙을 별도 제안해 승인받는다. 미승인 레코드를 테스트 명목으로 만들지 않는다.
