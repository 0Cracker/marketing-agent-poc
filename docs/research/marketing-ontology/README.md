## 사용자 지시와 적용 경계

- 자료조사·설계 근거는 문서와 대화에 모두 공유한다. 외부 사실, 저장소 사실, 사용자 요구, 설계 가설을 구분한다.
- 데이터 생성·수정·재사용·변환·보완은 구체적 제안을 보여준 뒤 명시 승인한다. 예시·테스트·seed도 동일하다.
- 승인된 새 가상 원천은 D003B의1,652행이다. 조사용40유형 명세와 구별하며 적재된 데이터 그래프는 없다.
- 기업 내부 온톨로지 자료가 없으므로 독자 설계다. 해당 기업 모델의 재현으로 표현하지 않는다.
- 계획 실행 요청은 데이터 제안의 자동 승인이 아니다. 목표 선택도 현재 미확정이다.
- 조사 문서 작성과 Git 발행은 다르다. 기존 규약에 따라 커밋·push·태그·Release는 수행하지 않았다.

## 기존 자료와의 관계
