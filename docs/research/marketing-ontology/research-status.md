# 조사 기록의 현재 확인 범위

2026-10-14 추가: [MC-1.0.0 공식 근거·확인 수준](common-contract/mapping-notes.md)에 W3C·Google 필드·Meta 공식 SDK·Shopify·방법론 자료의 확인 수준을 남겼다. 공식 사실·우리 설계·D003B 모의 가정·미확정을 구분했다. 기존 S/L 근거 누락은 복원하지 않았다. LOT 사이트 접근 실패는 저자 소개/리소스 확인으로 보완했고 NeOn 직접 본문은 재확인하지 못했다.

2026-10-13. 현재 작업 트리에는 이전 문서가 참조한 `evidence-register.md`가 없다. S01–S14와 L01–L06의 전체 설명·출처 대응을 이 파일에서 복원하거나 추정하지 않는다. 해당 ID를 사용하는 초기 문제·질문·온톨로지 문서는 근거 재확인이 필요한 초안이다.

현재 확인 가능한 자료는 [M01–M44 소스 목록](data-source-register.md)이다. 최신 [필드 사전](field-dictionary.md)은 이 목록의 M 식별자와 명시적인 설계 가설을 사용한다. 본문·코드·부분 확인·접근 실패를 구분했고, 소개 문서를 읽은 것을 실제 계정 데이터 확보로 취급하지 않는다.

추가 근거와 설계 영향:

| 자료 | 알게 된 점 | 설계 영향 | 남은 확인 |
| --- | --- | --- | --- |
| M40 네이버 쇼핑 | 상품·분류·판매처·가격 필드 | 한국 상품 매핑·offer 관측의 근거 | 실제 조회 권한·상품 연결 정확도 |
| M41 쇼핑인사이트 | 클릭의 상대 추이 | 관심 지수를 주문·검색 절대량과 분리 | 실제 분야·검색어·조회 범위 |
| M42 Google taxonomy | 외부 분류 체계 | 제품 분류 매핑에 버전·출처 보존 | 사용할 분류 코드·비교 적합성 |
| M43 KOSIS | 통계표 접근 경로 | 외부 한국 통계를 별도 문맥 관측으로 설계 | 개별 통계표·기준 기간 |
| M44 BLS | series·기간·값·각주 구조 | 미국 외부 통계의 단위·기준 보존 | 개별 series·국가 간 비교 가능성 |

필드의 필수 여부·30개 질문·수량 배분·가상 가격 범위는 우리의 설계 제안이다. 공급자나 현업이 그 범위를 보증한 사실이 아니다. 사용자 국가·비교 방식·대략적인 규모 선택과 실제 데이터 생성 승인은 구별한다.
