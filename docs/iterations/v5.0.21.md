# v5.0.21 기존 목표 ROAS 기준선 표시

- 날짜: 2026-11-17
- 기준: v5.0.20
- 작업 브랜치: `claude/gracious-cannon-ebmc8y`
- 범위: QA F11. 기존 데이터의 목표 ROAS를 ROAS 카드와 추이에 표시한다. 새 데이터, 스키마와 계산 계약 변경은 없다.

## 문제

비교 기준이 직전 14일뿐이라 284.7%가 좋은지 나쁜지 판단할 기준선이 없었다.

## 선택과 이유

- QA 리포트는 목표값이 없으면 신규 데이터 생성 승인이 필요하다고 했다. 사용자도 신규 데이터를 승인하겠다고 했다. 그러나 확인해 보니 18개 사례의 모든 캠페인에 이미 `targetRoas: 3.5`가 있고, [ROAS 교육용 공통 대시보드](../design/roas-training-dashboard.md)의 실행 조건에 "가상 목표 ROAS 350%"가 기록돼 있었다. 그래서 신규 데이터를 만들지 않고 기존 값을 재사용했다. 데이터 승인 기록은 갱신하지 않는다.
- 조회 범위의 캠페인 목표가 하나로 같을 때만 표시한다. 목표가 서로 다르면 집행비 가중 평균 같은 새 정의를 만들지 않고 표시하지 않는다.

## 변경

- `frontend/roas/training-target.ts`의 `scopeTargetRoas`: 범위 안 캠페인의 목표가 하나면 그 값을, 다르거나 없으면 null을 돌려준다.
- ROAS 카드에 "목표 ROAS 350.0% 대비 ±N%p, 목표 달성/미달", ROAS 추이에 주황 점선 목표선을 추가했다. 다른 지표에는 그리지 않는다.
