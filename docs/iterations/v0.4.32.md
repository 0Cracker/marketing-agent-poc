- 날짜: 2026-11-17
- 기준: `e2612c4cfa0a5907e25d2bd8f05f6b7a775c287d` (v0.4.31)

- 범위: 답변 형식 개선 계획 4단계. 실제 실행 답변(`RoasRunView`) 아래의 디버그 정보 배치만 바꾼다.

## 문제

답변 아래에 "실행 정보와 근거"와 "실제 조회, 모델 호출 기록"이 따로 있었다. 실행 정보에는 실행 ID와 해시가 들어 있었고, 사용자가 읽는 근거(v0.4.29의 참고한 자료)와 개발자용 실행 정보가 섞여 보였다. 한계 문구가 없을 때도 빈 영역이 렌더링돼 여백만 남았다.

## 선택과 이유

Databricks Genie처럼 답변에는 설명과 결과만 두고, 생성 과정(SQL, 사고 단계)은 "Show code" 같은 접힌 영역으로 분리했다. 실행 중에는 진행 상황을 볼 수 있도록 지금처럼 펼친다.

## 변경

- 실행 메타데이터와 호출 기록을 `분석 과정 보기` 하나로 합쳤다. 요약 줄에는 호출 건수와 근거 ID 개수를 표시한다. 펼치면 호출 기록이 먼저, 실행 ID와 해시가 그 아래에 나온다. 완료 후에는 접히고, 실행 중에는 펼쳐진다.
- 표시할 한계 문구가 없으면 한계 영역을 렌더링하지 않는다.
- 표시 정보의 종류(실행 ID, 범위 식별값, 자료 해시, 근거 ID, 원천 해시, 이벤트 상세)는 그대로 유지했다.
