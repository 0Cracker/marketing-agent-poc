# v0.4.3, ROAS 대화 UI와 대시보드 표현 개선

- 이전 버전: v0.4.2, 시작 SHA `c340db74521fe86f348dd6885b6032db1cac1566`.
- 날짜: 2026-10-27, dev 패치. 사용자 요청으로 작업 내용을 목적별 커밋과 패치 버전으로 정리한다.
- main 병합, 태그와 Release는 범위 밖이다.

## 변경

ROAS 화면에 공통 AI 패널을 연결하고 현재 조회 범위, 결론과 근거, 비교 표와 그래프, 인용 원천과 연결 복구를 제공한다. 대화는 같은 페이지 세션에서 조회 범위별로 유지한다. 서버 API와 답변 계약은 v0.4.2를 사용한다.

표 설정과 탐색 이력을 보존하고 진입 지표에 맞춰 열을 정리했다. 작은 추이는 두 기간의 공통 축을 사용하고 개선, 악화와 중립 색상을 구분한다. 기기 조회는 상세에서 선택하고 캠페인 전체 선택 버튼은 목록 헤더에 배치했다.

핵심 ROAS 카드는 넓은 카드와 큰 숫자, 지그재그 방향 화살표, ▲/▼ 증감으로 강조한다. 비교 문구는 `직전 14일: 355.8%` 형식이며 값은 조회 조건에 따라 바뀐다. 비율 차이는 %p로 유지하고 카드 내부 중복 막대는 제거했다. 기존 대시보드 진입 메뉴는 `(구) 대시보드`로 바꿨다.

## 한계와 운영

실제 모델 자유 해석의 완전한 정확성, 전 사례 UI와 실제 모바일 기기 사용성은 미검증이다. 최종 지그재그 카드의 PC 화면은 확인했으며 같은 후속의 모바일 재검증은 하지 않았다. AI 답변에는 기존 로컬 서버 또는 명시적으로 설정한 API 연결이 필요하며 Vercel 화면 배포만으로 AI 서버가 실행되지 않는다. 이번 정리에서 외부 모델을 새로 호출하지 않았다.

package.json과 package-lock.json의 루트 버전은 0.4.3으로 맞췄다. 사용자 승인 범위에 따라 두 개발 커밋을 dev에 push하고 원격 SHA와 Vercel 체크를 확인한다. 실제 push와 배포 결과는 원격 조회를 근거로 별도 보고하며, 이 문서는 커밋 전 검증 기록이다.
