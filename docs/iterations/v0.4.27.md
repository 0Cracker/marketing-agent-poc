# v0.4.27 QA 공용 비밀번호 길이 조건 완화

- 날짜: 2026-11-12
- 기준: origin/dev `2426fa9` (v0.4.26)
- 작업 브랜치: `fix/qa-password-min-8-20261112`
- 범위: Vercel Preview QA 로그인 설정 최소 길이를 16자에서 8자로 조정, 7자 거부 및 8자 허용 회귀 검사

## 변경 근거

PoC QA 공용 계정에서 16자 비밀번호는 사용성이 떨어진다는 사용자 피드백에 따라 최소 기준을 8자로 조정했다. 세션 서명 및 Agent 서버 간 HMAC 키는 기존 32자 이상 요건을 유지한다. 실제 모델, 광고 원천, 대시보드 데이터는 변경하지 않는다.

## 검증

- Node 24 로컬 격리 게이트웨이 스모크: 8자 로그인 성공, 7자 설정 거부, 틀린 비밀번호 거부 (통과).
- 테스트: `tests/agents/integration/qa-gateway.test.mjs`의 경계 조건 검사 추가.
- 전체 CI: 브랜치 PR 검증 결과에 따름.
- 외부 Vercel Preview 로그인 및 Cloudflare Tunnel E2E는 미검증.

## 적용 참고

Vercel Preview, dev 전용 `QA_LOGIN_PASSWORD`는 8자 이상으로 설정할 수 있다. 값 변경 후 새 배포(Redeploy)가 필요하다. 기존 로그인 세션을 강제 만료하려면 `QA_SESSION_SECRET`을 회전한다.
