# v0.4.9, 성과 현황 아래 지표 상세 탐색

- 날짜: 2026-10-28, dev 패치. 이전 버전 v0.4.8, 시작 SHA be1ef40.
- 사용자 선택: 성과 현황 내부의 지표 상세를 왼쪽 메뉴에서 계층으로 표시.

성과 현황 아래 지표 상세 그룹과 CTR, CPC, CVR, CPA, AOV 바로가기를 배치했다. 그룹명은 별도 화면을 만들지 않는 안내이며 현재 화면만 강조한다. 중복 가로 탐색 바를 제거하고 기존 카드 진입, 텍스트 경로 복귀, 필터와 브라우저 이력 처리를 유지했다.

ROAS 상세 진입은 제거하고 메인의 캠페인별 비교로 스크롤하도록 바꿨다. 신규 고객 수가 없어 계산할 수 없는 CAC는 미집계 카드만 남겼다. 기존 ROAS, CAC 이력은 성과 현황으로 복원한다. 모바일은 기존 메뉴 열기와 선택 후 닫기를 따른다. 원천과 스키마는 변경하지 않았다.

[검증과 한계](../../evidence/sidebar-navigation-20261028/validation.md): 데이터 검사 24개, 타입, 대상 린트와 빌드 통과. 실제 브라우저에서 지표 직접 이동, 뒤로 가기, 경로 복귀와 화면 계층을 확인했다. 모바일 실기기는 미검증이다.

패키지와 잠금 파일의 루트 버전은 0.4.9다. dev 커밋과 push, Vercel 확인 범위이며 main, 태그와 Release는 수행하지 않는다. 시작부터 존재한 삭제 3개는 제외한다.
