# v0.4.5, 즉시 열리는 예시 대화와 S16 복합 변화

- 날짜: 2026-10-27, dev 패치. 이전 버전 v0.4.4, 시작 SHA `84d0046`.
- 목표: 예시 클릭만으로 질문과 답변을 보고, AOV 개선이 CVR과 CPC 악화를 일부 상쇄하는 사례를 해석한다.

## 문제와 결정

기존 예시 버튼은 입력창에 문구만 넣었고 서버 연결이 없으면 답변을 볼 수 없었다. 첫째와 셋째 질문을 유지하고 둘째를 “ROAS가 떨어졌는데 AOV, CVR, CPC가 모두 변해서 원인을 모르겠어. 각 지표가 ROAS 변화에 얼마나 기여했는지 나눠 보고, 무엇부터 확인해야 할지 알려줘.”로 변경했다.

별도의 고정 수치나 서버 호출 대신 기존 기간 집계와 답변 컴포넌트를 재사용한다. 예시는 선택한 사례와 캠페인, 기기에 맞춰 계산하고 “예시 답변”으로 표시한다. 근거를 클릭하면 실제 집계에 포함된 행을 볼 수 있다. 다른 예시도 연속해서 열 수 있으며 일반 질문은 기존 AI 서버를 사용한다.

사용자는 복합 변화 중 하나가 개선되도록 데이터를 수정하길 요청했고, [구체적인 S16 변경안](../research/marketing-ontology/data-proposal.md#2026-10-27-s16의-aov-개선과-roas-하락-복합-사례-승인-실행)을 최종 승인했다. 할인 종료를 성과 168행, 분할 840행과 기존 구조의 변경 기록 3건에 반영했다. 다른 사례와 원천은 보존했다. 재생성 CLI의 Evidence 저장 위치를 이번 작업 폴더로 옮겨 과거 검산 결과를 덮어쓰지 않는다.

## 결과와 검증

AOV는 38,712.4원 → 40,847.5원으로 개선되고 CVR은 4.9% → 4.2%, CPC는 531.9원 → 596.3원으로 악화됐다. ROAS는 355.8% → 284.7%다. 여섯 가지 교체 순서의 평균 기여도는 각각 +17.2%p, -51.8%p, -36.5%p다. 예시는 CVR부터 확인하도록 안내하며 수식상 기여와 실제 원인을 구분한다.

[검증 기록](../../evidence/roas-examples-20261027/validation.md)에 실제 명령과 결과, [수정 범위 검증](../../evidence/roas-examples-20261027/data-validation.json)에 전후 수치와 보존 해시를 기록했다. 관련 회귀 107개와 독립 수치 검산 97,067항목이 통과했다. Chrome에서 수정된 S16의 KPI와 둘째 예시 질문, 답변을 확인했다. 실제 모델 출력과 마케터 학습 효과, 모바일은 미검증이다.

package.json과 package-lock.json 루트 버전을 0.4.5로 맞춘다. dev에 한 목적의 커밋으로 반영하며 main, 태그, Release는 이번 범위에 포함하지 않는다. 원격 배포 상태는 push 후 실제 커밋으로 확인한다.
