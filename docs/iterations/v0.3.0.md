# v0.3.0 · 대시보드와 CURRENT 자료 통합

상태: 로컬 검증 완료, 정식 미발행. 사용자 승인으로 2026-10-15~19 화면 작업을 이 버전으로 분류했다. 시작 기준은 v0.2.0의 d5f437727d8a704aeb296b134bebee693578e0d3다. 사후 정리 순서는 실제 작업 발생 순서와 구분한다.

## 변경과 이유

- 기존 워크벤치·검색형 필터·글꼴·브랜드/제품 계층·리뷰/KPI 피드백을 보존했다.
- 원천 조회와 화면 계약을 분리하고 표준 조회·업무별 차트·국가 비교를 추가했다.
- 기존 D008 자료와 CURRENT 활성 30,315행·보존 52,636행을 그대로 커밋했다. 새 자료는 생성하지 않았다.
- CURRENT manifest·파일 해시·업무 키·archive를 검증하고 필요한 유형만 적재한다. 과거 물리적 CRLF/LF 복사본은 archive에서 정확한 바이트를 보존한다.
- 이 체크포인트의 진입 버튼은 ‘근거 보기’이며 실행 가능한 에이전트와 HTTP 프록시는 v0.4.0에서 추가한다.

## 검증

[실행 목록](../../evidence/version-arrangement/checks.json)과 [로그](../../evidence/version-arrangement/logs/screen-current-data.txt)를 따른다. 화면 계약496조합·표준123조회·기존22,242행 전수 접근·비교323조회, 단계별 타입 검사와 빌드를 통과했다. 브라우저에서 CURRENT 일본 시장 화면과 국가별 비교 전환, 오류 경고 없음과 가로 넘침 없음을 확인했다. 이번에 과거272화면 전수를 재실행했다고 주장하지 않는다.

## 한계

v0.2.0 전체 회귀는 원본 절대 경로에서 7게이트·52질문 pass/complete다. [입력 대조](../../evidence/version-arrangement/v0.2.0/checkpoint-inputs.json)는 해당 체크포인트와 158개 입력의 바이트 동일성을 확인했다. 새 worktree의 승인·OOPS 절대 경로 제약은 유지하며 원본 기록을 수정하지 않았다.
