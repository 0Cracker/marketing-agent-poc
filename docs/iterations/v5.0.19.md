# v5.0.19 작은 추이 차트의 날짜와 읽는 법

- 날짜: 2026-11-17
- 기준: v5.0.18
- 작업 브랜치: `claude/gracious-cannon-ebmc8y`
- 범위: QA F09. 성과 현황의 작은 추이 차트에 날짜와 읽는 법을 더한다. 축 범위 계산(`miniPlotDomain`)은 바꾸지 않는다.

## 문제

작은 차트에는 날짜 축이 없었고, 점선이 같은 날짜가 아니라 직전 14일의 같은 요일이라는 설명도 없었다. 세로축 범위가 지표마다 달라 CTR +0.06%p는 급등처럼, ROAS -71.1%p는 완만하게 보였다.

## 선택과 이유

모든 작은 차트를 0부터 시작하는 공통 축으로 바꾸면 형태 변화가 보이지 않는다. 기존 UX-06의 지표별 공통 축 결정을 유지하고, 날짜와 읽는 법을 텍스트로 보완했다.

## 변경

- ROAS 구성 지표 머리말에 실선과 점선의 뜻, 변화 크기는 증감 숫자로 비교하라는 안내를 추가했다.
