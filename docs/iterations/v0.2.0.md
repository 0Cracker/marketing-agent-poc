## Discover — 문제와 근거

v0.1.0은 고정 Mock 시연이다. 다음 단계의 국가·제품 비교와 일본 상세 조사는 지표 의미·시간·출처·원천 연결을 검증해야 한다. 이전 CTI/Neo4j 가정과 실제 원천 정의를 그대로 공통규약으로 확대하면 잘못된 집계·원인 단정이 생길 수 있다.

미커밋 작업에는 프론트/데이터 폴더 이동, 기존 문서 삭제, 원천 조사·40유형 스키마, 승인된 D003B와 공통 의미 규약이 함께 있었다. 사용자가 지금까지 작업을 규칙에 맞게 커밋해 보존하도록 요청했다. 삭제 상태도 기존 작업으로 유지하고, 이전 내용은 시작 SHA의 Git 이력에서 조회할 수 있게 한다.
