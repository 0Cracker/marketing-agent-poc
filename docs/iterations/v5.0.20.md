## 변경

- F13 KPI 카드 순서: 현재값과 증감이 먼저, "직전 14일: …" 비교 문구가 그 아래에 온다.
- F14 리뷰 표: 표시 중인 행에 원문 링크가 하나도 없으면 "원문 확인" 열을 숨긴다. 현재 리뷰 85건은 모두 링크가 없어 5열로 표시된다. 기존 열 구성 회귀를 이 계약으로 바꿨다.
- F15 운영 기록: "연결 기록 33건" 아래에 "기간 중 변경 9건 + 시작 시점 설정 24건"을 표시한다.
- v5.0.18 보정: 단계 전환율을 소수 한 자리 %p로 판정해 반올림 차이를 "악화"로 표시하지 않는다. 같은 값은 "변화 없음"이다.
- v5.0.15 보정: 추천 탐색 순서의 번호가 공통 CSS에 지워져 다시 표시했다.
