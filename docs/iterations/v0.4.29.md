# v0.4.29 답변 근거 태그의 번호 칩 표시

- 날짜: 2026-11-17
- 기준: `5d3a3fd` (v0.4.28)
- 작업 브랜치: `claude/fervent-lovelace-50b3me`
- 범위: 답변 형식 개선 계획 2단계(A안). 프런트 렌더링만 바꾼다. 모델 지침, 서버 저장 계약, 근거 ID 연결은 바꾸지 않는다.

## 문제

`answer-guide.md`는 모델이 핵심 수치 뒤에 `[근거: 자료 / 지표 또는 기록 / 대상·기간]`을 쓰도록 한다. 지금까지는 이 태그가 회색 문장으로 본문에 그대로 나와서, 표본 답변 분량의 약 3분의 1을 차지했고 읽는 흐름을 끊었다.

## 선택과 이유

Intercom Fin은 출처를 기사 제목 링크나 하단 목록으로 보여주다가, 문장 끝의 작은 번호 표시로 바꿨다. Perplexity와 ChatGPT 검색도 같은 방식을 쓴다. 이를 참고해 본문에는 번호만 두고, 상세 내용은 눌렀을 때 펼치기로 했다.

두 가지 안을 비교했다.

- A안: 렌더러가 기존 텍스트 태그를 파싱한다.
- B안: 모델이 짧은 근거 ID를 쓰게 하고, 서버가 이를 `evidenceIds`와 원천 행에 연결한다.

B안은 지침의 "내부 근거 ID 미사용" 조항과 SDD 계약을 바꿔야 하므로 후속 결정으로 남겼다. 사용자가 계획을 승인해 A안으로 진행했다.

## 변경

- `collectCitations`를 추가했다. 태그 내용을 공백 정규화한 뒤, 같은 근거는 하나의 번호로 합친다.
- 본문, 목록, 표 셀의 태그를 번호 칩(`wb-run-cite`)으로 렌더링한다. 칩을 누르면 해당 블록 바로 아래에 자료 / 지표 또는 기록 / 대상·기간 카드를 펼치고, 다시 누르거나 닫기 버튼을 누르면 접는다.
- 표 아래처럼 근거만 있는 줄은 본문 문단 대신 작은 "근거 n" 줄로 표시한다.
- 답변 끝에 접힌 상태의 "참고한 자료 N개" 목록을 추가했다.
- 태그가 없는 답변은 이전과 같이 표시한다.

## 검증

- UI 테스트 15개 통과. 근거 칩 테스트 2개를 추가했다.
- `npx tsc --noEmit -p .`, `npx eslint frontend/roas tests/agents/ui`: 종료 코드 0.
- mock 화면 캡처(1440px, 390px, 첫 근거 칩 클릭 상태): 페이지 오류 0건, 페이지 가로 스크롤 없음.
- 칩은 모델이 쓴 텍스트를 보여줄 뿐, 실제 조회 결과와 대조하지 않는다. 원천 행 연결(B안)은 미구현이다.
