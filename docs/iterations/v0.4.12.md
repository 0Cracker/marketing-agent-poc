# v0.4.12, 상세 표 간소화와 정렬 수정

- 날짜: 2026-10-28, dev 패치. 이전 버전 v0.4.11, 시작 SHA `d79baf7`.
- 사용자 요청: 행을 펼쳤을 때 보고서 대신 데이터 표시, 보조 설명을 용어 옆 (i)로 이동, 운영 기록 영역 제거, 증감 색상 수정, 전체 범위 퍼널 제공, ROAS 보조 지표 상시 표시와 간격 정리.

행 확장의 기본 내용은 직전, 현재, 증감 표다. 일별 추이, 퍼널과 결제, 상품, 도달 데이터는 별도로 펼친다. 계산 해설, 기준 설정과 소재 원문, 운영 기록을 화면에서 제거했다. 원천 데이터는 보존한다.

설명 문장은 표 머리글, 지표 이름과 퍼널 제목 옆 (i)에서 확인한다. 별도의 구성 지표 설명 카드는 제거했다. ROAS의 보조 지표와 추이는 접지 않고 분석 표보다 먼저 배치한다. CVR과 CPA는 행 선택 전부터 현재 조회 범위의 구매 퍼널을 표시한다.

클릭수, 노출수와 구매 단계 도달수의 증가는 빨강, 감소는 파랑으로 표시한다. 비용 지표의 방향과 0 증감 중립 처리는 유지한다. 정렬 버튼의 기본 32px 높이가 정보 아이콘과 다른 기준선을 만들던 문제를 공통 20px 줄로 맞췄다. 셀 여백, 수치 우측 정렬, 두 줄 값의 간격, 행 펼침 아이콘과 툴팁 위치를 통일했다.

375px 검사에서는 숨겨진 차트 툴팁의 이전 위치가 본문 가로 넘침을 만드는 문제도 발견했다. 숨겨진 툴팁에만 위치 변환을 해제해 본문 폭을 731px에서 360px로 수정했다.

[검증 기록](../../evidence/kpi-table-cleanup-20261028/validation.md)에 실제 화면 측정과 자동 검사 결과를 남긴다. 기존 사례를 사용하는 45개 검사, 타입, 변경 파일 린트와 빌드를 통과했다. 원천과 API 계약은 변경하지 않았다. 기존 삭제 3개는 이번 커밋에서 제외한다. 원격 배포, main과 태그는 이번 작업 범위에 포함하지 않는다.
