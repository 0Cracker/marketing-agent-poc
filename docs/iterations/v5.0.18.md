# v5.0.18 구매 퍼널 단계 전환율 비교

- 날짜: 2026-11-17
- 기준: v5.0.17
- 작업 브랜치: `claude/gracious-cannon-ebmc8y`
- 범위: QA F08. CVR 상세의 구매 퍼널에 단계 전환율 비교와 가장 크게 나빠진 단계 표시를 더한다. 집계와 막대는 그대로 둔다.

## 문제

S16은 랜딩 세션이 44% 늘어 모든 막대가 길어졌다. 실제 신호인 단계별 전환율 악화(상품 조회→장바구니 16.6%→14.9%, 결제 시작→구매 60.0%→56.7%)는 회색 이탈 캡션에만 있었다.

## 선택과 이유

막대를 전환율 차트로 바꾸는 안도 검토했다. 그러나 유입량 변화도 판단에 필요하고, 기존 표시 계약과 회귀 검사를 크게 흔든다. 그래서 막대는 유지하고 단계 이름 아래에 "이전 단계 대비 전환율 직전 → 분석, 증감"을 더했다. 가장 많이 떨어진 단계에 배지를 붙였다.

## 변경

- `frontend/roas/training-funnel.ts`의 `worstStage`: 단계 전환율이 가장 크게 떨어진 단계를 고른다. 오른 단계와 계산할 수 없는 단계는 제외한다.
- 퍼널 각 단계에 전환율 비교와 개선/악화 표시(`viewRate`, `cartRate`, `beginRate`, `checkoutRate` 방향 규칙)를 추가했다. 최악 단계에는 "가장 크게 나빠진 단계" 배지와 배경을 표시한다.
