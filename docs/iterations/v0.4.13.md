# v0.4.13, 열 제목에서 증감 정렬

- 날짜: 2026-11-02, 로컬 작업 브랜치 `fix/kpi-header-sort`. 이전 버전 v0.4.12, 시작 SHA `3488c8d`.
- 사용자 확정: 현재값 정렬과 별도 정렬 목록을 없애고 표 머리글에서 증감 기준으로 정렬한다. 현재값과 증감은 같은 셀에 유지한다.

각 수치 열 제목의 ▲▼를 클릭하면 증감 내림차순과 오름차순이 전환된다. 비율 지표는 %p 변화, 금액과 건수는 상대 증감률을 사용한다. 전체 변화 기여는 기여값을 정렬한다. 선택 열과 방향을 강조하고 `aria-sort`와 키보드 버튼 조작을 제공한다. 기존 지표별 설정과 화면 복귀 상태를 재사용한다.

열은 선택 KPI, 전체 변화 기여, 설명 지표, 분자와 분모 순으로 배치했다. ROAS의 설명 지표는 클릭 비용, 구매 전환, 주문 금액 순이다. CPC는 노출 단가와 클릭 반응, CPA는 클릭 비용과 구매 전환을 앞에 둔다. CTR은 노출 비중, AOV는 할인율을 먼저 확인한다. CVR의 세션 구매율은 클릭 기준 CVR과 다른 집계 기준의 보조 지표다. 분자와 분모를 숨기거나 원천, API와 기여도 계산을 변경하지 않는다.

기존 순서에서 새 우선순위 검사가 실패하는 것을 확인한 뒤 구현했다. 46개 회귀 검사, 타입 검사, 변경 파일 린트와 빌드를 통과했다. 린트의 기존 pages 경로 안내와 빌드의 기존 폰트 경로 경고는 남아 있다. [화면과 검증](../../evidence/kpi-header-sort-20261102/validation.md)에 실제 확인 범위를 기록한다. 원격 push와 배포는 수행하지 않는다. 기존 미커밋 문서 변경과 삭제 파일은 이 작업에 포함하지 않는다.
