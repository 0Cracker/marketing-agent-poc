# v0.4.17, ROAS 분석표 증감 기준 정렬

- 날짜: 2026-11-02, 작업 브랜치 `fix/roas-change-column-sort`, 이전 버전 v0.4.16, 시작 SHA `4f8faf6`.
- 사용자 확인: ROAS 성과 현황의 주 분석 테이블에서 ROAS, CPC, CVR, AOV, 매출, 집행비 등 모든 수치 컬럼은 위쪽에 강조된 증감값으로 오름차순과 내림차순을 정렬한다. 비율 지표는 퍼센트포인트, 그 외 값은 직전 기간 대비 상대 증감률이다. 전체 변화 기여 컬럼은 기존 기여값을 사용한다.
- 다른 CTR, CPC, CVR, CPA, AOV 상세 페이지에서는 현재값 우선 표시와 현재 기간의 실제 수치 정렬을 유지한다. ROAS 화면의 위쪽 증감, 아래쪽 현재값 배치도 유지한다. 데이터, 집계 산식, API와 근거 표는 변경하지 않는다.
- 검증: `node --experimental-strip-types --test tests/training-analysis.test.ts` 10개 통과. ROAS 변화량 정렬과 기타 상세페이지 실제값 정렬을 같은 회귀 검사에서 확인한다. 화면 수동 검증은 미실행이며 배포는 수행하지 않는다.
- 범위 통제: 기존 미커밋 문서, 설계 파일, 테스트 및 원천 데이터 관련 작업은 커밋에서 제외한다.
