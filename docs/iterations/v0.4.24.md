## 반영 내용

- Jev 기반 단계별 도구 선택, Quick/Deep 실행 흐름, 7개 데이터 도구, 세션 상태와 SQLite 실행 기록, 취소, 모델 자동 전환을 연동.
- 최종 생성 답변은 Markdown 형식으로 표시하고 서버가 계산한 근거 데이터를 사용. 자동 답변 내용 재검증 또는 답변 보류 로직은 이전 합의대로 적용하지 않음.
- Deep 답변 대체 경로에서 Flash-Lite 대신 GLM을 사용. 실패 단계, 원인 코드, HTTP 상태를 실행 로그에 표시.
- 생성용 입력의 반복 메타데이터와 불필요한 날짜별 전체 집계를 제거하고 선택 지표 및 계산용 분자, 분모는 보존.
- 별도 Agent Trace UI와 빌드 설정, 재현 스크립트, 테스트 및 증거 기록 추가.
- ROAS Agent CI에 `test:agents`, ROAS/Training 회귀, lint, 기본 빌드, Agent Trace 빌드를 등록.

- 외부 실제 모델 API 호출과 실제 과금 확인은 이번 통합 검증에서 수행하지 않음. 회귀 검사는 mock 및 오프라인 경로 중심.
