# v5.0.14 AI 연결 상태 문구 정리

- 날짜: 2026-11-17
- 기준: v5.0.13
- 작업 브랜치: `claude/gracious-cannon-ebmc8y`
- 범위: QA F10 남은 부분. 대화 패널의 연결 상태 문구만 바꾼다. 서버 모드 값과 응답 계약은 바꾸지 않는다.

## 문제

로컬 대체 응답 모드(`offline_model_substitute`)에서 입력창 아래와 답변 머리글에 "오프라인 연결 확인"이 나왔다. 서버에 연결된 상태인데도 "지금 오프라인인가?"로 읽혔다.

## 변경

- 입력창 아래: "연결됨, 로컬 대체 응답 모드: 실제 AI 모델을 호출하지 않습니다." 실모델 연결 시 "연결됨, AI 답변의 수치와 근거를 확인하세요."
- 답변 머리글: "로컬 대체 응답". 예시 답변과 실모델 "분석 완료"는 그대로다.
- 서버 응답 본문의 "오프라인 연결 확인 결과입니다."는 서버 계약과 회귀 테스트가 고정하고 있어 이번 범위에서 바꾸지 않았다.
