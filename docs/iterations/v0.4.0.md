2026-10-19 사용자 승인으로 버전 경계를 재분류했다. 아래 기록은 원래 v0.2.0에 작성된 에이전트 작업이며 날짜·실행 결과·실패를 유지해 이동했다. 증거의 기존 경로는 역사적 식별자이므로 유지한다. 정식 발행을 뜻하지 않는다.


## 2026-10-19 · CURRENT 실제 모델 전체 흐름

사용자가 일본·2026년8월·6제품, 실패분 포함 최대24회 계획을 승인했다. [실행·결과 기록](../design/current-live-20261019.md)에 CURRENT 같은 dataHash의 분석·원문·후속 질문·예산·가상 승인·승인 복원·재고 후속 분석 무효화·최종 복원을 연결했다. 최종 기준선16시도와 이전 실패 기준선5시도를 합해21/24회다. 예산의 timeout·503을 보존하고 같은 설정의 한 차례 새 검토가 성공했으며 자동 키 순환은 없다. 승인·무효 상태 각각 재시작 후 같은 ID/버전/승인·무효 상태와 질문 이력을 복원했고 추가 모델 호출0이다.

전용 DB 경로와 fork 부모의 정상 종료, 키 없는 공급자 진단, 기존 API를 관찰하는 검증 제어기·독립 Python Decimal 예산 검산을 추가했다. Agent111·프런트18·타입 검사pass, 현재41유형/메타데이터·기존DB·양쪽HEAD 불변을 확인했다. 승인 상태는 실제 모델 reallocate 결과로 도달했으며 수동 후보 수정은 필요하지 않았다. 기존 미커밋 작업을 보존했고 커밋·발행·원천/마케팅 명세 변경·실제Ads는0이다. 대표 JP 흐름의 검증이며 모든 질문 품질·사람 수용·모바일·실제 집행 검증으로 확대하지 않는다.

## 2026-10-19 · 실제 LLM 도구 선택과 채팅 시각화

사용자가 Flash·Flash Lite·Gemma 중심 배치, 번호형 키 저장과 계속 진행을 요청해 기존 실행기를 실제 모델 모드에 연결했다. 분석은 Flash Lite, 예산은 Flash를 기본으로 하고 키는 한 개를 명시 선택한다. 같은 프로젝트 키를 429 우회용으로 순환하지 않는다. Gemma는 짧은 JSON 생성만 확인했으므로 기본 업무 배치에서 제외했다. 기존 미커밋 변경을 보존했으며 Git 발행·원천·마케팅 명세·실제 Ads는 변경하지 않았다.

실제 호출에서 응답 봉투 누락·미발급 사실 참조·반대 근거 누락이 검증에 걸려, 기존 계약을 공급자 JSON Schema로 제한했다. 최종 실제 흐름은 분석3호출·예산3호출로 통과했고 예산 모델은 동일 가상 계산 후 현행 유지·추가 조사를 선택했다. UI에는 기존 결론·행동 안내를 유지하며 수치 카드·점유율 그래프·원인 비교표·원문 카드·최근 대화·수동 재개를 연결했다. 설명 문장은 현재 검증 결과의 템플릿이다.

백엔드109/109·프런트17/17·타입 검사·Vite 빌드 통과, 실제 브라우저 분석·근거 링크·390px 넘침 검사를 확인했다. 실패 시도와 최종 결과를 구분해 [구현·검증 기록](../design/agent-live-20261019.md)에 연결했다. 전체 질문 품질·Gemma 업무 흐름·실제 집행을 완료했다고 보지 않는다. 새 버전·태그·커밋은 만들지 않았다.
