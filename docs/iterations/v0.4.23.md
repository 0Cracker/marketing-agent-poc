# v0.4.23 ROAS 캠페인 집계 및 열 순서 개선

- 일자: 2026-11-09
- 기준: `origin/dev` `1285419` (`v0.4.22` 보조 지표 가독성 변경 보존)
- QA: Jira KAN-2, 캠페인 분석 단위 선택 시 동일 상위 캠페인의 하위 집행 항목이 개별 행으로 보이는 문제
- 변경: S16 교육용 데이터의 `EDU-C1~C4`를 '8월 구매 캠페인', `EDU-C5~C6`을 '8월 콘텐츠 제휴'로 표시한다. 상위 캠페인 행을 펼쳐 하위 집행 항목의 원천 데이터와 지표를 조회할 수 있다.
- 정합성: 직전 14일과 현재 14일의 원천값을 따로 합산한 뒤 ROAS, CPC, CVR, AOV 및 전체 변화 기여를 계산한다. 명시적 상위 그룹 ID를 사용해 동명이인 캠페인 병합을 방지하며, 하위 기여 합은 상위 기여와 같다.
- UI: ROAS 상세 표 열 순서는 `전체 변화 기여 → ROAS → CPC → CVR → AOV → 귀속 구매 매출 → 유료 마케팅 집행비`. 다른 지표 상세 표는 기존 순서 유지.
- 검증: `tests/roas/training-analysis.test.ts`에 상위 합산, 하위 기여, 선택 필터, 열 순서 회귀 검사 포함. `dashboard-ux.yml` CI에서 `npm test`, 타입 검사, 린트, 빌드 검증.
- 범위 제한: 원천 데이터, 다른 작업자의 Agent 변경과 미커밋 파일은 수정하지 않음.
