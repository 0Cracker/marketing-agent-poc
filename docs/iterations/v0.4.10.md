# v0.4.10, 접을 수 있는 사이드바와 지표 그룹

- 날짜: 2026-10-28, dev 패치. 이전 버전 v0.4.9, 시작 SHA 6b249ff.
- 사용자 요청: 사이드바를 접어 본문을 넓히고, 지표 상세가 지표를 담는 그룹이라는 포함 관계를 강화.

데스크톱 로고 옆 접기 버튼으로 사이드바를 숨기고 상단 경로 옆 펼치기 버튼으로 복구한다. 화면과 필터는 그대로 유지하며 버튼 간 키보드 초점을 이동한다. 좁은 화면은 기존 메뉴 열기, 닫기를 유지한다. 새 의존성과 별도 페이지를 추가하지 않았다.

지표 상세는 화면 선택 대신 목록을 펼치고 접는 그룹이다. 폴더 아이콘, 방향이 바뀌는 화살표, 하위 연결선과 들여쓰기로 포함 관계를 표시했다. 지표만 선택 상태로 표시하며 카드나 브라우저 이력으로 상세를 열 때 그룹도 펼친다. 상태는 현재 화면 세션에서 유지하고 새로고침에는 기본 펼침으로 돌아간다.

[검증과 한계](../../evidence/sidebar-collapse-20261028/validation.md)에 본문 폭 216px 증가, CTR 분석 유지, 키보드 조작과 화면을 기록했다. 모바일 실기기는 미검증이다. 데이터와 스키마는 변경하지 않았다.

패키지와 잠금 파일 루트 버전 0.4.10, dev 커밋과 push, Vercel 확인 범위다. 기존 삭제 3개는 포함하지 않는다. main, 태그와 Release는 변경하지 않는다.
