# v5.0.16 지표 카드를 ROAS 분해식 순서로 재배치

- 날짜: 2026-11-17
- 기준: v5.0.15
- 작업 브랜치: `claude/gracious-cannon-ebmc8y`
- 범위: QA F06. 성과 현황의 지표 카드 순서와 묶음만 바꾼다. 지표 계산과 상세 화면은 바꾸지 않는다.

## 문제

카드가 CTR, CPC, CVR, CPA, CAC, AOV 순서로 동등하게 나열됐다. 화면이 쓰는 분해식 ROAS = AOV × CVR ÷ CPC와 순서가 달랐고, CTR은 산식에 없으며 CPA는 CPC ÷ CVR 파생값이다. CAC는 "미집계"로 카드 한 칸을 차지했다.

## 변경

- "ROAS 구성 지표": AOV, CVR, CPC를 산식 순서로 배치하고 산식을 함께 표시한다.
- "참고 지표": CTR, CPA. CTR과 CPA가 산식과 어떤 관계인지, CAC를 표시하지 않는 이유를 한 줄로 적었다.
- CAC 카드를 제거했다. 사이드바의 지표 상세 메뉴(CTR, CPC, CVR, CPA, AOV)는 바꾸지 않았다.
