# v5.0.17 매출과 CVR 용어 통일

- 날짜: 2026-11-17
- 기준: v5.0.16
- 작업 브랜치: `claude/gracious-cannon-ebmc8y`
- 범위: QA F07. 화면 용어와 설명만 바꾼다. 계산, 데이터 키와 서버 계약은 바꾸지 않는다.

## 문제

같은 매출을 ROAS 설명과 첫 화면은 "구매 전환 매출", 상세 표는 "귀속 구매 매출"로 불렀다. CVR도 카드는 "CVR", 상세는 "클릭 기준 구매 CVR", 퍼널은 "랜딩 세션 기준"이라 신입에게 서로 다른 지표처럼 보였다. CVR 상세의 KPI(클릭 분모)와 퍼널(세션 분모)의 차이도 설명이 없었다.

## 선택과 이유

- 매출 이름은 "귀속 구매 매출"로 통일했다. 표의 "귀속 구매 주문수", CVR 설명의 "광고 귀속 구매 주문수"와 같은 말을 쓰고, 광고에 귀속된 매출이라는 점이 드러난다.
- CVR 이름 자체는 사이드바와 상세 경로에서 쓰이므로 바꾸지 않고, 카드에 "클릭 기준"을 덧붙였다.

## 변경

- `training-dashboard.tsx`, `roas-examples.ts`, `shared/roas/roas-chat.mjs`의 "구매 전환 매출"을 "귀속 구매 매출"로 바꿨다. 예시 답변과 대화 표시 이름도 함께 바뀐다.
- CVR 카드에 "클릭 기준" 표시를 붙였다.
- 퍼널 위에 "분석 기간 클릭 N회 중 랜딩 세션은 M회…분모가 다릅니다" 문장을 추가했다(S16: 클릭 28,392회, 세션 24,701회).

## 검증

- `tests/roas/term-consistency.test.mjs` 2개 추가. `npm test` 90개, `npm run test:agents` 134개 통과.
- 실모델 답변이 새 표시 이름을 따르는지는 미검증이다(실모델 호출 승인 범위 밖).
- 화면 확인은 v5.0.20 최종 트리에서 일괄 수행했다. [결과](../../evidence/v5.0.20/validation/results.md)
