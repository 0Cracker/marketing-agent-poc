# v0.4.8, 지표 상세의 목적과 읽기 흐름 정리

- 날짜: 2026-10-28, dev 패치. 이전 버전 v0.4.7, 시작 SHA `0539d26`.
- 사용자 피드백: 경로가 버튼처럼 보임, 집계 기준의 접기 조작, 상세/비교 화면의 불분명한 구분, 원자료만 나열한 운영 근거와 중복 설정, 도달 용어와 지표 요약 정렬 문제.

## 선택과 구현

카드는 메인 ROAS 카드와 통일하는 안과 한 줄 비교안을 먼저 질문했고, 사용자는 카드 통일안을 선택했다. 화면 구조는 통합안과 두 화면 유지안을 제안했으나 별도 응답이 없어 권장 통합안을 기본값으로 적용한다고 알린 후 진행했다. 두 번째 선택을 사용자의 명시 승인으로 기록하지 않는다.

| 주석 | 반영 |
| --- | --- |
| 1 | 경로를 `성과 현황 / CTR 상세`처럼 테두리와 아이콘 없는 텍스트로 표시. 성과 현황을 누르면 기본 화면으로 복귀 |
| 2 | 기존 details를 설치된 Radix Tooltip으로 교체. 마우스 포인터와 키보드 초점에 설명을 제공하며 Escape로 닫음 |
| 3 | 상세와 비교 표를 한 화면에 통합하고 중복 전환 버튼과 view 상태 제거. 기존 지표 간 이동과 이력 유지 |
| 4 | 분석 기간에 겹치는 지표 관련 변경만 표시. 변경 전후 값, 대상, 사람이 읽는 시각과 함께 확인할 수치를 바로 제공. 원문은 추가 열람 |
| 5 | 별도 캠페인 설정/상품 기준 정보 블록 제거. 지표 계산과 관련 변경에 필요한 정보만 기존 데이터로 제공 |
| 6 | 도달을 광고를 본 사람 수, 빈도를 1인당 평균 노출 횟수로 표시하고 인원, 횟수 단위와 정의, 합산 불가 설명 제공 |
| 7 | 메인과 상세가 같은 지표 카드 컴포넌트를 사용. 현재 값, 직전 값과 증감을 정렬. 화살표는 수치 방향, 색은 개선/악화 의미를 따름 |

통합 시 기기별 비교가 상세의 모바일 선택을 강제로 전체로 초기화하는 문제를 확인했다. 비교 표만 두 기기를 포함하고 상세 범위는 유지하도록 수정했다. 중복 캠페인 표와 퍼널도 제거했다. 단일 비교 주제는 불필요한 탭을 표시하지 않는다. 데이터와 스키마는 변경하지 않았다.

## 검증과 한계

[검증 기록](../../evidence/detail-review-20261028/validation.md), [CTR 카드와 툴팁](../../evidence/detail-review-20261028/ctr-card-tooltip.jpg), [관련 운영 변경](../../evidence/detail-review-20261028/related-changes.jpg)을 따른다. 관련 검사 34개, 최종 변경 기록 검사 2개, 타입, 대상 린트와 빌드가 통과했다. 과거 S16의 227.8%를 기대하던 회귀 검사 한 곳을 기존 승인 데이터의 284.7%로 정정했으며 집계 방식과 원천 보존 검사는 유지했다.

인앱 브라우저에서 경로 복귀, 뒤로 가기의 CVR 모바일 선택 유지, 툴팁 초점/Escape, 공통 카드와 CPC 상승/악화 표현, 통합 구조, CTR 관련 변경 5건, 도달/빈도 명칭과 중복 설정 제거를 확인했다. 실제 마우스 호버 동작은 설치된 Radix의 포인터 처리에 연결했으며 자동 검수는 키보드 초점으로 수행했다. 실제 마케터의 과업 성공과 모바일 실기기는 미검증이다.

package.json과 package-lock.json 루트 버전을 0.4.8로 맞추고 dev에 반영한다. main, 태그와 Release는 범위 밖이다. 작업 시작부터 존재한 인수인계 문서와 examples 파일 3개의 삭제는 이번 변경에 포함하지 않는다.
