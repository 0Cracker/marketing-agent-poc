# v5.0.9 실제 모델 답변 Markdown 표시 정비

- 날짜: 2026-11-17
- 기준: v5.0.8 (작업 당시 기준 `b22ef99`, package 0.4.27)
- 작업 브랜치: `claude/fervent-lovelace-50b3me`
- 범위: 대화 패널의 실제 모델 답변(`RunMarkdown`) 스타일과 표 표시. 답변 내용, 서버 저장 계약, 모델 지침은 바꾸지 않는다.

## 문제

답변 형식 개선 계획(2026-11-17 대화, 사용자 승인 "ㄱㄱ")의 1단계다. mock 서버에서 `answer-guide.md` 형식의 심층 답변을 응답에 넣어 패널을 캡처하자 다음 문제가 보였다.

- `.wb-run-markdown`에 정의된 CSS가 없었다. 소제목이 본문과 비슷한 크기였고, Tailwind preflight 때문에 `ul`, `ol`의 기호와 번호가 사라졌다.
- 표 첫 열이 오른쪽으로 정렬됐고, 행이 지나치게 높았다. 증감 셀에 대시보드의 개선/악화 색 규칙이 적용되지 않았다.

## 변경

- `frontend/roas/run-markdown.css`를 추가했다. 소제목 단계와 구분선, 목록 기호, 표 테두리와 간격, 숫자 열 오른쪽 정렬과 고정폭 숫자를 정의한다. 기존 `.wb-chat-thread .wb-agent-result h3` 규칙보다 우선하도록 선택자 범위를 올렸다.
- 표의 첫 열을 행 머리글(`th scope="row"`)로 렌더링한다. 모든 값이 숫자인 열은 `is-numeric`으로 표시한다.
- `cellTone`을 추가했다. 부호가 있는 증감 셀의 지표 방향을 행 이름, 열 제목, 표 제목 순서로 찾는다. ROAS, 매출, CVR 등은 증가가 개선이고, CPC, 실패율 등은 감소가 개선이다. 집행비, 비용처럼 방향이 없는 지표와 0 증감은 회색이다. 방향은 대시보드의 `deltaTone` 규칙과 같다.

## 검증

- `node --experimental-strip-types --test tests/agents/ui/*.test.mjs`: 13개 통과. 신규 `run-markdown.test.mjs` 3개를 포함한다. 기존 표 테스트의 기대 태그는 의도한 변경에 따라 `td`에서 `th scope="row"`로 바꿨고, 파이프 이스케이프와 HTML 차단 검사는 유지했다.
- `npx tsc --noEmit -p .`, `npx eslint frontend/roas tests/agents/ui`: 종료 코드 0.
- Playwright 캡처(`npm run dev:agent:mock`, 응답 본문을 심층 답변 표본으로 교체): 1440px와 390px 화면 모두 페이지 오류 0건, 페이지 가로 스크롤 없음. 390px에서 넓은 표는 표 상자 안에서만 가로로 스크롤된다. 캡처는 세션 임시 폴더에만 있어 Evidence로 보존하지 않았다.
- 실제 모델 답변의 표시와 Vercel Preview는 확인하지 않았다.
