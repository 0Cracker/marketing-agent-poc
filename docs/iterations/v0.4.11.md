# v0.4.11, KPI 변화와 운영 근거를 연결하는 분석 표

- 날짜: 2026-10-28, dev 패치. 이전 버전 v0.4.10, 시작 SHA `eb30a96`.
- 사용자 승인 범위: 제안한 KPI 표 개편 계획의 구현. 기존 데이터 재사용, ROAS 현황과 CPC, CTR, CVR, CPA, AOV 상세, 수학적 기여와 행 확장. 신규 데이터와 원천 계약 변경은 제외한다.
- 목적별 커밋 단위: 공통 계산, 화면과 검증을 하나의 기능 변경으로 묶는다. main, 태그, Release와 원격 배포는 이번 구현 범위에 포함하지 않는다.

## Discover, 반복되는 비교 표

모든 상세에 기기별 성과 비교와 캠페인 막대, 별도 비교 작업 영역이 반복됐다. 지표별로 필요한 분자와 분모, 분석 단위와 운영 근거가 분산돼 있었다. 원천에는 캠페인과 기기 집계, 유입 분할, 상품 분할과 운영 기록이 이미 존재한다.

## Define, 수치 분해와 운영 원인 구분

사용자는 전체 변화 기여 계산, 분자와 분모의 기본 표시, 상품 구성과 할인 중심 AOV를 선택했다. KPI별 기본 열과 행을 달리하고 현재값과 증감만 기본 표시한다. 직전값, 관련 계산과 운영 기록은 행을 펼쳐 확인한다. 수학적 기여가 인과관계나 조정 시 회복 효과를 입증하지 않는다는 경계를 유지한다.

## Develop, 계산과 탐색 연결

- ROAS는 집행비, CPC와 CVR은 클릭수, CTR은 광고 노출수, CPA와 AOV는 주문수 비중을 사용한다. 구성 효과의 기준을 전체 KPI의 두 기간 평균으로 잡고 자체 변화와 구성 변화를 구분한다. 0 분모, 신규와 종료 그룹은 전체 기여만 직접 계산한다.
- ROAS 예시 답변의 6순서 평균 계산을 화면과 공유한다. CPA, CPC는 두 순서 평균을 사용한다. CPC의 광고와 콘텐츠 조회 지표는 분리하고 전체 CPC의 그룹 기여는 공통 클릭수 분모를 유지한다.
- 소재와 타깃, 게재 위치, 검색어는 캠페인과 함께 식별한다. 상품 분할과 유입 분할을 교차 결합하지 않는다. 세부 유입 범위에서는 상품 교차 분석과 도달 미제공을 표시한다.
- 행 확장에는 직전값, 계산 근거, 자체 변화와 구성 변화, 일별 추이, 운영 기록과 원문을 배치한다. CVR, CPA는 같은 세션의 순차 퍼널, 재방문 구매, 결제와 계측 자료를 구분한다. AOV는 상품별 주문 비중, 할인 전 단가, 실현 판매가와 할인액을 연결한다.
- 좁혀 보기만 조회 범위를 바꾼다. 상단 요약과 추이, 표, 예시 답변을 같은 자료로 갱신하고 뒤로 가기에서 범위, 정렬과 펼침을 복원한다. 기존 AI 조회 계약은 소재와 타깃 범위를 지원하지 않으므로 해당 범위에서는 로컬 예시만 제공한다. 실시간 질문은 세부 범위를 해제한 뒤 사용한다.
- 기존 서체와 증감 색상을 유지했다. 필수 열은 숨기지 않고 표 내부 가로 스크롤과 고정 행 이름을 사용한다. ROAS의 보조 지표 카드는 접은 영역에 보존했다.

초기 타입 검사에서 새 테스트의 원천 자료 타입 표기가 누락된 오류 3개를 발견해 `TrainingData` 표기를 추가했다. 브라우저에서 반올림된 양수 0 표시와 범위 이동 후 남는 상태 안내를 확인해 수정했다.

커밋 시 Git 작성자 설정이 없어 첫 명령이 실패했다. 최근 3개 커밋의 동일한 작성자 정보를 확인하고 이번 커밋 명령의 `-c` 옵션에만 적용했다. 저장소와 전역 Git 설정은 변경하지 않는다.

## Deliver, 검증과 한계

[검증 기록](../../evidence/kpi-analysis-20261028/validation.md)에 실제 명령, 수치 검산, 화면 조작과 캡처를 기록한다. 기존 원천의 바이트 보존을 포함한 회귀 114개를 통과했다. 수학적 합계 검사는 기존 18개 사례와 두 보고 시점의 1,080개 조합을 사용하며 신규 테스트 데이터를 만들지 않았다.

실제 마케터의 조사 성공률과 인과관계는 미검증이다. 375px 에뮬레이션과 키보드 가로 스크롤은 확인했지만 모바일 실기기는 미검증이다. 다상품 주문, 광고그룹, 프로모션, 랜딩 버전 연결, 경매 경쟁과 신규 고객 데이터는 추가하지 않았다. 필요 시 생성 수량, 관계와 검산 규칙을 별도로 제안한다.

패키지와 잠금 파일 루트 버전은 0.4.11이다. 기존 삭제 3개는 이번 변경에 포함하지 않는다. 원천 JSON, manifest, 공통 데이터 타입과 API 계약은 보존한다.
