# v0.4.7, 예시 질문별 분석 목적 분리

- 날짜: 2026-10-28, dev 패치. 이전 버전 v0.4.6, 시작 SHA `b2f8222`.
- 사용자 피드백: ROAS 기간 변화와 AOV, CVR, CPC 복합 변화는 다른 질문인데 예시 답변이 동일하다.

## 원인과 변경

두 질문을 같은 기여도 분석 분기에 연결하고 기간 변화 질문에 매출과 집행비 문장 하나만 추가한 것이 원인이었다. 질문별 결론, 비교 자료와 추천 행동을 별도로 검증하지 않아 중복된 답변이 배포됐다.

기간 변화 예시는 전체 매출과 집행비 증감, 상승/하락 캠페인 수, 하락 폭이 가장 큰 캠페인, 상승 폭이 가장 큰 캠페인과 현재 최저 캠페인을 비교한다. 선택 범위의 모든 캠페인 ROAS를 표와 그래프로 제공하고 실제 캠페인 원천 행으로 연결한다. 캠페인 자체의 ROAS 증감 순위와 전체 하락의 인과적 기여도 순위는 구분해 설명한다.

복합 변화 예시는 기존 AOV, CVR, CPC의 여섯 순서 평균 기여도와 상쇄 효과를 유지한다. 구매 이탈 예시와 데이터, 일반 AI 서버 요청은 변경하지 않았다.

## 검증

[검증 기록](../../evidence/example-intents-20261028/validation.md)을 따른다. 관련 검사 17개, 타입 검사, 대상 린트와 빌드가 통과했다. 기본 S16에서 첫째 예시는 매출 +29.3%, 집행비 +61.6%, 하락 4개와 상승 2개, 캠페인 비교 6행을 보여준다. 둘째는 지표별 +17.2%p, -51.8%p, -36.5%p와 전체 비교 1행을 보여준다. 결론, 요약, 근거와 행동이 서로 다르고 선택 범위를 지키는지 회귀 검사를 추가했다. 18사례, 두 보고 시점, 캠페인과 기기 범위 684개 조합의 원천 행 검산과 기존 기여도 합계 검사가 통과했다.

Chrome에서 서버 미연결 상태로 두 질문을 연속 클릭해 다른 답변을 확인했다. 실제 모델 출력과 실제 마케터의 이해도는 이번 검증 범위 밖이다. package.json과 package-lock.json 루트 버전을 0.4.7로 맞추고 dev에 반영한다. main, 태그와 Release는 변경하지 않는다.
