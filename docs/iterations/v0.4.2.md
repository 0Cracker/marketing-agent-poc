# v0.4.2, ROAS 조회 API와 근거 계약

- 이전 버전: v0.4.1, 시작 SHA `8029ac7d2788e62367f569c8f2ec38f1d3225366`.
- 날짜: 2026-10-27, dev 패치. main 병합과 태그, Release는 범위 밖이다.
- 사용자 승인: 지금까지의 작업을 목적별로 커밋하고 패치 버전을 갱신해 dev에 반영.

## 변경

ROAS 교육 자료를 현재 화면과 같은 필터와 집계로 조회하는 `/agent-api/roas/chat`을 추가했다. 기존 공급자 연결과 호출 간격 제한, 세션 토큰과 Origin 검사를 재사용한다. 데이터 해시와 조회한 근거 ID를 대조하며 표와 순위는 실제 집계에서 계산한다. 클라이언트에는 답변 타입과 호출 메서드를 추가했다. 새 원천 레코드와 데이터 스키마, 의존성은 추가하지 않았다.

서버, 공통 답변 계약, 클라이언트 호출과 회귀 검사를 한 커밋으로 묶는다. 화면 연결과 스타일은 후속 v0.4.3에 둔다. 이 커밋만 적용해도 기존 UI와 API가 유지된다.

## 검증과 한계

검증 명령과 결과는 [dev 패치 검증](../../evidence/dev-patches-20261027/validation.md)에 기록한다. 이전 로컬 모델과 화면 검증은 후속 UI 커밋에서 원래 Evidence와 함께 보존한다. 실제 모델 자유 서술의 모든 숫자와 인과 해석을 보장하지 않으며, 배포 화면의 AI는 기존 로컬 API 연결이 필요하다.
