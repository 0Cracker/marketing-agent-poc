# v0.4.18, 로컬 성과 화면의 dev 동기화

- 날짜: 2026-11-03, 이전 로컬 버전 v0.4.17, 시작 SHA `f329be0`, 작업 브랜치 `fix/local-performance-sync`.
- 원인: 원격 dev는 v0.4.15인 반면 로컬은 v0.4.16, v0.4.17 커밋과 미커밋 UI 변경을 실행하고 있었다. 앞선 확인은 화살표와 정보 아이콘만 확인해 화면 전체의 동기화를 입증하지 못했다. 캐시 문제로 확인된 것이 아니다.
- 요청: 로컬 성과 화면의 관련 변경까지 커밋하고 dev에 반영한다. 진행 중인 리뷰 데이터, 설계 문서, CI 초안과 기존 삭제 파일은 포함하지 않는다.

기존 로컬 UI 구현을 모아 반영한다. ROAS 표의 증감 우선 표시와 현재 라벨, 금액 정수 표시와 구매율 소수 두 자리, 공통 증감 서식과 반올림 색상, 클릭 기준 구매 CVR과 동일 세션 구매율의 명칭을 포함한다. KPI 요약과 추이를 나란히 배치하고 좁은 화면에서는 세로로 배치한다. CPA에서는 CPC와 CVR 관련 수치를 표시하고 구매 퍼널은 CVR 상세로 연결한다. 헤더 설명은 별도 (i) 대신 기존 헤더의 툴팁으로 제공한다. 원천 데이터와 집계, API는 변경하지 않는다.

표현과 배치 자체를 새로 개발하지 않고 이미 로컬에서 실행 중인 코드를 검증하고 커밋한다. 배포와 로컬의 실제 화면 대조를 마친 후에만 동기화 완료로 보고한다. [검증과 배포 기록](../../evidence/local-performance-sync-20261103/validation.md)을 따른다.
