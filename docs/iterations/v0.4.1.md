## Discover, Define

사용자가 캠페인 분류, 상세 탐색과 복귀, 반복 설명과 기간 비교 표현의 불편을 지적했다. 별도 승인으로 교육용 자사 상품, 초기 예산과 클릭당 제휴 비용 계약 오류를 정정한 기존 미커밋 변경도 이번 대시보드 수정본에 함께 포함한다. 데이터 변경 승인과 검산은 기존 기록을 보존한다.

## Develop

캠페인 검색과 집행처 선택, 고정 경로와 현황 복귀, 보조 지표 툴팁을 연결했다. 상세의 현재/직전/증감을 왼쪽에 모으고 반복 정의는 접었다. 캠페인 비교는 공통 눈금의 이중 막대, 표는 한 행과 공통 눈금 일별 추이로 변경했다. 퍼널은 단계별 이탈 수와 이탈률을 보여 준다. 원본 ID를 보존한 표시 이름을 사용한다. 새로 생성한 화면 데이터는 없으며 데이터 감사에서 승인받은 정정 범위를 포함한다.

같은 후속의 추가 피드백: 상단 기기 필터를 제거하고 상세의 모바일/PC 성과 비교와 선택적 기기 조회로 옮겼다. 전체 캠페인 조회는 목록을 감싸는 헤더 안의 버튼으로 바꿨다. 없는 기기나 새 수치를 만들지 않았다. 추가 브라우저 확인은 Work 설정의 로컬 브라우저 비활성화로 수행하지 못했다. 실제 검증 범위는 위 Evidence를 따른다.

카드 표현 후속: 작은 추이의 별도 범위 문구를 상한, 중간값, 0의 옅은 왼쪽 축 눈금으로 대체했다. ROAS는 직전 기간과 분석 기간 전체 값 사이에 상승/하락 화살표와 %p 차이를 표시한다. 기존 집계 코드와 추가 검사로 두 주 수치가 기간 매출 합계/집행비 합계이며 일별 단순 평균이나 마지막 날 값이 아님을 확인했다. 표현 검사는 5개 통과이며 화면 조작 한계는 위 Evidence에 유지한다.

브라우저 주석 2건 후속: 카드별 그래프가 작고 정렬과 여백이 어긋난다는 제공 화면에 따라 최소 카드 폭을 늘리고 제목/값/176px 그래프의 행 높이를 맞췄다. ROAS는 기존 현재 값과 직전 값 배치, 작은 설명을 복원하고 큰 방향 아이콘, 상승/하락 단어와 추가 산식을 제거했다. 증감 옆 작은 곡선 화살표만 남겼다. 이번 변경을 직접 브라우저로 확인하려 했지만 로컬 브라우저 비활성화가 지속되어 제공된 화면과 코드 기준으로 수정했다. 시각 검증 완료로 기록하지 않는다.

사용자 의도 재확인 후 수정: 임의로 바꾼 카드 열 수를 일반 PC의 기존 3열로 되돌리고 카드 내부 176px 그래프와 행 정렬은 유지했다. 작은 추이만 실제 두 기간 값을 포함하는 상한/하한 2개 눈금을 사용하며 큰 그래프의 0 기준 축은 보존한다. ROAS는 직전 작은 값 → 곡선 화살표 → 큰 현재 값으로 배치하되 기존 작은 설명은 유지하고 상승/하락 단어와 추가 산식은 넣지 않는다. 표현 검사는 공통 범위와 일정값 등의 검사 2개를 추가해 7개 통과다. 화면 검증의 한계는 기존 Evidence에 유지한다.
