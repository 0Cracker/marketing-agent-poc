# v0.4.14, 활성 열의 단일 정렬 표시

- 날짜: 2026-11-02, 로컬 작업 브랜치 `fix/kpi-header-sort`. 이전 버전 v0.4.13, 시작 SHA `b934a4e`.
- 사용자 수정: 양방향 삼각형을 항상 나열하지 않고 선택한 열만 살짝 강조한다. 오름차순은 ▲, 내림차순은 ▼ 하나만 표시하고 표 내부 (i)를 제거한다.

활성 머리글에만 연한 배경과 단일 방향 삼각형을 표시한다. 비활성 머리글의 화살표는 비운다. 화살표 공간을 유지해 방향 전환으로 글자가 움직이지 않도록 했다. 메인 표, 기간별 계산 근거 표, 상품 표의 정보 아이콘과 관련 설명 정의를 제거했다. 결측 수치의 구분은 유지하고 이유는 텍스트의 title에 남긴다. 표 외부에서 사용하는 공통 정보 컴포넌트는 유지한다.

정렬 산식, 열 순서, 원천 데이터와 API는 변경하지 않았다. 표현 변경이므로 새 논리 검사를 추가하지 않고 기존 분석 검사 10개와 실제 화면 검증을 수행했다. 타입 검사, 변경 파일 린트와 빌드가 종료 0이다. 기존 pages 경로 안내, 폰트 경로와 플러그인 소요 시간 안내는 남아 있다. [화면 검증](../../evidence/kpi-sort-indicator-20261102/validation.md)을 따른다. 원격 push와 배포는 수행하지 않는다.
