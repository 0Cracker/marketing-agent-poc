# v0.4.4, 표 수치와 AI 답변의 성과 색상 통일

- 날짜: 2026-10-27, dev 패치. 시작 SHA: `3fffbdd7e9d59a369d98c8db8a19cc3465c6f99b`.
- 사용자 요청: 모든 표 수치에 빨강은 개선, 파랑은 악화, 회색은 중립을 적용하고 dev에 커밋, 반영한다.

## 문제와 변경

기존 기간 비교와 캠페인 표는 증감만 성과 방향으로 칠하고 현재 수치는 별도 색을 사용했다. AI 답변은 지표 의미 없이 증가를 개선으로 처리해 CPC 상승도 빨강으로 표시할 수 있었다.

기존 공통 판정 함수 deltaTone을 표의 현재 수치, 증감, 상세 지표와 비교 그래프 수치, AI 답변 표와 그래프에 연결했다. CPC, CPA, 결제 실패와 로딩 시간은 감소가 개선이며 매출, 구매, 전환율은 증가가 개선이다. 판매 수량, 재방문 구매와 주문 원장 매출, 주문 수에도 증가가 개선인 규칙을 적용했다.

직전 값은 비교 기준으로 회색을 사용한다. 집행비, 노출, 클릭, 가격, 할인, 도달, 빈도처럼 증감만으로 성과를 확정할 수 없는 값은 중립이다. 미집계, 비교 불가와 표시 정밀도에서 0인 증감도 중립으로 유지한다. 원천 데이터와 계산식은 변경하지 않았다.

## 검증과 범위

[검증 기록](../../evidence/table-colors-20261027/validation.md)을 따른다. 프런트 검사 29개, 교육 대시보드 24개, ROAS 67개가 통과했고 타입 검사, 대상 린트와 빌드를 확인했다. 프런트 29개에 색상 공통 규칙 검사 8개가 포함된다.

package.json과 package-lock.json 루트 버전을 0.4.4로 맞춘다. 기존 dev에서 직접 커밋하고 push하므로 별도 병합 커밋은 필요하지 않다. main, 태그, Release는 범위 밖이다. 원격 반영과 Vercel 상태는 커밋 후 실제 SHA로 확인한다. 실제 브라우저 화면과 전 사례의 육안 확인은 미실행이다.
