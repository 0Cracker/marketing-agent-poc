## 검증과 한계

후보 및 Squash 후 main에서 기존 테스트 2개·TypeScript·Vite build 모두 종료 0. A 분석→계획 승인→Mock 등록, E 결측·예산 버튼 차단, C 모의 배분과 가정, B/D/F의 판단 차이를 브라우저에서 확인했다. PNG 3개와 검증 요약을 Evidence에 포함했다.

JS 약 707KB 청크 경고가 남는다. 모바일/전체 접근성·마케터 이해·시간 절감/실제 효과는 미검증이다. 이전 baseline에 같은 CTI 사례가 없어 동일 조건의 UI 전후 비교는 불가능하다. v0.0.0은 식별용 baseline이며 새로 검증 완료한 과거 성과가 아니다.

## 기존 작업 보존

원격 기존 커밋 2개와 Draft PR #1 및 codex/inline-analysis-reports 브랜치는 보존했다. 별도 로컬 이력의 b7f0551은 local-source-20261013 Annotated Tag로 원격에 보존했다. 기존 소스를 가져오는 과정에서 텍스트 줄바꿈만 정규화했고 기능·Mock는 변경하지 않았다. tsconfig.tsbuildinfo는 디스크에 보존하되 Git 추적에서 제외했다.

원래 작업은 stash@{0}과 바탕화면 marketing-poc-local-source-20261013.zip / marketing-poc-local-new-files-20261013.zip에도 남겨 두었다. 원본 복구용이며 현재 진행 중인 미완료 작업을 뜻하지 않는다. 임의로 적용하면 오래된 파일이 덮어써질 수 있으므로 복원 필요 시 먼저 내용을 비교한다.

태그에 포함된 일지·인덱스는 발행 직전 준비 상태다. 발행 후 사실을 같은 태그 트리에 다시 커밋하지 않았으며 Release Notes와 이 보고서에 기록했다. 인덱스의 발행 완료 상태 갱신은 다음 dev 사이클에 반영한다. 다음 버전·기능을 임의 생성하지 않았다.
