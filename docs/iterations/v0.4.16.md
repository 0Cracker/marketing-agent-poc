# v0.4.16, ROAS 표 증감 우선 표시와 실제값 정렬

- 날짜: 2026-11-02, 작업 브랜치 `fix/roas-table-raw-sort`. 이전 버전 v0.4.15, 시작 SHA `a51c961`.
- 문제 및 근거: ROAS 메인 분석 표에서는 셀의 위쪽 현재값과 실제 정렬 기준(증감)의 불일치로 정렬 결과가 직관적이지 않았다. 사용자는 ROAS 페이지에서 증감 우선 표시, 다른 지표 페이지에서 기존 순서 유지, 모든 수치 헤더에서 현재 분석 기간의 원시값 정렬을 선택했다.
- 변경: ROAS 상세 데이터의 주 분석 표에서만 증감을 첫 줄, 현재값을 두 번째 줄에 표시한다. CPC, CTR, CVR, CPA, AOV 등 다른 지표 페이지, 상품/기간별 근거 표, KPI 요약의 값 배치는 유지한다. 수치 헤더의 오름차순/내림차순은 해당 지표의 현재 분석 기간 실제값을 기준으로 한다. 전체 변화 기여 열과 기본 영향 기여도 순서는 기존 기여 계산/정렬을 유지한다. 결측은 마지막에 둔다. 데이터, 집계 산식 및 API는 수정하지 않았다.
- 검증: `node --experimental-strip-types --test tests/training-analysis.test.ts` 10개 통과. 원시값 오름차순과 내림차순, 기여도 기본 정렬 회귀를 확인했다. 화면을 통한 시각적 점검은 수행하지 않았다. 별도 Evidence 캡처는 생성하지 않았다.
- 범위 통제: 기존 미커밋 AGENTS.md, 문서, data 관련 변경과 미추적 파일은 본 커밋에 포함하지 않는다. main 병합, 태그, Release, 원격 push는 범위 외다.
