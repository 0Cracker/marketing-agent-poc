# v5.0.13 운영 기록의 발생 기간을 추이 음영으로 표시

- 날짜: 2026-11-17
- 기준: v5.0.12 (`eff56c2`)
- 작업 브랜치: `claude/gracious-cannon-ebmc8y`
- 범위: QA 후속. 운영 기록에 이미 있는 시작·종료 값을 추이 차트의 기간 음영으로 표시한다. 데이터와 스키마는 바꾸지 않는다.

## 문제

v5.0.8의 이벤트 마커는 기록 날짜에 세로선 하나만 그린다. S16 모바일 간편결제 오류는 8/21 00:00부터 8/25 00:00까지 이어졌는데, 차트에서는 8/21 하루 사건처럼 보였다. CVR 하락 구간(8/21~8/24)과 겹치는지 사용자가 원문을 열어 날짜를 계산해야 했다.

## 변경

- `trainingEvents`가 각 날짜 묶음에 `spans`를 함께 돌려준다. 기록의 `values.시작`, `values.종료`를 읽고, 자정 종료는 그 날을 포함하지 않는다. 분석 기간 끝과 보고 시점에서 잘라낸다.
- 전체 추이와 지표 상세 추이에 `ReferenceArea` 음영을 그리고, 이벤트 버튼에 "08/21~08/24 지속, 차트 음영"을 표시한다.
- 음영은 기록된 발생 기간이며, 성과 변화의 원인 판단이 아니다. 기존 안내 문구를 유지한다.
