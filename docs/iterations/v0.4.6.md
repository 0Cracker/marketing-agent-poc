# v0.4.6, 지표 상세의 고정 탐색과 성과 현황 복귀

- 날짜: 2026-10-27, dev 패치. 이전 버전 v0.4.5, 시작 SHA `48f51f5`.
- 사용자 요청: 구 대시보드의 아이콘과 문구 변경, 지표 상세에 진입한 사실과 성과 현황으로 돌아갈 동선 개선.

## 문제와 변경

상세 화면에서는 작은 경로 버튼을 찾아야 성과 현황으로 돌아갈 수 있었고, 다른 지표를 보려면 다시 현황으로 돌아가는 과정이 필요했다. 필터 아래의 고정 탐색 바에 성과 현황 복귀와 지표 바로 이동을 배치했다. 현재 지표는 밑줄과 aria-current로 표시하고 상세 분석, 비교 표와 운영 기록도 같은 위치에서 전환한다. 기존 색감, 폰트와 브라우저 이력 구현을 재사용했다.

구 대시보드는 Marketing 로고와 같은 Layers 아이콘으로 변경하고 “(구) 대시보드 확인”으로 표시한다. 성과 현황에서 펼쳐둔 표를 복귀 전에 복원해 문서 높이 변화로 스크롤이 잘리는 문제를 수정했다. 이동 후 주제목에 키보드 초점을 옮겨 전환을 인식할 수 있도록 했다. 데이터와 계산식은 변경하지 않았다.

## 검증과 한계

[검증 기록](../../evidence/navigation-20261027/validation.md)과 [최종 CPC 화면](../../evidence/navigation-20261027/cpc-navigation.jpg)을 따른다. 교육 대시보드 회귀 24개와 타입, 대상 린트, 최종 빌드를 통과했다. Chrome에서 지표 직접 이동과 비교 표 전환, 상세 하단의 고정 탐색, 성과 현황 복귀, 브라우저 뒤로/앞으로, AI 패널과의 동시 표시를 확인했다. 펼친 표가 있는 성과 현황에서 실제 좌표 클릭 전후 scrollY 1,097px와 펼침 상태가 유지됐다. 별도 모바일 기기와 실제 사용자 효과는 미검증이다.

package.json과 package-lock.json 루트 버전을 0.4.6으로 맞추고 한 목적의 dev 커밋으로 반영한다. main, 태그와 Release는 범위 밖이며 Vercel은 push 후 실제 커밋 상태를 확인한다.
